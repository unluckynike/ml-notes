# A/B 测试深读：功效分析、序贯设计与实战陷阱清单

这篇是**实验设计与 A/B 测试**主题的深度补充。演示里「偷看膨胀假阳性」只是一个坑，这篇把工业实验的完整方法论讲全：**功效分析的具体计算**、**序贯检验的原理**、以及一份可以直接当检查表用的陷阱清单。

> [!KEY] 一句话抓住本质
> A/B 测试的统计纪律只有三条：**预先定死样本量与分析方案**（防偷看）、**保证功效**（样本量够大，否则白跑）、**分流随机且稳定**（SRM 告警）。三条全守住的实验才配下结论——任何一条破了，结论都只是「碰巧」。

## 一、功效分析：样本量怎么算出来的

检验四要素的闭式关系：α（假阳性率）、功效 1−β（检出真效应的概率）、效应量 δ、样本量 n。双比例检验的经验公式：

$$n/\text{组} \approx \frac{16 \cdot \bar{p}(1-\bar{p})}{\delta^2}$$

**两个直觉读数**：

1. **n 与 δ² 成反比**——效应减半、样本 ×4：检测 1pp 差异要 3.6 万/组，0.5pp 要 14 万/组。小流量的业务要么攒流量、要么接受「只能检出大差异」；
2. **基线越极端越省样本**：p̄=50% 最费（16×0.25=4），p̄=5% 或 95% 省 5 倍（16×0.0475）——低基数指标的实验意外地便宜。

**功效不足的隐性代价**：不是「测不出」而是「测出的显著结果更可能是高估」（victory bias：只有碰巧超大的效应才能在低功效下显著——**small study effect**）。看论文里小样本+大效应的组合要警惕。

**功效分析一行公式**——样本量由「效应大小、显著性、功效」三者锁死：

```python
import numpy as np
from scipy import stats
def sample_size(p0, mde, alpha=0.05, power=0.8):
    p1 = p0 + mde
    z_a, z_b = stats.norm.ppf(1 - alpha/2), stats.norm.ppf(power)
    var = p0*(1-p0) + p1*(1-p1)
    return int(np.ceil(((z_a + z_b)**2 * var) / mde**2))

print('基线 5%，检出 8%（+3pp）：每组需', sample_size(0.05, 0.03), '人')
print('基线 5%，检出 6%（+1pp）：每组需', sample_size(0.05, 0.01), '人')
# 效应缩小 3 倍 → 样本量涨 9 倍——「小效应想显著」是 A/B 的头号成本黑洞
```

## 二、序贯检验：合法地「边跑边看」

业务要求「尽早止损/尽快收益」，完全不许偷看不现实。**序贯方法**给出合法的偷看协议：

- **alpha spending**：把总 α 预算分配到检查时点（越早的检查花得越少）——每次检验用剩余预算折算的临界值（比 0.05 严得多）；
- **mSPRT / 贝叶斯序贯**：混合似然比检验，任何时候都可以看且假阳率仍受控（Optimizely 的方案）；贝叶斯版用「B 击败 A 的后验概率 ≥ 95%」做决策规则；
- **group sequential**（_group-sequential_）：预定 K 个检查点（如 4 次），用 Pocock/O'Brien-Fleming 边界——OBF 的边界早期极严、末期接近 0.05，是最常用的形态。

**成本**：序贯方法需要稍多的样本达到同样功效（多 10~30%）——这是「随时能看」的保险费。

## 三、陷阱清单（检查表）

**实验前**：

- [ ] 指标预注册（主指标 1 个、护栏指标若干）——「跑完挑好看的指标」= 多重检验作弊；
- [ ] 样本量/时长计算（含预计流量折算天数，且覆盖完整周期——周中/周末行为不同）；
- [ ] 分流哈希稳定（同一用户始终同组）与 SRM（样本比例失配告警：设计 50/50 实际 49.5/50.5 都要查——分流 bug 是最常见的假结论来源）。

**实验中**：

- [ ] 不提前停（除非用序贯方法）；
- [ ] 监控护栏（延迟/崩溃率/护栏业务指标）而非主指标；
- [ ] 排除机器人与异常流量（一个爬虫集群能污染整个实验）。

**实验后**：

- [ ] SRM 检验（χ² 检验分流比例）；
- [ ] 分群稳健性（新用户/老用户、平台、地域的效应方向一致吗——不一致说明有交互效应）；
- [ ] 谨慎外推：「实验期有效」不等于「长期有效」（novelty effect 新鲜感效应）。

## 常见误区

- **「p < 0.05 说明 B 比 A 好」** —— p < 0.05 只说明「如果无差异，出现此数据的概率 < 5%」——不含效应大小、不含先验信息、且被多重比较扭曲；决策需要看效应量与 CI。
- **「实验跑了足够久就可以停了」** —— 提前停止（peeking）导致假阳性率远超 α（演示可见膨胀至 20%+）；固定样本量或用序贯方法——「看一眼就走」是第一大坑。
- **「A/B 测试不需要关注分流质量」** —— SRM（样本比例失配）是实验 bug 的头号信号：设计 50/50 实际 49/51 就值得排查——分流 bug 会产生方向完全错误的结论。
- **「一次实验只测一个变量所以结论可靠」** —— 忽略了网络效应（用户互相影响）、周期效应（工作日 vs 周末）、新颖性效应——实验设计比「随机分流」复杂。

## 四、要点总结

1. **三条纪律**：预注册样本量与方案、功效足够、分流随机稳定（SRM 检查）。
2. **样本量公式**：n ≈ 16p̄(1−p̄)/δ²；效应减半样本 ×4。
3. **偷看膨胀**：反复检验的假阳率远超 α；合法方案是 alpha spending/mSPRT/贝叶斯规则。
4. **功效不足的隐性代价**：显著的效应倾向被高估（small study effect）。
5. **三大进阶陷阱**：辛普森（分流不均）、网络效应（需 cluster 随机化）、多重指标（FDR/Bonferroni 校正）。
6. **novelty effect**：新鲜感效应让早期指标虚高——实验时长要覆盖完整行为周期。
