# K-Means 深读：目标函数、初始化与收敛性

这篇是 **K-Means 聚类**主题的深度补充。K-Means 看起来是「分配 → 求均值」的常识，但它的**目标函数是什么、为什么必然收敛、坏初始化怎么毁掉结果**——这三问的答案让它从「会用」变成「真懂」。

> [!KEY] 一句话抓住本质
> K-Means 在最小化**簇内平方和**（SSE/WCSS）：$J = \sum_{k=1}^{K}\sum_{i \in C_k} \lVert x_i - \mu_k\rVert^2$。「分配」和「移动质心」两步，各自都是在这个目标上做**坐标下降**——每步只会让 J 变小或不变，所以必然收敛。

---

## 一、K-Means 在优化什么

给定 K 个簇，定义目标（也叫失真函数 distortion）：

$$J = \sum_{i=1}^{n}\sum_{k=1}^{K} r_{ik}\,\lVert x_i - \mu_k \rVert^2$$

其中 $r_{ik}$ 取 0 或 1（「硬分配」）：点 $i$ 属于簇 $k$ 则为 1。变量有两类：分配 $r$ 和质心 $\mu$。联合优化是 NP 难的，K-Means 交替固定一方优化另一方：

- **固定 $\mu$，优化 $r$**：每个点独立选择——离哪个质心最近就归谁（距离最小化显然是最优分配）。
- **固定 $r$，优化 $\mu$**：对 $J$ 求导置零，解就是**簇内均值**（这正是名字的由来）：

$$\frac{\partial J}{\partial \mu_k} = -2\sum_{i \in C_k}(x_i - \mu_k) = 0 \;\Rightarrow\; \mu_k = \frac{1}{|C_k|}\sum_{i \in C_k} x_i$$

两步都只降不升 → $J$ 单调收敛；而「把 n 个点划分成 K 簇」的方式有限，J 不会无限下降 → **有限步内必然停止**（严格说是到达一个不动点）。代价：收敛到的是**局部最优**，取决于初始化。

> [!NOTE] 它是 EM 的特例
> 把 GMM 的协方差取成相同的 $\epsilon I$ 并令 $\epsilon \to 0$，E 步的软责任退化为「最近质心的 one-hot」，M 步就是均值——K-Means 是 GMM 的硬分配极限。见「EM 算法与高斯混合」的深度阅读。

## 二、初始化：一次坏运气毁掉所有

随机挑 K 个点当初始质心，可能两个质心落在同一个真实簇里，最终那个簇被撕成两半、另两个簇被合并——**而且没有任何梯度信号能逃出来**。经典痛图：把「优/良/中」三类学生聚成「高个组/矮个组」。

**k-means++（2007，Arthur & Vassilvitskii）**：让初始质心互相离得远。

1. 第一个质心均匀随机选。
2. 之后每个质心以**正比于最近已选质心距离的平方**的概率选取：

$$P(x) = \frac{D(x)^2}{\sum_{x'} D(x')^2}$$

效果：理论保证期望近似比 $\le O(\log K)$，实践中几乎消灭了「坏局部最优」；代价只是初始化多花 O(nK) 距离计算。**现代库默认都是 k-means++，手写时别再均匀随机取点。**

**n_init 多次重启**：跑 10 次取 J 最小的一次，是另一层保险（sklearn 默认 n_init=10）。

## 三、K 怎么选：三个实用工具

**肘部法（Elbow）**：画 J 随 K 的曲线。真实簇数之前 J 陡降，之后变缓——拐点即肘。缺点：拐点常常模糊，本质是个「视觉法」。

**轮廓系数（Silhouette）**：对每个点算「与自己簇的凝聚度」对比「与最近邻簇的分离度」：

$$s(i) = \frac{b(i) - a(i)}{\max(a(i),\; b(i))},\qquad s \in [-1, 1]$$

$a(i)$ = i 到同簇其他点的平均距离（越小越好），$b(i)$ = i 到**最近的其他簇**所有点的平均距离（越大越好）。s 接近 1 说明归属清晰；接近 0 说明在边界上；负数说明大概率分错了。选让**平均轮廓系数最大**的 K，比肘部法客观。

**业务先验**：聚类的 K 常常由下游需求决定（客服分 5 组、运营分 8 层）——不要为了 0.02 的轮廓系数差距违背业务约束。

## 四、什么时候会失灵

| 数据形态 | 失灵原因 | 换什么 |
|---|---|---|
| 环形/月牙形嵌套簇 | 基于质心的球形假设 | DBSCAN / 谱聚类 |
| 大小悬殊的簇 | 大簇的质心被拉偏，吞掉小簇 | GMM / 层次聚类 |
| 密度不同的簇 | SSE 偏爱大而密的簇 | DBSCAN / HDBSCAN |
| 高维稀疏 | 欧氏距离失去区分度（维度灾难） | 先降维 / 余弦距离 + 球形 K-Means |
| 类别特征 | 均值无定义 | K-Modes / K-Prototypes |

> [!TIP] 工程细节清单
> - **必须标准化**：量纲大的特征会垄断距离（身高 mm vs 体重 kg）。
> - **Mini-Batch K-Means**：大数据上每次只用一小批样本更新质心，快数倍，质量略降——sklearn 的 `MiniBatchKMeans`。
> - **看簇的稳定性**：换 seed 重跑，簇成员大换血 = 结果不可信。
> - K-Means 的 J 只在**同一 K、同一数据**下可比，不能跨 K「J 更小说明更好」（K 越大 J 必然越小，K=n 时 J=0）。

## 五、面试要点速答

1. **K-Means 的目标函数？** 簇内平方和 J；两步分别是对 r 和 μ 的坐标下降，各自最优解是「最近分配」和「簇均值」。
2. **为什么必然收敛？** J 每步单调不增 + 取值空间有限（划分有限）→ 必达不动点；但只是局部最优。
3. **k-means++ 好在哪？** 按距离平方概率撒初始质心，避免同簇扎堆；期望近似比有理论界。
4. **K 怎么选？** 肘部法看 J 拐点、轮廓系数取最大、结合业务约束；不要用 J 本身跨 K 比较。
5. **K-Means 与 GMM 的关系？** 硬 vs 软分配、球形 vs 椭圆、SSE vs 似然；K-Means 是 GMM 协方差趋于相同极小时的极限。
6. **为什么必须标准化？** 欧氏距离对量纲敏感，大量纲特征主导 J 的梯度方向。
