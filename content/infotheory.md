# 信息论深读：编码视角、KL 的方向性与信息瓶颈

这篇是**信息论**主题的深度补充。演示里「熵/交叉熵/KL」三个数联动，这篇把**编码视角**讲透（为什么 −log p 就是比特数）、**KL 方向性的实际后果**（正向/反向的行为差异）、以及**信息瓶颈**这个现代表示学习的理论框架。

> [!KEY] 一句话抓住本质
> 信息论的统一视角是**编码**：熵 = 最优编码长度；交叉熵 = 用错误模型编码的代价；KL = 两者之差。深度学习的「最小化交叉熵损失」字面意义上就是「让模型学会给真实世界编码」——损失函数的历史就是信息论的应用史。

---

## 一、编码视角：−log p 为什么是比特数

Shannon 的洞察：**编码长度可以与概率挂钩**——概率 p 的事件「信息量」= −log₂p 比特。直觉验证：

- p=1（必然事件）：0 比特（说了等于没说）；
- p=0.5：1 比特（一次抛硬币）；
- p=0.001：约 10 比特（千分之一的事发生了，很「意外」）。

**熵** = 平均编码长度 $H(p) = -\sum p\log_2 p$。为什么 −log 恰好是最优的：把高频事件编短码、低频编长码（霍夫曼编码的思想），可以证明平均长度最短能压到 −Σp log p（存在性：算术编码任意接近）。

**交叉熵与 KL**：手头有一套为 q 设计的编码（每个符号 −log₂q 比特），却要编码 p 分布的消息——平均代价 $H(p,q) = -\sum p\log_2 q$。多付的 $H(p,q) - H(p) = KL(p\|q)$ 就是「模型错误的罚金」。

> [!NOTE] 机器学习就是学编码
> 语言模型 = 学习「文本的分布」= 学习给文本编码（每个 token 的交叉熵）；训练后模型的压缩率（bits per character）与能力强相关——**「压缩即智能」假说**（Hutter）的信息论版本。这也是为什么 GPT 可以无损压缩文本（nanogpt 压缩实验）。

**熵与 KL 的数值实验**——验证「均匀分布熵最大」「KL 非负且不对称」：

```python
import numpy as np
def H(p):                                        # 香农熵（比特）
    p = np.asarray(p); p = p[p > 0]
    return float(-(p * np.log2(p)).sum())

print(round(H([0.5,0.5]),2), round(H([0.9,0.1]),2), round(H([0.99,0.01]),2))  # 1.0→0.47→0.08
print(round(H([0.25]*4),2), round(H([0.5, 0.25, 0.25, 0.0]),2))  # 均匀 = log2(K) 上限

def KL(p, q):
    p, q = np.asarray(p), np.asarray(q)
    mask = p > 0
    return float((p[mask] * np.log2(p[mask] / q[mask])).sum())

print(round(KL([0.5,0.5],[0.9,0.1]), 3), round(KL([0.9,0.1],[0.5,0.5]), 3))
# 两个方向的 KL 不相等——「正向追均值，反向保模式」（正文第二节）
```

## 二、KL 的方向性：正向 vs 反向的行为差异

$KL(p\|q) \ne KL(q\|p)$，而且方向的差别有**可预测的行为后果**：

- **正向 KL(p‖q)（匹配 q 到 p）**：q 必须「覆盖」p 的所有峰——否则 p 有而 q 没有的区域 KL→∞。行为：**均值覆盖（mean-seeking）**，q 倾向铺开；
- **反向 KL(q‖p)**：q 可以集中到 p 的某一个峰，只要那里 q 有概率密度就行。行为：**零回避（mode-seeking）**，q 倾向收缩到单个峰。

这正是变分推断的选型：VAE 用反向 KL（q 集中到某个合理解释，宁可保守）；期望传播用正向。也是蒸馏（学生拟合教师分布）中温度参数（见蒸馏深读）重要性的根源——软化分布让 KL 的覆盖行为更可控。

**Jensen 不等式的角色**：KL≥0 的证明来自 log 的凹性；「期望的函数 ≤ 函数的期望」这一条也是 EM/ELBO（见 EM 深读）和 Jenson-Shannon 散度（GAN 的原始目标，见其深读）的来源——**一条不等式串起半个机器学习**。

## 三、互信息与信息瓶颈

**互信息** I(X;Y) = KL(p(x,y) ‖ p(x)p(y))：知道 X 让 Y 的不确定度下降多少（= H(Y) − H(Y|X)）。它是「相关性」的信息论升级——捕捉任意统计依赖（线性相关的皮尔逊相关系数只是它的线性切面）。

**信息瓶颈（Information Bottleneck）**：表示学习的理论框架——学一个压缩表示 T，使得

$$\min \; I(X;T) - \beta \, I(T;Y)$$

即「T 尽量不含 X 的信息（压缩），但保留关于 Y 的信息（预测）」。深度学习的泛化有一个假说：网络先拟合（I(T;Y)↑）再压缩（I(X;T)↓）——实证有争议，但作为目标函数的「信息瓶颈」已衍生出变分信息瓶颈（VIB）等实用方法。InfoNCE（对比学习，见 CLIP/自监督深读）就是互信息的下界估计。

## 常见误区

- **「KL 散度是距离」** —— KL 不对称（KL(p‖q) ≠ KL(q‖p)）且不满足三角不等式——它是「散度」不是「距离」；方向选择影响优化行为。
- **「熵为零表示系统完全确定」** —— 对离散分布正确；**连续分布的微分熵可为负甚至负无穷**——连续情形需要加参考测度才有意义。
- **「互信息为零 = 独立」** —— 对互信息定义正确；但常被误用于「相关系数为零 = 独立」——相关系数只捕捉线性关系，互信息捕捉所有统计依赖——两者不可互替。
- **「最大熵模型 = 最不确定的模型」** —— 最大熵是在**满足已知约束**下最不确定——约束外的假设全部排除；它不是「不做假设」而是「只做已验证的假设」。

## 四、要点总结

1. **−log₂p = 信息量**：概率越小越意外；熵 = 平均意外程度 = 最优编码长度。
2. **交叉熵 = 用错码本的代价**；KL = 罚金；「最小化交叉熵 ≡ 最大似然 ≡ 最小化 KL」。
3. **KL 方向性**：正向均值覆盖、反向零回避——变分推断与蒸馏的行为差异根源。
4. **互信息**：捕捉任意依赖的相关性升级版；InfoNCE 是它的下界估计。
5. **信息瓶颈**：压缩 + 保留任务信息 = 表示学习的目标函数化。
6. **压缩即智能假说**：语言模型的压缩率与能力强相关——信息论视角的「为什么 GPT 有效」。
