# DDIM 深读：非马尔可夫视角与确定性采样

这篇是**扩散加速采样**主题的深度补充。DDIM 的操作只有一行（把更新公式里的 σ 置 0 并跳步），但它的推导揭示了一个深刻事实：**DDPM 的马尔可夫前向过程只是训练目标的包装，采样时可以换掉它**。这篇把这个「换视角」讲清楚。

> [!KEY] 一句话抓住本质
> DDPM 的训练只学了一个东西：**每个噪声水平下预测 x₀（或等价地预测 ε）**。DDIM 指出：给定这个预测器，加噪过程的「路径」可以不是马尔可夫链——把更新公式写成广义形式 $x_{t-1} = \sqrt{\bar\alpha_{t-1}}\hat{x}_0 + \sqrt{1-\bar\alpha_{t-1}-\sigma_t^2}\,\hat\epsilon + \sigma_t z$，**σ=0 就得到一条确定性捷径**，可以任意跳步。

---

## 一、广义更新的推导

DDPM 后验采样（见扩散模型主题）每步用完整 $\beta_t$ 的高斯转移，被迫逐步走 1000 步。DDIM 的洞察：训练目标（变分下界的每一项）**只依赖边缘分布** $q(x_t|x_0)$，不依赖转移的具体形式——于是可以自由设计一个「非马尔可夫」前向，其反向采样的均值恰为：

$$x_{t-1} = \sqrt{\bar\alpha_{t-1}}\;\hat{x}_0 + \sqrt{1-\bar\alpha_{t-1}-\sigma_t^2}\;\hat\epsilon_\theta(x_t,t) + \sigma_t z,\qquad \hat{x}_0 = \frac{x_t - \sqrt{1-\bar\alpha_t}\,\hat\epsilon_\theta}{\sqrt{\bar\alpha_t}}$$

- $\sigma_t = \sqrt{(1-\bar\alpha_{t-1})/(1-\bar\alpha_t)}\cdot\sqrt{\beta_t}$ 时完全复现 DDPM；
- $\sigma_t = 0$ 时随机项消失——**采样变成确定性映射** $x_T \to x_0$。

**跳步**：确定性意味着轨迹是「一条线」——不必沿原始时间网格走，可以取子序列（如每 4 步取一点，1000 步 → 25 步）。质量损失来自「大步长下 $\hat x_0$ 预测的误差被放大」，实践 20~50 步几乎无损（本站 DDIM 演示实测 25 步追平 100 步 DDPM）。

---

## 二、确定性带来的三个红利

1. **seed 可复现**：同一 $x_T$ 必得同一图——编辑工作流（改 prompt 重跑）的前提；
2. **隐空间插值/编辑**：在 $x_T$ 空间或 $\hat x_0$ 空间插值，结果平滑可控（随机采样时每次都是新随机路径）；
3. **反演（DDIM inversion）**：把真实图沿确定性轨迹**正向推回噪声**，再从那里改条件生成——图生图编辑（prompt-to-prompt 类方法）的技术底座。

## 三、后续加速谱系

| 方法 | 思路 | 步数 |
|---|---|---|
| DDIM | 非马尔可夫 + 跳步 | 20~50 |
| DPM-Solver | 把采样视为解概率流 ODE，高阶数值解 | 10~20 |
| 渐进蒸馏 | 学生学教师的「两步并一步」 | 4~8 |
| **一致性模型** | 约束轨迹上任意点一步映射回 x₀ | 1~4 |
| LCM / SD-Turbo | 一致性蒸馏落到 SD | 1~4 |

一句话主线：**从「沿着训练时的链走」到「解 ODE」再到「直接学端到端映射」**——每一步都把「采样路径」这个自由度用得更彻底。

## 三·五、DDIM 反演的数学与编辑管线

反演（inversion）是把真实图 $x_0$ 沿确定性 ODE **正向推回噪声** $x_T$：DDIM 的更新可逆（σ=0 时每步是双射）——反向积分即可：

$$x_{t+1} = \sqrt{\bar\alpha_{t+1}}\;\hat{x}_0(x_t) + \sqrt{1-\bar\alpha_{t+1}}\;\hat\epsilon(x_t)$$

反演误差的两个来源：**积分步数**（大步长的离散误差）与**CFG 的非可逆性**（s>1 时正向不是严格双射——反演要用 s=1）。误差在编辑管线里被复利放大：真实图 → 反演 → 换 prompt → 生成，链条越长越「不像原图」。

**编辑管线的完整账**：prompt-to-prompt（交叉注意力图替换：结构注意力来自反演、内容注意力来自新 prompt）、instruct-pix2pix（直接学「编辑指令→图像差分」免反演）、与 ControlNet 组合（反演保结构 + 控制保构图）——**编辑质量 = 反演精度 × 条件强度** 的权衡。

## 四、要点总结

1. **DDIM 为什么能跳步？** 确定性轨迹（σ=0）是一条连续曲线，不必逐格走；训练目标只约束边缘分布，允许换采样路径。
2. **σ 参数的两种极端？** σ 按后验=DDPM（随机）；σ=0=DDIM（确定）——一个公式统一两族采样器。
3. **DDIM 的三个工程红利？** 可复现、隐空间插值/编辑、DDIM 反演。
4. **跳步太少的代价？** 大步长放大 $\hat x_0$ 预测误差——细节丢失、伪影；经验下限 ~10 步。
5. **DDIM 反演是什么？** 沿确定性轨迹正向把图推回噪声，用于图生图编辑——反演误差是编辑保真度的瓶颈。
6. **与 DPM-Solver 的关系？** 同为「改采样不改模型」；DPM-Solver 把问题形式化为 ODE 数值积分，高阶方法收敛更快。
