# 正则化与归一化深读：L1/L2 的几何与 BN 的真面目

这篇是**正则化与归一化**主题的深度补充。L1/L2/ Dropout/BN 常被混为一谈，其实它们治的病不同：**L1/L2 治参数过大，Dropout 治共适应，BN 治的是损失面崎岖**。这篇用几何和贝叶斯两个视角讲透 L1/L2，再拆 BN 的「官方故事」与「真实原因」。

> [!KEY] 一句话抓住本质
> L2 是「圆等高线碰球」——收缩所有权重但几乎不产生精确零；L1 是「菱形等高线碰球」——尖角常落在坐标轴上，**整维权重被压成 0**（稀疏）。贝叶斯视角下两者不过是先验不同：L2↔高斯先验，L1↔拉普拉斯先验。BN 则是把每层输入拉回稳定分布，让损失面更平滑、可用大学习率。

---

## 一、L2 / L1：几何与贝叶斯双视角

约束形式：$\min L(\theta) + \lambda\lVert\theta\rVert_p^p$（p=1 或 2）。几何视角：损失等高线与正则「球」的切点即解：

- **L2（圆）**：切点几乎总在**一般位置**——所有权重一起缩小，没有谁归零；
- **L1（菱形）**：菱形的**尖角在坐标轴上**，等高线很容易撞到角——对应「某些权重恰为 0」，模型自动做特征选择。

贝叶斯视角（最大后验 MAP）：

$$\max_\theta \log P(\theta|D) = \log P(D|\theta) + \log P(\theta)$$

- 高斯先验 $P(\theta)\propto e^{-\theta^2/2\sigma^2}$ → 惩罚 $\theta^2$（L2）；
- 拉普拉斯先验 $\propto e^{-|\theta|/b}$ → 惩罚 $|\theta|$（L1）。

一句话：**正则化 = 先验**；λ 越大先验越强（越信「权重应该小」）。

**权重衰减的细节**：实现上「L2 加进损失」与「每步 θ←θ−ηλθ（衰减）」在 SGD 下等价，在 **Adam 下不等价**（L2 会被自适应缩放）——所以有 AdamW（见优化器深读）。

## 二、Dropout：训练时随机关闭神经元

每步以概率 p 丢弃神经元（相当于从指数多个子网络中随机采样一个训练），测试时不丢、权重按 (1−p) 缩放（或训练时 Inverted Dropout 预先放大）。效果：

- **打破共适应**：任何神经元不能依赖特定伙伴的存在，必须学到独立有用的特征；
- **隐式集成**：不同 dropout 掩码 = 不同子网络，测试近似平均（与 bagging 的亲缘）。

现代注意：Transformer 全连接层/注意力上的 dropout 仍在用；**配 BN 时要小心**（方差失配），且大模型趋势是少用或不用 dropout、靠数据量与增广正则。

## 三、BatchNorm：官方故事与真面目

**官方故事（2015）**：缓解「内部协变量偏移」（前层参数变 → 本层输入分布变）。

**后续研究（Santurkar 2018）**：把 BN 换成「故意注入错误分布扰动」效果不掉——**协变量偏移不是关键**。BN 真正做的是**平滑损失面**：把每层输入分布重新中心化/定标，让损失对参数的 Lipschitz 常数变小 → 可用更大学习率、对初始化更宽容、收敛显著加快。

训练/测试行为差异：训练用 batch 统计（引入轻微噪声——附带正则），测试用移动平均统计——**这就是 BN 在小 batch 下崩的原因**（统计噪声太大），也是 GroupNorm/LayerNorm 存在的理由。

**归一化家族一张表**（对谁归一）：

| | 统计范围 | 适用 |
|---|---|---|
| BatchNorm | 同通道跨 batch | CV 大 batch |
| **LayerNorm** | 同样本所有特征 | **Transformer/NLP**（batch 无关） |
| InstanceNorm | 同样本单通道 | 风格迁移 |
| GroupNorm | 同样本通道分组 | 小 batch CV（检测/分割） |

Transformer 用 LN 的原因一句话：序列任务的 batch 语义弱、长度不定，按「样本内」归一化与 batch 解耦；且 Pre-LN（见 Transformer 深读）对深模型稳定性更好。

## 常见误区

- **「L1 正则化总能产生稀疏解」** —— L1 在**强相关特征组**中倾向于随机选择其中一个（不稳定）；弹性网（L1+L2）通过混合惩罚稳定特征选择——L1 的稀疏性不是绝对的。
- **「岭回归的 λ 越大越好（越不容易过拟合）」** —— λ 过大导致所有系数趋近于零（欠拟合）；λ 通过交叉验证选择——正则化强度是偏差-方差权衡，不是单调关系。
- **「正则化只防止过拟合」** —— 正则化还有其他作用：改善数值稳定性（岭回归解决共线性）、编码先验知识（贝叶斯视角）、改善模型可解释性（L1 特征选择）。
- **「训练误差和测试误差的 gap 就是过拟合程度」** —— gap 大可能因为验证集太小/分布不同；过拟合的严格判定需要**学习曲线**（训练/验证误差随数据量增加的趋势）。

## 五、归一化的现代变体与选择

| 归一化 | 统计范围 | 适用场景 | 一句话 |
|---|---|---|---|
| **BatchNorm** | 同通道跨 batch | CV 大 batch | 标配但依赖 batch |
| **LayerNorm** | 同样本所有通道 | Transformer/NLP | 不依赖 batch 大小 |
| **InstanceNorm** | 同样本单通道 | 风格迁移 | 去除样本特定的对比度 |
| **GroupNorm** | 同样本通道分组 | 小 batch CV | BN 的替代 |
| **RMSNorm** | 只做缩放不做中心化 | LLM（LLaMA/Gemma） | 简化版 LN，更快 |

**选择口诀**：batch 大 → BN；Transformer/NLP → LN；小 batch CV → GN；风格化 → IN；LLM 推理 → RMSNorm。

## 六、Dropout 的现代替代品

| 方法 | 思想 | 适用 |
|---|---|---|
| **Dropout** | 随机置零 + 缩放 | MLP/注意力权重 |
| **DropPath** | 随机跳过整个残差分支 | 有残差结构的网络 |
| **Stochastic Depth** | 随机跳过整层 | 深层网络（训练加速+正则化） |
| **DropBlock** | 随机丢弃连续区域 | CNN（空间相关性的正则化） |
| **Token Dropping** | 随机丢弃部分 token | ViT（训练加速+正则化） |

**趋势**：大模型（LLM/扩散）逐渐减少 dropout 依赖——靠数据规模、更好的架构与标签平滑来正则化。

## 四、要点总结

1. **L1 为什么稀疏、L2 为什么不？** L1 菱形尖角在坐标轴上，切点常为整维零；L2 圆滑，只能整体收缩。
2. **正则化与贝叶斯先验的关系？** MAP 框架下 L2↔高斯先验、L1↔拉普拉斯先验；λ 平衡似然与先验。
3. **Dropout 的两个作用？** 打破神经元共适应 + 隐式子网络集成；测试时缩放补偿。
4. **BN 为什么有效（最新解释）？** 不是消除协变量偏移，而是平滑损失面 → 大学习率、快收敛、初始化宽容。
5. **BN 为什么小 batch 崩、Transformer 用 LN？** BN 依赖 batch 统计，batch 小噪声大；LN 按样本归一与 batch 解耦、适配变长序列。
6. **权重衰减与 L2 什么时候不等价？** 自适应优化器（Adam）里 L2 会被缩放，衰减应解耦（AdamW）。
