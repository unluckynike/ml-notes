# LSTM 深读：四个门的公式在救什么

这篇是 **LSTM 长短期记忆网络**主题的深度补充。LSTM 的公式群常被当成黑盒背诵，这里把**四个门逐一拆开**，并用 RNN 深读里的梯度链分析，说清「细胞状态这条传送带」到底解决了什么。

> [!KEY] 一句话抓住本质
> LSTM 给 RNN 加了一条**加法更新的细胞状态** $c_t$：信息沿 $c$ 流动时梯度只走「乘 forgotten 门」的路，不再穿过 tanh 雅可比连乘——遗忘门接近 1 时梯度几乎无衰减地直达远处。三个门（遗忘/输入/输出）都是**学出来的开关**，决定记什么、写什么、说什么。

---

## 一、公式逐个拆

LSTM 每步接收 $(x_t, h_{t-1}, c_{t-1})$，先算三个门与候选记忆（全部是 sigmoid/tanh，输出在 (0,1) 或 (-1,1)）：

$$f_t = \sigma(W_f\,[h_{t-1}, x_t] + b_f)\quad\text{（遗忘门：旧记忆留多少）}$$

$$i_t = \sigma(W_i\,[h_{t-1}, x_t] + b_i)\quad\text{（输入门：新信息写多少）}$$

$$\tilde{c}_t = \tanh(W_c\,[h_{t-1}, x_t] + b_c)\quad\text{（候选记忆：可能写入的内容）}$$

然后是关键的两行——**细胞状态加法更新**与输出：

$$c_t = f_t ⊙ c_{t-1} + i_t ⊙ \tilde{c}_t$$

$$o_t = \sigma(W_o\,[h_{t-1}, x_t] + b_o),\qquad h_t = o_t ⊙ \tanh(c_t)$$

各设计的用意：

- **$c_t$ 的更新是加法**（不是把 $c$ 喂进 tanh 再循环）——这是与朴素 RNN 的本质区别，梯度分析见下节。
- **$\tanh(c_t)$ 限幅**：$c$ 本身无界增长会数值爆炸，输出前压回 (-1,1)；但 $c$ 的**传递不受限幅影响**。
- **门是逐元素（⊙）的**：向量的每一维有独立的开关——「词性」可以长期记住，「当前主语单复数」可以快速更新，互不干扰。

---

## 二、为什么这解决了梯度消失

对细胞状态求导（沿时间往回一步）：

$$\frac{\partial c_t}{\partial c_{t-1}} = \text{diag}(f_t) + (\text{经由 } i_t,\tilde{c}_t \text{ 的项})$$

主导项是 $\text{diag}(f_t)$——**一个元素在 0~1 的对角阵，不再包含 $W^{\text{T}}$ 的连乘、不再穿 tanh 导数**。当遗忘门学到接近 1，梯度以近似恒等的强度回传几十上百步；需要遗忘时门也可以关到 0。

对照 RNN 的 $\prod_t \text{diag}(\tanh')W_{hh}^{\text{T}}$：LSTM 把「必须衰减」改成了「**由门控制的衰减**」——记忆多久成了可学习参数。这也是「恒等映射让深网络可训」思想的最早成功案例，ResNet 的残差连接是它在视觉里的回响。

> [!TIP] 一个常考细节
> 很多实现把 $b_f$ 初始化为 1（而非 0）：训练初期遗忘门接近全开，梯度畅通，网络先学会「记住」，再慢慢学「遗忘」——这个小技巧对训练稳定性帮助显著。

## 三、GRU：省一个门的等价简化

$$z_t = \sigma(W_z[h_{t-1}, x_t]),\qquad r_t = \sigma(W_r[h_{t-1}, x_t])$$

$$h_t = (1-z_t)⊙h_{t-1} + z_t⊙\tilde{h}_t,\qquad \tilde{h}_t = \tanh(W[r_t⊙h_{t-1}, x_t])$$

GRU 把「遗忘门 + 输入门」合并成单一更新门 $z$（$1-z$ 与 $z$ 硬互补：忘多少写多少绑定），并省去独立的细胞状态与输出门。

| 维度 | LSTM | GRU |
|---|---|---|
| 参数量 | $4h(h+x)$ | $3h(h+x)$（省 25%） |
| 状态 | $c$ 与 $h$ 分离 | 只有 $h$ |
| 遗忘/写入 | 独立控制 | 绑定（$1-z$ 与 $z$） |
| 效果 | 长序列略稳 | 多数任务打平，小数据更快 |

经验：两者差距通常小于调参的波动，选哪个先看工程约束（显存/速度），有极长依赖时略偏 LSTM。

**参数量速算**：4 组变换（f/i/o/c），每组 $(h+x) \times h + h$ → $\approx 4h(h+x)$。面试常考「LSTM 50 万参数，隐层多大」这类反算。

## 四、面试要点速答

1. **LSTM 与 RNN 的本质区别？** 细胞状态**加法更新** + 门控：梯度沿 $c$ 的回传主导项是 $\text{diag}(f_t)$，衰减变成可学习的。
2. **四个门各自的激活与范围？** f/i/o 是 sigmoid (0,1)（比例开关），候选 $\tilde{c}$ 是 tanh (-1,1)（内容）。
3. **为什么 $b_f$ 初始化为 1？** 让早期遗忘门≈全开，梯度畅通，先学记忆后学遗忘。
4. **GRU 省了什么、代价是什么？** 省输出门与独立细胞态（参数 -25%）；代价是遗忘与写入被绑死为互补比例。
5. **LSTM 为什么不能根治而只是缓解？** 门仍输出 (0,1)，超长依赖仍会衰减；且串行结构限制并行——Transformer 用注意力一步直达任意位置。
6. **peephole 是什么？** 让门也看 $c_{t-1}$ 的变体；现代实现（含 PyTorch 默认）多数不用，效果增益有限。
