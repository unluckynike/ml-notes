# 世界模型深读：model-based RL 与表示之争

这篇是**世界模型**主题的深度补充。演示里「想象失真→事故」的因果，对应这个领域最核心的数学问题——**模型误差的复合放大**。这篇讲清 model-based RL 的账、两条表示路线（像素生成 vs 抽象预测）的分歧，以及自动驾驶为什么是这个领域最好的试炼场。

> [!KEY] 一句话抓住本质
> 世界模型 = 学到的环境动力学 $f_\theta(s,a)$，价值在于**把试错从现实搬到想象**（数据效率、零风险）；风险在于 rollout 每步误差复合放大，K 步之后的想象可能是幻觉——「想象多远敢信多远」是全部工程的中心。

---

## 一、model-based RL 的账

| | model-free（DQN/PPO） | model-based（世界模型） |
|---|---|---|
| 数据效率 | 低（样本即全部信息） | **高**（模型可外推、可重放想象） |
| 计算分布 | 训练期交互多 | 训练期大量「脑内 rollout」 |
| 风险 | 收敛慢 | 模型偏差（model bias）：想象里的最优在现实中未必对 |

经典配方 **Dyna**：真实少量交互 → 学模型 → 从模型大量生成想象数据 → 策略同时在真假数据上学习。Dreamer 系列（2019-23）把它做到视觉控制 SOTA：VAE 压缩观测 → RSSM（确定性+随机性混合的状态）→ 想象 rollout 训练 actor-critic——**「在梦里学会走路」**。

**模型误差的复合**：单步误差 ε，K 步 rollout 后误差上界约 Kε（乐观情形）到指数级（误差改变后续分布时）——所以实用系统总是「短 rollout + 高频回到真实观测」（MPC 滚动时域：只执行想象中的第一步，观察真实结果再重新规划）。

---

## 二、表示路线之争：像素 vs 抽象

**路线 A·像素生成**（Sora/Genie 类）：预测下一帧画面。优点：信息无损、可视化、数据就是视频；缺点：算力巨大、大量预算花在与决策无关的细节（叶子晃动）。

**路线 B·抽象状态预测**（JEPA，LeCun 力主）：只预测**与决策相关的抽象特征**（其他车在哪、速度多少），不预测像素。优点：效率高、不被不可预测的细节污染；缺点：表示由任务决定，通用性受限。

自动驾驶的工程答案偏 B：**占用栅格网络（Occupancy Network）**——不分类「这是车还是行人」，直接预测每个 3D 体素「被占用吗 + 速度」——通用障碍物表示，长尾物体（侧翻的卡车、掉落的沙发）不再依赖类别先验。

## 三、自动驾驶栈：世界模型的三份工作

1. **感知**：BEV（鸟瞰）+ 占用网络把多相机融合成统一的 3D 空间表示；
2. **预测**：他车轨迹预测（多模态：可能左转也可能直行，各带概率）；
3. **规划与仿真**：规划器在预测出的未来里做 rollout（演示所展示的）；世界模型同时是**仿真器**——生成罕见危险场景（cut-in、鬼探头）做回归测试，这是「数据闭环」的核心资产。

**端到端之争**：特斯拉 FSD v12+ 把感知-规划压成一个网络（模仿学习为主）；批评者指出端到端缺「可验证的中间表示」——事故归因与安全认证都难。**分栈 vs 端到端**是这个领域 2024 年后的最大路线争论。

## 三·五、Dreamer 的三件套与不确定性规划

Dreamer 系列（model-based RL 的标杆）把世界模型拆成三个组件：

1. **表示**：RSSM——确定性路径（h，像 LSTM 的稳定记忆）+ 随机性路径（z，捕获环境的多模态未来）并行，两路信息融合成状态；
2. **想象中学习 actor-critic**：在学到的模型里 rollout 15~20 步，直接对想象轨迹反传（value 的 λ-回归）——不需要真实环境的一步一个样本；
3. **闭环**：真实少量交互 → 更新模型 → 更新想象 → 执行想象中的最优动作。

**不确定性感知规划**：模型对「没见过的状态」的预测不可靠——两种防御：集成模型（ disagreement 作为内在成本，鼓励模型去搞懂它不确定的区域）、或只在置信区间内规划（保守 fallback 到 model-free 行为）。本站演示的「失真度」旋钮就是这个问题的玩具版：想象不可信时，规划宁可保守。

世界模型与数据闭环在自动驾驶的交汇：影子模式（车队收集模型预测与人类驾驶的分歧样本）→ 筛选高价值场景 → 仿真引擎（世界模型）生成变体 → 回归测试——**数据闭环的质量是端到端驾驶的真正护城河**。


## 四、要点总结

1. **model-based RL 的收益与风险？** 数据效率/零风险试错 vs 模型偏差——rollout 越长想象越像幻觉。
2. **复合误差怎么缓解？** 短 rollout + MPC 滚动执行（只信第一步）、高频真实校正、不确定性感知（不确定处保守）。
3. **Dyna 是什么？** 真实交互学模型→模型生成想象数据→真假数据同训——MBRL 的原型配方。
4. **JEPA 与 Sora 路线的分歧？** 预测抽象特征 vs 生成像素——效率与通用性的取舍。
5. **占用网络为什么重要？** 通用障碍物表示，不依赖类别先验——长尾场景的感知兜底。
6. **端到端驾驶的争论点？** 性能上限 vs 可验证性/可归因——安全认证是分栈路线的护城河。
