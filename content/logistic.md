# 逻辑回归深读：从最大似然到交叉熵

这篇是**逻辑回归**主题的深度补充，也是「监督学习为什么用交叉熵」这一根本问题的答案所在。「逻辑回归为什么不用 MSE」「交叉熵怎么推出来的」是最高频的两个疑问，这篇一次讲透。

> [!KEY] 一句话抓住本质
> 逻辑回归 = 对伯努利分布做最大似然估计，似然取对数后就是**交叉熵损失**；它对线性得分 z 的梯度恰好是 $(\sigma(z) - y)x$——**预测错多少，梯度就有多大**，这正是它训练比 MSE 稳的根源。

---

## 一、模型：用线性得分预测概率

$$P(y=1 \mid x) = \sigma(w^{\text{T}}x + b) = \frac{1}{1 + e^{-(w^{\text{T}}x+b)}}$$

sigmoid 不是拍脑袋选的：它把「对数几率的线性模型」变成概率——

$$\log\frac{P(y=1|x)}{P(y=0|x)} = w^{\text{T}}x + b$$

即**对数几率（log-odds）是线性的**，系数 $w_j$ 的含义是「特征 j 增加一个单位，正类几率乘 $e^{w_j}$」——这是逻辑回归可解释性的来源（风险报告、评分卡的标准建模工具）。

**二十行跑通训练**——注意梯度 $(p - y)\,x$ 的形式：与线性回归的 MSE 梯度同构，没有 sigmoid 导数因子，这正是「交叉熵配 sigmoid」在求导上的优雅：

```python
import numpy as np
rng = np.random.default_rng(0)
X = np.column_stack([np.ones(100), rng.normal(size=(100, 2))])  # 首列=截距
w_true = np.array([0.5, -2., 1.])
y = (X @ w_true > 0).astype(float)              # 由 sigmoid 的决策边界生成标签

w = np.zeros(3)
for _ in range(500):                            # 交叉熵 + 全量梯度下降
    p = 1 / (1 + np.exp(-X @ w))                # sigmoid：线性得分 → 概率
    w -= 0.1 * X.T @ (p - y) / len(y)           # 梯度 = (p − y)·x

print(w.round(2))     # 方向与 w_true 一致但更大：完全可分时 MLE 不收敛，权重沿真方向发散
                      # ——这正是逻辑回归要配正则化（见岭回归/正则化主题）的原因
print(round(np.mean((1 / (1 + np.exp(-X @ w)) > 0.5) == y), 3))  # 训练集准确率
```

## 二、损失从哪来：最大似然而不是拍脑袋

单个样本 $(x, y)$，$y$ 取 0 或 1。伯努利似然：

$$P(y \mid x) = \hat{p}^{\,y}(1-\hat{p})^{\,1-y},\qquad \hat{p} = \sigma(w^{\text{T}}x+b)$$

负对数似然（对全数据集求和）：

$$L = -\sum_i \left[y_i\log\hat{p}_i + (1-y_i)\log(1-\hat{p}_i)\right]$$

这就是**二元交叉熵**。一句话：**交叉熵 = 伯努利/分类分布的负对数似然**。多分类时换成 categorical 分布，得到 softmax + 交叉熵，推导完全平行（见下）。

对 $z = w^{\text{T}}x + b$ 求梯度，用 $\sigma'(z) = \sigma(z)(1-\sigma(z))$，奇迹出现：

$$\frac{\partial L}{\partial w} = \sum_i \left(\sigma(z_i) - y_i\right)x_i$$

**梯度 = 预测误差 × 特征**——和线性回归的 MSE 梯度形式完全一样，但sigmoid 把误差压在 (−1,1)。这个简洁形式也解释了为什么逻辑回归能用 SGD 顺畅训练。

---

## 三、为什么不用 MSE：两个硬理由

设用 $L = \frac{1}{2}(\sigma(z) - y)^2$，对 z 求导：

$$\frac{\partial L}{\partial z} = (\sigma(z)-y)\cdot\sigma(z)(1-\sigma(z))$$

1. **梯度被激活导数杀死**：预测很错时（$\hat p \to 0$ 而 $y=1$），$\sigma(z)\to 0$，梯度 $\to 0$——**越错越学不动**（梯度消失）。交叉熵的梯度 $(\hat p - y)$ 在错得离谱时恰恰最大。
2. **非凸**：MSE 套 sigmoid 后损失面有局部极小；负对数似然关于 $(w,b)$ 是**凸的**——全局最优可保证，这是最大似然路线的另一个红利。

> [!TIP] 一句话总结
> 「交叉熵配 sigmoid/softmax」不是惯例，是**配对好的**：激活函数的对数恰好把链式法则里的导数项抵消掉，梯度只剩「预测 − 真值」。这是神经网络输出层设计的同一条原理。

## 四、工程细节

- **正则化**：L2（默认，对应高斯先验）让权重小而分散；L1 产生稀疏系数（特征筛选）。注意正则项**不作用于截距 b**。
- **类别不平衡**：损失加权（class_weight='balanced'）或事后校准阈值；不要靠欠采样硬砍数据。
- **校准**：逻辑回归**天生良好校准**（最大似然直接拟合概率），这是它相比 SVM/树模型在「要概率不要只排序」场景的王牌。
- **多分类**：softmax 推广——$\hat{p}_c = e^{z_c}/\sum_j e^{z_j}$，损失为 categorical 交叉熵；one-vs-rest 是多分类的另一种展开，系数解释更直接。
- **完全分离**：某超平面能 100% 分开两类时，MLE 无解（权重冲向无穷）——正则化或 Firth 修正解决；sklearn 默认带 L2 所以能收敛，但系数会异常大，要警惕。

```python
# 亲手验证梯度公式：数值梯度 vs 解析梯度
import numpy as np
def loss(w, X, y):
    z = X @ w; p = 1/(1+np.exp(-z))
    return -np.mean(y*np.log(p+1e-12) + (1-y)*np.log(1-p+1e-12))
def grad(w, X, y):
    p = 1/(1+np.exp(-(X @ w)))
    return X.T @ (p - y) / len(y)       # 就是 (σ(z)−y)x 的平均
# np.allclose(grad(...), numerical_grad(...)) → True
```

## 常见误区

- **「逻辑回归输出的是概率所以不需要校准」** —— 逻辑回归在训练分布上天然校准（极大似然估计的一致性），但**分布漂移后校准会退化**；迁移学习/采样修正后的 LR 仍需校准检查。
- **「逻辑回归只能处理线性决策边界」** —— 决策边界在**特征空间**中是线性的——通过特征交叉/多项式特征/样条变换，LR 可以拟合非线性边界（与线性代数深读的「参数线性」呼应）。
- **「正则化系数 C 越小越好（越不容易过拟合）」** —— C 过小导致欠拟合（系数全部压向零）；用交叉验证选 C——不是单调的「越小越安全」。
- **「逻辑回归系数可以直接解释为特征重要性」** —— 系数受特征尺度影响（未标准化时大尺度特征系数偏小）；比较重要性需先标准化或用标准化后的系数/OR 值。

## 五、多分类扩展：Softmax 回归与 OvR

**Softmax 回归（多项逻辑回归）**：K 类时输出 K 组权重，softmax 归一化为概率：

$$P(y=k|x) = \frac{e^{w_k^Tx + b_k}}{\sum_{j=1}^{K} e^{w_j^Tx + b_j}}$$

损失为 categorical cross-entropy = −Σ log p(y=c|x)。**One-vs-Rest（OvR）**替代方案：训练 K 个二分类器（每个类 vs 其余），预测时取最大概率——OvR 更适合「类别不互斥」的场景。

## 六、逻辑回归在工业界的持续统治力

| 场景 | 为什么仍然用 LR |
|---|---|
| 广告 CTR 预估 | 大规模稀疏特征 + FTRL 在线学习 + 可解释 |
| 金融风控评分卡 | 监管要求系数可解释（每点的贡献可追溯到特征） |
| 医疗诊断筛查 | 概率输出天然校准 + 简单可靠 |
| 冷启动推荐 | 少样本稳定 + 在线更新方便 |

**大规模 LR 的工程**：10 亿特征的 CTR 模型——FTRL 算法（Follow The Regularized Leader）实现在线稀疏更新（只更新有值的特征维度）——这是深度学习模型难以匹敌的工程效率。

## 五、要点总结

1. **交叉熵怎么推出来的？** 伯努利似然取负对数；softmax + 交叉熵是 categorical 版本。
2. **为什么不用 MSE？** 预测很错时梯度反而趋零（被 σ' 杀死）+ 损失非凸；交叉熵梯度 $(\hat p − y)$ 误差越大梯度越大且损失凸。
3. **系数怎么解释？** 对数几率的线性系数：$w_j$ 是特征每加一单位、正类几率乘 $e^{w_j}$ 的对数。
4. **逻辑回归为什么要标准化？** 梯度下降收敛速度（不是正确性）；拟牛顿法(LBFGS)对尺度也敏感。
5. **和 SVM 怎么选？** 要概率输出/校准 → 逻辑回归；要最大间隔+核技巧 → SVM；大数据在线学习 → 逻辑回归 SGD。
6. **什么时候逻辑回归会失效？** 特征与对数几率非线性关系（加交互/样条）、完全分离、强共线（系数不稳）。
