# Transformer 深读：注意力为什么长这样

这篇是 **Transformer 注意力**主题的深度补充。上面的「核心思想」标签页讲了直觉（Q·K·V 查表），这里回答更根本的问题：**这套公式是怎么一步步推出来的，为什么每个部件都长成这样**。

> [!KEY] 一句话抓住本质
> 注意力 = **一次可微分的软字典查询**：用 Q 去「问」所有 K，拿到一组相似度权重（softmax 归一化），再按权重把所有 V 加权求和。整个网络里**唯一跨越 token 传播信息的操作**就是它。

---

## 一、注意力要解决什么问题？

Transformer（2017）之前的序列模型是 RNN / LSTM：第 $t$ 步的隐状态依赖第 $t-1$ 步，

$$h_t = f(h_{t-1}, x_t)$$

这个递归结构带来两个硬伤：

| 问题 | 原因 | 后果 |
|---|---|---|
| **长程依赖衰减** | 信息要逐步传递，$x_1$ 影响 $x_{100}$ 需要走 99 步 | 梯度消失/爆炸，远处的词「记不住」 |
| **无法并行** | $h_t$ 必须等 $h_{t-1}$ 算完 | 训练时间随序列长度线性堆叠，GPU 大量算力闲置 |

注意力的思路是一次性**让每个 token 直接看到所有 token**——任意两点的交互路径长度变成 $O(1)$，且整个计算是矩阵乘法，天然可并行。

> [!NOTE] Attention is all you need
> 论文标题不是修辞：原论文把 RNN 完全删掉，只留注意力和逐位置前馈网络，机器翻译质量反超当时所有系统。真正的贡献是证明了**递归不是序列建模的必需品**。

## 二、注意力 = 可微分的软字典查询

### 2.1 从硬查询到软查询

普通字典（Python 的 dict）是**硬查询**：用 key 精确匹配，返回唯一 value。但它不可微、无法训练。

把它「软化」成三步：

1. 每个 token 的向量 $x_i$ 通过三个矩阵投影出三个角色：
   - 查询 $q_i = W_q x_i$——「我想找什么」
   - 键 $k_i = W_k x_i$——「我有什么标签」
   - 值 $v_i = W_v x_i$——「我实际提供的内容」
2. 用查询和所有键算**相似度**：$e_{ij} = q_i \cdot k_j$
3. softmax 归一化成权重，加权求和所有值：

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^{\text{T}}}{\sqrt{d_k}}\right)V$$

为什么要拆成 Q/K/V 三份而不是直接用 $x_i \cdot x_j$？因为「**我如何被别人检索**」和「**我检索别人时看什么**」和「**我真正传出去的内容**」是三件不同的事——一个词作为「被查询对象」的语义（K）和它实际贡献的信息（V）可以不同。给三份自由度，让模型自己学出分工。

### 2.2 为什么除以 $\sqrt{d_k}$

这是必考题，答案是**控制 softmax 进入饱和区**。

设 $q$、$k$ 的每个分量是均值 0、方差 1 的独立随机变量，则点积 $q \cdot k = \sum_{i=1}^{d_k} q_i k_i$ 的方差是 $d_k$。$d_k = 64$ 时点积标准差是 8——softmax 的输入动辄 ±20，梯度几乎为 0（softmax 饱和时梯度 $\propto$ 概率 $\times (1-$ 概率$)$，接近 0 或 1 时都趋近 0）。除以 $\sqrt{d_k}$ 把方差拉回 1，让 softmax 工作在梯度健康的区间。

> [!TIP] 记法
> $\sqrt{d_k}$ 除的不是「随便一个数」，而是**点积的标准差**——本质是方差归一化。记住这个推导，比死记公式稳。

## 三、多头注意力：一组注意力不够

单头注意力是**一次加权平均**——它把所有信息压进一个混合里，无法同时关注「句法依赖」和「指代关系」这类不同类型的关联。

多头做法：把 $d_{\text{model}}$ 切成 $h$ 份，每份 $d_k = d_{\text{model}}/h$，各自独立做注意力再拼接：

$$\text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h)W^O$$

$$\text{head}_i = \text{Attention}(QW_i^Q,\; KW_i^K,\; VW_i^V)$$

关键细节：**总计算量与单头（同维度）几乎相同**——不是把模型变大 $h$ 倍，而是把同一预算切成 $h$ 个「视角」。实验上 $h=8$ 或 $12$ 是常见甜点；头数太多会让每个头维度太小、表达能力不足。

> [!NOTE] 头都在看什么？
> 可视化研究（如 BERTology 系列）发现：有的头盯**相邻位置**，有的盯**句法依存**（主谓一致），有的盯**标点/分隔符**。也有大量冗余头——剪掉一半头性能几乎不掉，这是「头剪枝」方向的基础。

## 四、位置信息：注意力本身不知道顺序

注意力对所有 token 是**对称**的——把句子词序打乱，注意力的输出只是同步换位，模型无法区分「猫追狗」和「狗追猫」。所以必须显式注入位置。

原始方案是固定的正弦位置编码：

$$PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d}}\right),\qquad PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d}}\right)$$

好处：任意偏移 $k$ 的 $PE_{pos+k}$ 都能表示成 $PE_{pos}$ 的**线性函数**（三角恒等式），模型容易学到相对位置关系；且外推到训练没见过的长度也有定义。

后续演化（细节见「位置编码与长上下文」主题）：可学习的绝对位置（BERT/GPT-2）、旋转位置编码 RoPE（现代 LLM 主流，把相对位置编进 Q/K 的旋转角）、ALiBi（直接给注意力分数加线性偏置惩罚）。

## 五、整体架构：注意力的「三明治」

Transformer 层不是只有注意力，每层是：

```
x → 多头注意力 → 残差相加 → LayerNorm → 前馈网络(FFN) → 残差相加 → LayerNorm
```

两个容易忽视的部件：

- **前馈网络 FFN**：两层 MLP，中间维度通常是 $4d_{\text{model}}$，激活从 ReLU → GELU → SwiGLU 演化。**参数量大头在 FFN**（约 2/3），可以理解为「每个 token 独立过一遍的知识加工」，注意力只负责搬运信息。
- **残差连接 + LayerNorm**：深层网络可训练的保障。现代模型几乎都用 **Pre-LN**（归一化放在子层之前，$\text{LN}(x) + \text{Sublayer}(\text{LN}(x))$），因为 Post-LN 在深于 12 层时容易训练不稳定。

> [!WARN] 常见误解
> 「Transformer 没有递归所以没有位置信息错乱问题」——错，恰恰相反：**没有递归才需要额外注入位置**。「注意力层数越多越好」——不加残差和 Pre-LN，深了根本训不动。

## 六、复杂度与工程优化

注意力对序列长度的复杂度是 $O(n^2 d)$——$n$ 个 token 两两算分数。上下文 128K 时注意力矩阵有 $1.6 \times 10^{10}$ 个元素，这是长上下文的核心瓶颈。工程上的主要武器：

| 技术 | 思路 | 效果 |
|---|---|---|
| **KV Cache** | 推理时缓存已算过的 K、V，每生成一个 token 只算新 Q | 生成从 $O(n^2)$ 每步降到 $O(n)$ 每步 |
| **FlashAttention** | 分块计算注意力，不让 $n \times n$ 矩阵离开 SRAM | 精确注意力，显存 $O(n)$，速度数倍 |
| **MQA / GQA** | 多个 Q 头共享一组 KV 头 | KV cache 缩小数倍，长上下文推理的关键 |
| **滑窗 / 稀疏注意力** | 每个 token 只看局部窗口或拓扑子集 | 计算降到近似线性，代价是全局建模变弱 |

> [!TIP] KV cache 为什么只缓存 K/V 不缓存 Q
> 自回归生成时，前文 token 的输出已经确定，它们不再产生新查询；**只有新 token 需要用 Q 去查询全部历史**，而历史被查询的内容就是 K 和 V。这是「推理优化与部署」主题的入口。

## 七、要点总结

1. **为什么要缩放 $\sqrt{d_k}$？** 点积方差随维度线性增长，softmax 会饱和导致梯度消失；除以 $\sqrt{d_k}$ 恢复方差为 1。
2. **Q/K/V 为什么分开？** 查询角色、被检索角色、实际内容三种语义解耦，给模型表达自由度。
3. **多头为什么有效？** 多个表示子空间并行关注不同关系；总维度不变，代价几乎为零。
4. **自注意力与 RNN 的本质区别？** 任意两 token 交互路径 $O(1)$ vs $O(n)$；完全并行 vs 顺序依赖。
5. **注意力复杂度？** $O(n^2 d)$，时间与显存都是平方级；FlashAttention 不改变复杂度，只是把显存压到 $O(n)$ 并大幅加速。
6. **为什么需要位置编码？** 注意力是置换等变的（对称），本身不含顺序信息。
7. **Pre-LN 与 Post-LN 区别？** Pre-LN 把 LN 放子层前，梯度更稳定，深层可训练；Post-LN 理论表达略强但难训。
