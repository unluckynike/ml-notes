# LLM 评测深读：裁判偏差、校准与评测的博弈论

这篇是 **LLM 评测与裁判**主题的深度补充。演示量化了位置/长度偏差，这篇讲全裁判方法论：**成对比较为什么优于打分**、**裁判校准的具体操作**、以及「评测即博弈」下榜单的博弈论问题。

> [!KEY] 一句话抓住本质
> LLM-as-a-Judge 的核心矛盾：**规模化的评测必须自动化，而自动化的裁判是另一个 LLM——带着自己的口味与可被利用的漏洞**。所以评测工程的两条铁律：裁判必须与人类标注校准（κ 一致性），评测协议必须假设被评测方会优化裁判（Goodhart 防御）。

---

## 一、成对比较优于绝对打分：为什么

让裁判给单个回答打 1~10 分的问题：**分数锚点漂移**——同一回答在不同批次/上下文里会被打不同分（LLM 对绝对量表的内部一致性差）；而「A 与 B 谁好」的相对判断稳定得多（人类也一样，这是心理测量学的经典结论）。

**成对协议的标准形态**：

1. 同一问题下两个匿名回答（随机左右顺序）；
2. 裁判输出：胜者 + 理由；
3. 交换顺序再评一次，**两次一致才计入**（位置偏差的对冲）；
4. 聚合成 Elo/Bradley-Terry 排名（Chatbot Arena 用在线 Elo，见其深读的偏好模型同款数学）。

MT-Bench（2023）的校准结果：GPT-4 裁判与人类偏好的一致率约 85%（超过人类评审之间的一致率 ~81%）——**但这个数字有前提**：问题类型（开放对话）、无长尾专业内容、偏差缓解到位。

---

## 二、四大偏差与缓解矩阵

| 偏差 | 表现 | 缓解 |
|---|---|---|
| **位置偏好** | 偏先出现（部分模型偏后） | 交换顺序、两次一致才采纳 |
| **长度偏好** | 长=详尽的错觉，系统性偏爱长回答 | 长度控制（同长度对比）/长度归一 |
| **自我偏好** | 偏自家模型的输出风格 | 裁判与被评模型异源、多裁判 |
| **风格偏好** | 列表体/自信口吻/emoji 加分 | 多维拆分打分、rubric 明确化 |

演示里的「测出胜率失真」公式化：测出胜率 = 真实胜率 ⊕ 位置偏差 ⊕ 长度偏差——偏差强度哪怕只有 10~20%，也足以颠倒 5 个百分点内的真实差距。

---

## 三、裁判校准的具体操作

把裁判当「一个待评估的模型」：

1. **金标集**：300~1000 条人工标注的偏好对（覆盖任务谱系）；
2. **一致性度量**：Cohen κ（校正偶然一致）≥0.6 才可用；分任务类型报告（数学题裁判稳、开放创意弱）；
3. **偏差剖析**：位置/长度/自我偏好的量化（演示的方法），超阈值即触发缓解；
4. **回归监控**：换裁判模型或换被评模型版本时重跑金标集——**裁判本身有版本管理**；
5. **人机分层**：裁判做初筛与大规模回归，抽 5~10% 人工复核校准漂移。

## 四、评测的博弈论：Goodhart 攻防

榜单公开后，被评测方（模型团队）会**针对性优化**——这是理性行为不是丑闻：

- **对裁判的过拟合**：知道裁判爱列表体/爱长回答 → 生成策略迎合（见评测基准深读的 benchmark hacking 同机制）；
- **对提示的过拟合**：评测提示词公开 → 特定措辞的「应试」能力；
- **选择性报告**：只报有利基准——社区对策是**多源评测交叉**（Arena 盲测 + 私有动态基准 + 任务级真实指标）。

**Arena 的博弈设计**值得单独记：题目来自真实用户（无法预先优化）、模型匿名对战（无品牌偏好）、Elo 动态更新（历史战绩衰减）——它是「不可刷榜」的设计范式，代价是噪声大与偏向「讨喜」而非「专业」。

## 常见误区

- **「LLM 裁判是客观中立的」** —— LLM 裁判有系统性偏差：偏好长回答/偏好特定格式/偏爱自己家族模型的输出——需要去偏（如位置交换、多裁判投票）才能用于严肃评测。
- **「基准分数可以跨论文直接比较」** —— 不同论文可能用了不同子集/few-shot 设置/prompt 模板/解析方式——同一基准不同设置的分差可达 10~20 个点——只比较相同设置下的数字。
- **「评测数据集不会被训练数据污染」** —— 大模型训练爬取互联网时可能包含基准题目（含答案）——MMLU/GSM8K 等主流基准的污染已有多篇论文证实——需要使用私有/新生成的评测集做对照验证。
- **「多选题的准确率可以从随机基线直接解读」** —— 选择题存在「选项位置偏差」（偏好 A/C 位置）与「无需理解题目的表面模式匹配」——需要位置置换测试与无题干对照。

## 五、要点总结

1. **为什么成对比较优于绝对打分？** 绝对量表锚点漂移，相对判断稳定——心理测量学同款结论。
2. **四大裁判偏差？** 位置/长度/自我/风格——各有对应缓解（交换/控制/异源/拆分）。
3. **裁判校准的流程？** 金标集 → κ 一致性（≥0.6）→ 偏差剖析 → 版本管理 → 人工抽检。
4. **为什么位置偏差要「交换取平均」？** 单次评估的顺序效应系统性地偏一方；交换后偏差对冲、真实差距保留。
5. **Goodhart 在评测里怎么体现？** 榜单公开→针对性优化裁判口味；对策是多源交叉+动态基准+人类锚点。
6. **Arena 为什么难刷？** 用户现想的问题 + 匿名对战 + Elo 衰减——预优化空间被压缩。
