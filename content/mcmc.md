# MCMC 深读：细致平衡、收敛诊断与 HMC

这篇是**采样与 MCMC**主题的深度补充。MH 的接受公式「为什么长那样」、链「看起来收敛≠真收敛」的诊断、以及 HMC 用梯度加速的直觉——这三块讲清，MCMC 就从「会用」到「会审」。

> [!KEY] 一句话抓住本质
> MCMC 的合法性全部押在一个条件上：**细致平衡** π(x)K(x→x′) = π(x′)K(x′→x)——它保证链的平稳分布恰是目标 π。MH 的接受概率就是「把任意提议修补成满足细致平衡」的最优补丁；诊断与加速的一切技巧，都是在回答「多久才走到平稳」与「怎么走快点」。

---

## 一、细致平衡：一行等式撑起整个方法

马尔可夫链由转移核 K 决定。若存在分布 π 满足：

$$\pi(x)\,K(x \to x') = \pi(x')\,K(x' \to x)$$

则 π 是平稳分布（进入 π 后永远留在 π）。** MH 的构造**：任给一个提议 q(x→x′)，定义接受概率 A，让合成转移 K = q·A 满足细致平衡——解这个方程得：

$$A(x \to x') = \min\left(1,\; \frac{\pi(x')q(x'|x)}{\pi(x)q(x|x')}\right)$$

对称提议（q 两向相等）时退化为纯密度比 π(x′)/π(x)。**这就是那个公式的来历：不是拍脑袋，是细致平衡方程的解。**

**Metroplis 算法二十行**——只要能算目标密度的「比值」，连归一化常数都不需要：

```python
import numpy as np
def metropolis(logp, x0, steps=20000, scale=0.5, seed=0):
    rng = np.random.default_rng(seed)
    x, lp, acc, chain = x0, logp(x0), 0, []
    for i in range(steps):
        prop = x + rng.normal(scale=scale)     # 对称提议 → 接受率只看目标比
        lpp = logp(prop)
        if np.log(rng.random()) < lpp - lp:    # MH 准则：min(1, p(新)/p(旧))
            x, lp = prop, lpp; acc += 1
        chain.append(x)
    return np.array(chain), acc / steps

logp = lambda x: -0.5 * (x - 2)**2              # 目标 N(2,1)，未归一化
chain, rate = metropolis(logp, 0.0)
print(round(chain[1000:].mean(), 2), round(chain[1000:].std(), 2), round(rate, 2))
# ≈2.0 ≈1.0 0.5~0.9：均值与标准差都被链摸了出来
```

## 二、两大病与诊断

**病 1·混合慢**：链在峰间跳跃 rare——双峰分布里步长小时可能几万步不跨谷（演示里橙线轨迹困在单峰即此）。**有效样本量**（ESS）= N / (1 + 2Σρ_k)，ρ_k 是样本自相关——名义 1 万样本、ESS 可能只有 50。

**病 2·初值偏差（burn-in）**：链从远处的初值出发，前期样本不代表 π——常规做法是丢弃前段，但「丢多少」本身难定。

**诊断三件套**（能说出名字就赢一半）：

1. **迹图（trace plot）**：参数随迭代的折线应像「厚毛毯」——有趋势/长程漂移 = 没收敛；
2. **多链 R-hat（Gelman-Rubin）**：多条不同初值的链，链间方差应≈链内方差（R-hat < 1.01 惯例）；
3. **自相关图**：拖长尾巴 = ESS 低，需要更多样本或更好的采样器。

## 三、吉布斯采样：MH 的逐坐标特例

逐坐标提议「从满条件 P(x_j | x_{−j}) 采样」——接受率恒为 1（满条件是精确提议）。实现简单（LDA 的吉布斯正是它，见深读），但**坐标轮流更新的蛇形移动在高维强相关时极慢**——这正是 HMC 登场的痛点。

---

## 四、HMC：借梯度「沿等高线」走

直觉：把分布 π 想成地形，MH 随机游走像「醉酒乱撞」；HMC 给样本一个**动量**，让它像冰球一样沿等高线滑行——每步移动远、依然精确。

机制：引入辅助动量 p，哈密顿动力学

$$H(x, p) = -\log\pi(x) + \frac{\lVert p\rVert^2}{2}$$

交替更新「位置（沿梯度）」与「动量」，走 L 步后 Metropolis 校正（leapfrog 积分的离散误差由接受步兜底）。**它用上了 π 的梯度信息**——同维度下 ESS 高几个数量级，Stan/PyMC 的默认（NUTS 自动调步长与 L）。

代价与边界：梯度可得上才好用；离散参数/严重多峰仍难（ Tempering 系是补救）。

## 五、MCMC vs 变分推断 vs 扩散（有趣的谱系）

| 方法 | 思路 | 偏差/方差 |
|---|---|---|
| MCMC | 随机游走到目标 | 无偏（渐近）、慢 |
| 变分推断（VI） | 简单分布族逼近 | 有偏、快 |
| 朗之万动力学 | 梯度+小噪声的 MCMC | **扩散模型的采样器本质**（见扩散深读） |

扩散模型 = 「朗之万/概率流采样的深度学习化」——MCMC 的思想以新形态统治了生成模型。

## 常见误区

- **「MCMC 样本之间是独立的」** —— MCMC 样本**必然自相关**（相邻样本高度相似）——有效样本量（ESS）远小于名义样本量；需要用 thining 或报告 ESS。
- **「burn-in 之后样本都是独立的」** —— burn-in 只去除初值影响；链内的自相关持续存在——burn-in ≠ 独立采样，仍需考虑自相关修正。
- **「R-hat ≈ 1 就说明收敛了」** —— R-hat 只能检测「明显未收敛」（多链间差异大）；R-hat≈1 不能排除所有链共同卡在同一个局部模式——需要结合多模态诊断（如不同初始化的链）。
- **「MCMC 只用于贝叶斯推断」** —— MCMC 是通用的**高维分布采样**技术——在统计物理（Ising 模型）、计算生物学（序列比对）与生成模型（扩散采样）中都有应用。

## 六、要点总结

1. **细致平衡是什么、为什么重要？** πK=πK 的双向平衡，保证 π 是平稳分布；MH 公式是它的解。
2. **MH 接受率对称提议下是什么？** min(1, π(x′)/π(x))——只用密度比值，归一化常数消掉。
3. **burn-in 与 ESS？** 前期不代表分布的样本要丢；有效样本量按自相关折减，名义样本≠有效样本。
4. **R-hat 诊断什么？** 多链间/内方差比 >1 说明链没混到同一分布——多链是廉价保险。
5. **吉布斯与 MH 的关系？** 逐坐标满条件提议的 MH 特例（接受率恒 1）；强相关维度下移动缓慢。
6. **HMC 为什么快？** 用梯度+动量做远距离提议（沿等高线滑），同维度 ESS 高数量级；NUTS 自动调参。
