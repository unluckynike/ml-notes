# 决策树深读：分裂准则、剪枝与三代算法

这篇是**决策树**主题的深度补充。树是最好解释也最容易被低估的模型——XGBoost 的每一步分裂、随机森林的每个基学习器，用的都是这篇里的公式。把熵、基尼、增益算清楚，集成学习的门槛就矮了一半。

> [!KEY] 一句话抓住本质
> 决策树 = **贪心地选「最能降低标签不纯度」的问题来问**。每次分裂在候选切分里找信息增益（或基尼增益）最大的那个，递归下去；不加以限制就会一直问到每片叶子纯为止——所以**剪枝和深度控制才是树的灵魂**，分裂准则只是入场券。

---

## 一、三种不纯度：熵、基尼、方差

**熵**（ID3/C4.5 用于分类）：度量标签分布的混乱度。

$$H(D) = -\sum_{c} p_c\log_2 p_c$$

二类时：50/50 → 熵=1（最乱）；全纯 → 0。**信息增益** = 分裂前熵 − 分裂后各子集熵的加权平均：

$$\text{Gain}(D, a) = H(D) - \sum_{v}\frac{|D^v|}{|D|}H(D^v)$$

**基尼**（CART 分类树的默认）：从分布里随机抽两个样本类别不同的概率。

$$\text{Gini}(D) = 1 - \sum_{c}p_c^2$$

与熵数值相近、**不用算对数**（快），sklearn 默认。

**方差**（CART 回归树）：叶子的预测就是均值，分裂目标是最大程度降低子集方差（等价于最小化平方误差 SSE）。

> [!NOTE] 增益偏好「多值特征」的坑
> 信息增益偏爱取值多的特征（极端：把「样本编号」当特征，增益最大但完全无泛化）。C4.5 的修补是**增益率** = 增益 / 特征固有熵 $\text{IV}(a) = -\sum_v \frac{|D^v|}{|D|}\log_2\frac{|D^v|}{|D|}$；CART 干脆只用二叉切分，天然规避。

**一次贪心分裂的全部逻辑**——对每个特征的每个候选阈值算不纯度增益、取最大者；整棵树就是这个函数的递归：

```python
import numpy as np

def gini(y):
    p = np.bincount(y) / len(y)
    return 1 - (p ** 2).sum()

def best_split(X, y):
    best = (None, -1.0)
    for j in range(X.shape[1]):                 # 遍历每个特征
        for t in np.unique(X[:, j])[:-1]:       # 候选阈值：相邻取值之间
            L, R = y[X[:, j] <= t], y[X[:, j] > t]
            if len(L) and len(R):
                w = len(L) / len(y)
                gain = gini(y) - w * gini(L) - (1 - w) * gini(R)   # 基尼增益
                if gain > best[1]:
                    best = ((j, t), gain)
    return best

rng = np.random.default_rng(0)
X = rng.normal(size=(60, 2)); y = (X[:, 0] > 0.3).astype(int)
print(best_split(X, y))     # ((0, ≈0.3), gain)：正确找到特征 0 与阈值
```

## 二、三代算法一张表

| | ID3 | C4.5 | CART |
|---|---|---|---|
| 分裂准则 | 信息增益 | 增益率 | 基尼（分类）/ 方差（回归） |
| 树形 | 多叉 | 多叉 | **严格二叉** |
| 连续特征 | 不支持 | 二分找阈值 | 二分找阈值 |
| 缺失值 | 不支持 | 按权重分派 | 支持 surrogate 分裂 |
| 剪枝 | 无 | 悲观剪枝 | 代价复杂度剪枝 |
| 回归 | ✗ | ✗ | ✓ |

sklearn 的 `DecisionTreeClassifier` 是 CART：连续特征在每个节点做「排序后扫最优阈值」的精确贪心（O(n log n) 每特征每节点）。

## 三、剪枝：树真正的正则化

不限制的树 = 把训练集背下来（每叶一个样本，训练误差 0）。两种剪枝：

**预剪枝**（提前停）：`max_depth` / `min_samples_leaf` / `min_samples_split` / `min_impurity_decrease`——简单快，但「目光短浅」：当前增益小不代表子孙分裂后不赚。

**后剪枝**（代价复杂度，CART 的 $\alpha$ 剪枝）：自底向上，最小化

$$C_\alpha(T) = \sum_{\text{叶 } t} \text{SSE}(t) + \alpha\,|T_{\text{leaf}}|$$

$\alpha$ 是「每片叶子的租金」：$\alpha$ 大 → 树短。对一系列 $\alpha$ 生成子树序列，交叉验证选最优——**先长满再回头剪**，效果通常优于预剪枝（sklearn 的 `cost_complexity_pruning_path`）。

> [!TIP] 实战经验
> 单棵树的测试精度很少打过调好的逻辑回归——树的价值在**可解释性**（画出决策路径给业务看）和**当基学习器**（bagging/boosting 用它，方差和偏差各有妙用）。单树追求的是「稳」，集成才追「准」。

## 常见误区

- **「决策树对异常值鲁棒所以不需要清洗数据」** —— 决策树对特征值的异常**不敏感**（分裂基于排序而非绝对值），但**标签噪声**会严重影响分裂质量——特征异常鲁棒 ≠ 标签噪声鲁棒。
- **「基尼系数和信息增益总是选择相同的分裂」** —— 两者在多数情况下一致但在**类别不平衡**时可能选择不同的分裂——基尼偏向多数类、信息增益（熵）对类别分布变化更敏感。
- **「决策树天然处理缺失值所以不需要填补」** —— 取决于实现：sklearn 的决策树**不接受 NaN**（需要预处理）；CART 理论有替代分裂（surrogate splits）但 sklearn 未实现——不能一概而论。
- **「决策树是不稳定的模型所以没有价值」** —— 单棵树确实不稳定（数据微变导致树结构大变）；但这种不稳定性正是 **bagging（随机森林）和 boosting 有效的原因**——不稳定性是集成的必要条件。

## 四、要点总结

1. **熵与基尼的区别？** 都度量不纯度、数值相近；基尼无对数运算更快，是 sklearn 默认；C4.5 用熵。
2. **信息增益为什么偏多值特征？增益率怎么修？** 取值越多子集越纯（增益虚高）；除以特征固有熵惩罚多值，但 C4.5 实际用「先筛增益高的再按增益率选」的启发式防矫枉过正。
3. **预剪枝 vs 后剪枝？** 预剪枝快但短视（可能错过后续增益）；后剪枝（代价复杂度）先长满再自底向上权衡 α|叶| 与误差，通常更准但更慢。
4. **回归树叶子输出什么？** 子集均值；分裂准则是方差减少（SSE 下降）最大。
5. **CART 为什么二叉？** 统一处理连续/类别、规避多值偏好、支持回归；多叉可由连续二叉近似。
6. **决策树对缺失值怎么办？** C4.5 按权重同时走多支；CART 用替代分裂（surrogate）；sklearn 原生不支持（需要预处理）。
