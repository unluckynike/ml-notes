# ResNet 深读：退化现象与恒等映射的数学

这篇是 **ResNet 残差网络**主题的深度补充。残差连接如今是深度学习的「默认地基」（Transformer、扩散 U-Net、几乎所有现代架构），但它的出发点常被讲错——**不是为了解决过拟合，而是解决「深网络训不动」的退化（degradation）**。

> [!KEY] 一句话抓住本质
> 实验发现：普通网络 56 层的**训练误差**反而比 20 层高——这不是过拟合（训练集都不行），是优化问题。ResNet 把层的学习目标从「映射 H(x)」改成「**残差 F(x) = H(x) − x**」，并在前向里保留恒等支路 $y = F(x) + x$：最坏情况 F(x)=0，深网络**至少不比浅网络差**；反向时 $\partial y/\partial x = F'(x) + 1$，梯度有了一条无衰减的回程高速。

---

## 一、退化现象：深为什么反而差

He 等在 2015 年的观察（原文实验，CIFAR-10）：

| 网络 | 训练误差 | 测试误差 |
|---|---|---|
| 20 层普通 CNN | 较低 | 较低 |
| 56 层普通 CNN | **更高** | 更高 |

关键在**训练误差也更高**——排除过拟合（过拟合是训练好、测试差）。也不是梯度消失（当时已用 BN，浅层梯度充足）。结论：**深层普通网络的解空间对 SGD 来说太难走**——理论上 56 层能精确包含 20 层的解（多余层学成恒等即可），但 SGD 很难把一层「推向恒等」，因为普通层的默认行为是乱变换。

> [!NOTE] 一句话记住动机
> 问题不是「容量太大」而是「优化不动」：让「什么都不做」成为一层**容易学到的默认值**，深度就只增不减了。

## 二、残差块：让恒等变成「零成本默认」

$$y = F(x, W) + x$$

- 学的目标是**残差** $F$：若某层无用，把权重推向 0 即 $F \to 0$，该层退化为恒等——**「什么都不做」是权重的原点邻域，SGD 一抬脚就到**；而普通层要表示恒等，权重得组合出单位映射，远不在原点附近。
- 前向有**捷径（shortcut）**：$y = F(x)+x$ 恒成立，信息永远有一条无损通路。
- 反向的梯度：

$$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y}\left(\frac{\partial F}{\partial x} + 1\right)$$

**那个 +1** 是全部魔法的来源：梯度 = 「残差支路的梯度」+「原样传回的梯度」。即使 $F$ 的梯度很小，梯度仍能完整流过该层——这与 LSTM 细胞状态的加法更新（$\text{diag}(f_t)$ 主导项）数学上同构。

**维度不匹配时**（通道数变化/下采样）：$x$ 换成 $W_sx$（1×1 卷积投影）——但实验发现恒等捷径效果最好，投影只在必要处用。

**恒等支路的梯度账**——每层 Jacobian 从「乘 w」变成「乘 1+w」，深度的连乘不再归零：

```python
import numpy as np
def chain_grad(L, residual):
    """普通链每层乘 w；残差链乘 1+w（恒等支路常开）"""
    w = -0.2
    g = 1.0
    for _ in range(L):
        g *= w + (1.0 if residual else 0.0)
    return abs(g)

for L in (10, 40):
    print(L, f"{chain_grad(L, False):.1e}", f"{chain_grad(L, True):.1e}")
# 普通：1e-7 → 1e-28（消失）；残差：0.1 → 1e-4（一路可达）
```

## 三、Bottleneck 与网络全景

ResNet-50/101/152 用「瓶颈块」控制计算量——先 1×1 压维、再 3×3 卷积、再 1×1 升维：

$$x \to \left[1\times1,\; C/4\right] \to \left[3\times3,\; C/4\right] \to \left[1\times1,\; C\right] \to +\,x$$

3×3 卷积在 C/4 维度上做，FLOPs 从 $9C^2$ 降到约 $2C^2 + 2.25C^2/…$——同 FLOPs 下网络可以更深。ResNet-50 有 2560 万参数、38 亿次 FLOPs，2015 年 ImageNet 错误率 3.57%（首超人类）。

**Pre-Act（预激活）变体（2016）**：把 BN/ReLU 放到残差支路**之前**而不是之后——捷径全程纯净（identity 上没有任何非线性/归一化），梯度通路更干净，深达 1000+ 层仍可训练。现代 Transformer 的 Pre-LN 结构正是这个思想。

> [!TIP] 残差家族速览
> - **DenseNet**：捷径从「加下一层」改成「拼接所有前层」——特征复用更狠，参数更省。
> - **Transformer 的残差**：每个子层输出 `x + Sublayer(LN(x))`，同样靠 +1 保梯度。
> - **扩散模型 U-Net**：上下采样之间的跳连是残差思想的「跨距版」——保住高频细节。
> 学会看任何新架构的「梯度有没有高速公路」，是读论文的实用技能。

## 常见误区

- **「残差连接解决了梯度消失所以梯度总是正常的」** —— 残差解决了「深层网络的退化问题」（更深反而更差）并缓解梯度消失，但不消除所有优化困难（如 batch 内不一致与死神经元）。
- **「ResNet 的名字来自『残差学习比直接学习更容易』」** —— 更精确：残差连接让网络可以**选择性地**学习增量修正（恒等映射作为默认），使「更深」从「更差」变为「至少不更差」——解决的是退化不是泛化。
- **「BN 和残差都是解决梯度消失的所以可以互换」** —— BN 解决的是**内部协变量偏移**（每层输入分布变化）与平滑损失面；残差解决的是**梯度高速公路**——机制不同，互补而非互换。
- **「ResNet 的网络深度可以无限增加」** —— 超过 1000 层后仍会出现训练不稳定（需要 carefully tuned 的初始化与归一化）；深度有实际收益递减点——「越深越好」有条件限制。

## 五、ResNet 变体谱系与 DenseNet 的对比

ResNet 开创的「跳连」思想催生了一系列后续架构，核心差异在于**如何组合跳跃信息**：

| 变体 | 跳连方式 | 特点 |
|---|---|---|
| **ResNet** | 加法：y = F(x) + x | 最简、最稳定 |
| **DenseNet** | 拼接：y = [x, F₁(x), F₂(F₁(x)), ...] | 特征复用更强，但内存↑ |
| **ResNeXt** | 分组卷积 + 加法 | 多分支增加宽度 |
| **PreAct ResNet** | BN/ReLU 在残差分支之前 | 梯度更畅通 |
| **Res2Net** | 多尺度组内残差 | 感受野多尺度 |

**DenseNet 的「密集连接」**：每层看到所有前层输出（拼接而非相加）——特征复用最充分（不需要重新学习边缘检测），但内存随层数平方增长（存储所有中间特征图）。CSD/动态路由是缓解方案。

## 六、ResNet 的「集成分解」视角

Veit 等（2016）提出一个颠覆性解读：**ResNet 不是「一个深网络」而是「多个浅网络的隐式集成」**。

数学展开：$y_3 = x + F_1(x) + F_2(x+F_1(x)) + F_3(...)$——展开后可见：ResNet 等价于多个「删除某一层后的子网络」的**集成平均**。

这解释了两个现象：

1. **删除单层不崩溃**：删除一层只是移除了集成中的一个成员——其他成员仍工作（普通网络删层则断路）；
2. **层的顺序可以微调**：集成成员对层顺序不敏感——残差网络对层的微小重排有一定容忍度。

**工程启示**：训练 ResNet 时不需要每一层都「学到独立的知识」（集成成员有冗余）；剪枝时可以基于「该层被集成依赖的程度」而非简单的权重范数。

## 四、要点总结

1. **ResNet 解决的是过拟合吗？** 不是，是**退化**（训练误差也升高）——优化问题；过拟合另有 dropout/增广/正则应对。
2. **为什么学残差比学原映射容易？** 恒等映射是残差支路的「零点邻域」（F=0 即恒等），SGD 易达；普通层表示恒等需要权重组合出单位阵。
3. **捷径如何帮梯度？** $\partial y/\partial x = F'(x)+1$，+1 项让梯度无衰减回传——与 LSTM 细胞状态同构。
4. **bottleneck 为什么省算力？** 1×1 先降维，把昂贵的 3×3 卷积放到 C/4 通道上做。
5. **Pre-Act 与标准块的区别？** BN/ReLU 提前，捷径变成纯恒等，千层可训；等价于 Transformer 的 Pre-LN。
6. **ResNet-18 与 ResNet-50 的块有何不同？** 18/34 用两个 3×3 的基本块；50+ 用 1×1-3×3-1×1 瓶颈块。
