# SVM 深读：间隔、对偶与核技巧

这篇是 **支持向量机 SVM**主题的深度补充。SVM 是机器学习课程里数学最重的经典模型，这一节重点不是「是什么」而是**为什么最优解只依赖支持向量、为什么对偶问题能引出核技巧**。这篇按这两条主线推一遍。

> [!KEY] 一句话抓住本质
> SVM 把分类问题变成几何问题：在所有能分开两类的超平面中，选**离两边样本都最远**的那个。「最大化间隔」配上拉格朗日对偶后，解只由**少数贴在间隔边界上的样本（支持向量）**决定——这既是稀疏性的来源，也是核技巧的入口。

---

## 一、间隔的几何：为什么最大化 $\frac{1}{\lVert w\rVert}$

超平面 $w^{\text{T}}x + b = 0$。可以证明（对任意缩放 $w \to cw, b\to cb$ 平面不变，故可取**规范形式**）：若样本被正确分类，则约束为

$$y_i\,(w^{\text{T}}x_i + b) \ge 1$$

此时**几何间隔**（最近的样本到超平面的距离）为：

$$\gamma = \frac{1}{\lVert w \rVert}$$

最大化间隔 = 最小化 $\lVert w\rVert$，等价于凸二次规划：

$$\min_{w,b}\;\frac{1}{2}\lVert w\rVert^2 \quad \text{s.t.}\quad y_i(w^{\text{T}}x_i + b)\ge 1,\;\; i=1,\ldots,n$$

> [!NOTE] 为什么间隔大 = 泛化好（直觉版）
> 间隔是「分类器对样本扰动的容忍度」。间隔越大，训练集附近存在的大间隔超平面越少，**假设空间的「有效容量」越小**——这是统计学习理论（VC 维下界随间隔放大）给出的泛化保证，比「拟合训练集」深刻一层。

## 二、拉格朗日对偶：为什么非要转对偶

原问题每个约束配一个乘子 $\alpha_i \ge 0$，构造拉格朗日函数：

$$L(w, b, \alpha) = \frac{1}{2}\lVert w\rVert^2 - \sum_{i=1}^{n}\alpha_i\left[y_i(w^{\text{T}}x_i + b) - 1\right]$$

原问题 = $\max_\alpha \min_{w,b} L$。对内层求偏导置零：

$$\frac{\partial L}{\partial w} = 0 \;\Rightarrow\; w = \sum_{i=1}^{n}\alpha_i y_i x_i,\qquad \frac{\partial L}{\partial b} = 0 \;\Rightarrow\; \sum_{i=1}^{n}\alpha_i y_i = 0$$

代回消去 $w, b$，得到**对偶问题**：

$$\max_{\alpha}\;\sum_{i=1}^{n}\alpha_i - \frac{1}{2}\sum_{i=1}^{n}\sum_{j=1}^{n}\alpha_i\alpha_j y_iy_j\, \langle x_i, x_j\rangle \quad \text{s.t.}\;\; \alpha_i \ge 0,\;\; \sum_i \alpha_i y_i = 0$$

两个非平凡的收益：

1. **数据只以内积 $\langle x_i,x_j\rangle$ 出现**——这是核技巧的接口（第四节）。
2. 变量是 $\alpha \in \text{R}^n$ 而不是 $w \in \text{R}^d$，**与特征维度无关**——高维/无限维特征反而好算。

## 三、KKT 条件与支持向量

强对偶成立（凸问题 + Slater 条件）时，最优解满足 KKT 互补条件：

$$\alpha_i\left[y_i(w^{\text{T}}x_i + b) - 1\right] = 0$$

它把样本劈成两半：

- $\alpha_i = 0$：样本离间隔边界还有富余（$y_i(w^{\text{T}}x_i+b) > 1$），**对模型零贡献**。
- $\alpha_i > 0$：必有 $y_i(w^{\text{T}}x_i + b) = 1$——样本**正好压在间隔边界上**，这就是**支持向量**。

于是 $w = \sum_{i\in\text{SV}}\alpha_i y_i x_i$：**最终的分类器只是支持向量的线性组合**。删掉所有非支持向量重新训练，得到的模型一模一样——这是「SVM 解稀疏」的确切含义，也解释了推理为什么快（只需和 SV 做内积）。

> [!TIP] 求解器一瞥
> 实际不直接解 QP，而是 SMO（序列最小优化）：每次只挑两个 $\alpha$ 一起优化（其余冻结），解析解出这两个变量的最优值，反复扫描直到 KKT 违背消失。libsvm/liblinear 都是这一族。

## 四、软间隔：现实数据不可分怎么办

线性不可分（或噪声点会把间隔挤没了）时引入松弛变量 $\xi_i \ge 0$：

$$\min_{w,b,\xi}\;\frac{1}{2}\lVert w\rVert^2 + C\sum_{i=1}^{n}\xi_i \quad \text{s.t.}\quad y_i(w^{\text{T}}x_i+b)\ge 1 - \xi_i$$

对偶形式与硬间隔**几乎一样**，只是 $\alpha$ 多了上界：

$$0 \le \alpha_i \le C$$

$C$ 的读法：**间隔宽度与违反量的汇率**。

| $C$ | 行为 | 风险 |
|---|---|---|
| 大 | 违反代价高 → 间隔窄，努力分开每个点 | 对噪声敏感，过拟合 |
| 小 | 允许违反 → 间隔宽，更平滑 | 欠拟合 |

注意现在支持向量包括三类：边界上的（$0<\alpha<C$）、**越界点**（$\alpha = C$，$\xi > 0$）和恰好落在超平面错侧的。

## 五、核技巧：内积换个地方算

线性 SVM 在原空间分不开时，想法是先映射 $\phi(x)$ 到高维再找超平面。问题：$\phi$ 可能维度极高（无限维）根本显式算不动。

对偶问题里数据**只以内积出现**——只要能直接给出 $\langle \phi(x_i), \phi(x_j)\rangle$，根本不需要写出 $\phi$ 本身。定义核函数：

$$K(x_i, x_j) = \langle \phi(x_i), \phi(x_j)\rangle$$

常用核：

| 核 | 表达式 | 直觉 |
|---|---|---|
| 线性 | $x^{\text{T}}z$ | 原始空间，等价线性 SVM |
| 多项式 | $(x^{\text{T}}z + c)^{d}$ | 交叉特征的高维爆炸 |
| **RBF（高斯）** | $\exp(-\gamma\lVert x - z\rVert^2)$ | 局部相似度，$\gamma$ 大 = 每点影响范围小，接近最近邻 |
| Sigmoid | $\tanh(\kappa\, x^{\text{T}}z + c)$ | 形似神经网络（历史原因） |

合法核的判定（Mercer 条件）简化版：对任意样本集，核矩阵（Gram 矩阵）$K_{ij} = K(x_i,x_j)$ 必须**半正定**。

> [!WARN] 核方法的代价
- **预测是核的线性组合**：每条预测要算「与所有 SV 的核」，SV 一多推理变慢（对比线性模型一次矩阵乘）。
- **$\gamma$ 极敏感**：RBF 的 $\gamma$ 过大 = 每个训练点自成一类，过拟合教科书案例。务必交叉验证调 $(C, \gamma)$。
- **核不能「看见」标签**：用标签构造相似度（比如 target encoding 式的核）是数据泄漏。

## 六、SVM vs 逻辑回归：一张表选型

| 维度 | SVM | 逻辑回归 |
|---|---|---|
| 损失 | 铰链 $\max(0, 1-yf)$ | 对数似然 $\log(1+e^{-yf})$ |
| 解 | 稀疏（只依赖 SV） | 稠密（所有样本都有权重） |
| 概率输出 | 需 Platt 缩放校准 | 天然概率 |
| 大样本 | 对偶规模 $n^2$，吃力 | SGD 友好，线性可扩展 |
| 高维稀疏（文本） | 线性核很快 | 同样好，且可解释 |
| 非线性 | 核技巧成熟 | 需手工特征/神经网络 |

经验法则：**中等规模 + 需要非线性边界 → RBF-SVM；超大规模或需要概率 → 逻辑回归/GBDT；高维稀疏 → 线性核两者皆可**。

## 七、要点总结

1. **为什么叫支持向量？** KKT 互补条件保证 $\alpha_i>0$ 的样本恰在间隔边界上；解与预测都只由它们决定。
2. **为什么要解对偶？** 对偶只依赖内积（引入核）；变量数与特征维度无关；自然带出稀疏性。
3. **$C$ 的作用？** 松弛的罚系数：大 → 窄间隔重拟合，小 → 宽间隔更平滑。
4. **核技巧的本质？** 隐式地在高维空间算内积，避免显式映射；合法性要求 Gram 矩阵半正定。
5. **RBF 的 $\gamma$ 怎么理解？** 高斯宽度：$\gamma$ 越大单个样本影响半径越小、边界越弯曲，越容易过拟合。
6. **SVM 概率输出怎么做？** Platt scaling：对决策值再拟合一个逻辑回归校准。
7. **为什么 SVM 对特征缩放敏感？** 间隔由欧氏距离定义，量纲大的特征会垄断距离；必须先标准化。
