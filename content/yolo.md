# 目标检测深读：两阶段与一阶段、IoU 与 NMS

这篇是**目标检测 YOLO**主题的深度补充。检测 = 「在哪里 + 是什么」，比分类多出「框回归」与「重复框去重」两大件。这篇讲清两大流派的设计哲学差异、IoU/NMS 这两个必考基础件、以及 YOLO 系列演化的主线。

> [!KEY] 一句话抓住本质
> 检测的输出是「一组 (框, 类别, 置信度)」。两阶段（R-CNN 系）：先生成候选框再逐框分类——准但慢；一阶段（YOLO/SSD）：在特征图上**一次前向直接回归**所有框——快但早期精度低。十年演化把两者差距抹平，工程上按延迟需求选型。

---

## 一、检测比分类难在哪

分类：一张图一个标签。检测：**变长输出**——不知道有几个物体、在哪、多大。三大基础件解决三件事：

- **框表示**：$(x, y, w, h)$ 或中心+尺寸；回归目标通常编码为相对锚框/网格的偏移；
- **IoU（交并比）**：两个框的交集/并集，衡量「框得准不准」的通用度量——预测的对齐质量用它评，训练的正负样本用它定（IoU > 阈值算正例），NMS 用它判重复；
- **NMS（非极大值抑制）**：同一物体会被多个框命中，按置信度排序，保留最高的，删掉与它 IoU 超阈值的其余框——去重标准件。

---

## 二、两阶段与一阶段

**两阶段（R-CNN → Fast/Faster R-CNN）**：

1. 第一阶段**提议**：Faster R-CNN 用 RPN（区域提议网络）在特征图上滑 anchor，提出「可能有东西」的候选框（~2000→筛到几百）；
2. 第二阶段**分类+精修**：对每个候选框（RoI Align 抠特征）做类别预测与框回归。

哲学：**先找可疑区域再仔细看**——每个框都有充分计算，定位精细，小物体友好。

**一阶段（YOLO/SSD/RetinaNet）**：把检测当**密集回归**——特征图每个格子直接输出 K 个框的 (类别分数, 坐标偏移)，一次前向全部出。哲学：**万物皆回归，一遍扫完**——速度碾压（实时），但早期痛点是**正负样本极端不平衡**（上万格子只有几十个正例）。

**不平衡的解药·Focal Loss**（RetinaNet, 2017）：

$$FL(p) = -(1-p)^\gamma\log(p)$$

给「已经很对」的简单负样本的损失乘上 $(1-p)^\gamma$ 衰减（γ≈2），让训练聚焦难样本——一阶段精度从此追平两阶段，实时与精度兼得。

## 三、YOLO 演化主线（按思想节点记）

| 版本 | 关键思想 |
|---|---|
| v1 (2016) | 网格直接回归：一个格子固定预测几个框——「You Only Look Once」 |
| v2/v3 | anchor 框 + 多尺度特征图（FPN 思路）检测大小物体 |
| v4/v5 | 工程大杂烩：各种免费涨点技巧（CSP、PAN、Mosaic 增广）+ 部署友好 |
| v8/v11 | **anchor-free 回归**：直接预测中心点+宽高，配合解耦头（分类/回归分开） |
| YOLO-World 等 | 开放词表：接 CLIP 式文本嵌入，检测「没见过的类」 |

-anchor 化是重要节点：anchor 是先验框（聚类数据集得到），anchor-free 则让网络直接预测框本身——省去先验设计，配合 Focal/质量标签（用 IoU 当分类监督）后性能不输。

## 四、评估：mAP

**AP = PR 曲线下面积**（单类），**mAP = 各类 AP 平均**。按 IoU 阈值分档：mAP@0.5（宽松，PASCAL 传统）、mAP@0.5:0.95（COCO 标准，更严）。速度用 FPS / 每图延迟。选型时永远「精度-延迟」一起看——**部署预算（边缘端 30ms vs 服务器 100ms）决定你能用哪一档模型**。

> [!TIP] 实战清单
> - 小物体：高分辨率输入 + 多尺度训练 + FPN；「切图检测」（大图切块分别检再拼回）是工业常见大招；
> - 密集遮挡：Soft-NMS（降权而非删除）、改用集合预测（DETR 路线，用匈牙利匹配免去 NMS）；
> - 类别不平衡：focal / 重采样 / copy-paste 增广。

## 常见误区

- **「YOLO 只能做实时检测（精度不如 Faster R-CNN）」** —— YOLOv8/v9/v10 在 COCO 上的精度已与 Faster R-CNN 持平甚至超越——「快但不准」是 v2/v3 时代的印象。
- **「YOLO 的 anchor-free 设计不需要 anchor」** —— anchor-free 仍然需要**预设的参考点/宽高比范围**（分配策略决定哪个 gt 分给哪个预测格子），只是消除了手工设计的 anchor 框——不是完全「无参考」。
- **「小目标检测只需增加输入分辨率」** —— 提高分辨率有帮助但计算量平方增长；更有效的方法：多尺度特征融合（FPN/PANet）、更小的 stride、copy-paste 增广——分辨率只是手段之一。
- **「mAP@0.5 是衡量检测器的最佳指标」** —— mAP@0.5 对定位精度不敏感（IoU=0.5 太宽松）；COCO 使用 mAP@0.5:0.95（平均多个 IoU 阈值）更严格——选择指标应匹配应用需求。

## 五、要点总结

1. **两阶段 vs 一阶段的本质区别？** 候选框提议与分类是否分离；两阶段准而慢，一阶段快但受正负不平衡之苦（Focal Loss 解决）。
2. **IoU 的定义与用途？** 交/并面积比；用于正样本判定、损失加权（GIoU/DIoU）、NMS 去重、mAP 评估。
3. **NMS 流程？** 按置信度排序 → 保留最高 → 删除与其 IoU>阈值 的框 → 对剩余重复。
4. **anchor 是什么？anchor-free 呢？** 预设的先验框（数据集聚类得到），网络回归相对它的偏移；anchor-free 直接预测中心/宽高，省先验设计。
5. **Focal Loss 治什么？** 密集预测中简单负样本淹没梯度：$(1-p)^\gamma$ 压低易样本权重，聚焦难样本。
6. **DETR 的颠覆点？** 集合预测 + 二分图匹配损失，去掉手工 anchor 与 NMS，端到端可微（代价：训练慢、小物体弱）。
