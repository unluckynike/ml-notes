# 过拟合与偏差方差深读：一行分解与三种药

这篇是**过拟合·偏差方差**主题的深度补充。「过拟合」三个字背后是一行可以推出来的恒等式——**期望误差 = 偏差² + 方差 + 噪声**。理解每一项的含义，就能对着训练曲线开对药方：欠拟合补容量、过拟合补数据/正则、噪声只能接受。

> [!KEY] 一句话抓住本质
> 模型在「不同训练集上重训」的波动叫**方差**，所有训练集平均下来仍系统性的偏差叫**偏差**，数据本身的不可预测叫**噪声**。三者此消彼长：容量升 → 偏差降方差升。过拟合 = 方差主导；欠拟合 = 偏差主导；**药方取决于诊断**。

---

## 一、推导：一行恒等式

对固定测试点 (x,y)，$y = f(x) + \epsilon$（噪声零均值、方差 σ²）。模型预测记 $\hat{f}(x)$（在随机训练集 D 上训练），期望误差：

$$\text{E}\left[(y - \hat{f})^2\right] = \left(f - \text{E}[\hat{f}]\right)^2 + \text{E}\left[(\hat{f} - \text{E}[\hat{f}])^2\right] + \sigma^2$$

三项依次是：**偏差的平方**、**方差**、**噪声**。

证明只需对 $\text{E}[(y-\hat f)^2]$ 加减 $\text{E}[\hat f]$ 展开交叉项（噪声独立均值为零，交叉项消掉）。三项读法：

- **偏差²**：平均模型偏离真值的系统性错误——「模型族不够灵活」；
- **方差**：换个训练集模型变多少——「模型对样本噪声太敏感」；
- **噪声**：$\sigma^2$ 是地板——任何模型不可能低于它（在该损失下）。

---

## 二、诊断：对着两条曲线读数

训练误差 vs 验证误差随**训练量/模型容量**的曲线：

| 曲线形态 | 诊断 | 药方 |
|---|---|---|
| 训练误差高，验证误差≈训练 | **欠拟合（偏差主导）** | 加容量/加特征/训练更久/换模型 |
| 训练误差低，验证误差高 | **过拟合（方差主导）** | 加数据/正则/早停/降容量/增广 |
| 两者都高且差距大 | 数据有问题 | 查泄漏、查分布漂移、查标注 |
| 训练误差比验证还高 | 检查实现 | dropout/BN 只在训练开的正确性、数据增广是否泄漏到验证 |

**学习曲线**（误差 vs 训练集大小）另有一读：验证误差仍随数据量下降 → 「加数据还有肉」；已平 → 瓶颈在偏差或噪声。

## 三、每种药压的是哪一项

| 手段 | 压偏差 | 压方差 |
|---|---|---|
| 更大/更深的模型 | ✓ | ✗（方差更高） |
| 更多数据 | 微 | ✓（最纯粹的方差药） |
| L2/L1 正则 | ✗（略升偏差） | ✓ |
| Dropout / 增广 | ✗ | ✓ |
| 早停 | ✗ | ✓（停在方差起飞前） |
| 集成（bagging/平均） | ✗ | ✓（平均掉方差，见随机森林深读） |
| 特征工程 | ✓ | 视情况 |

> [!NOTE] 偏差方差的现代注脚
> 经典权衡假设「固定模型族扫容量」。现代过参数化网络有两个新现象：**双下降**（测试误差随容量过峰后再次下降）与**插值 regime**（零训练误差也不必然过拟合）——零训练误差 ≠ 记忆化，隐式正则（SGD 偏好平坦解）承担了防过拟合的职责。经典分解仍是诊断的第一工具，但「容量=危险」的直觉要松绑。

## 四、面试要点速答

1. **写出分解并解释三项？** 期望误差=偏差²+方差+σ²；推导对 (y−f̂)² 加减 E[f̂] 展开。
2. **K 近邻的 K 与偏差方差？** K 小 → 灵活 → 低偏差高方差；K 大 → 平滑 → 高偏差低方差。K=1 训练误差恒 0（完美过拟合示例）。
3. **Bagging 为什么降方差？** 独立模型平均方差 /M，相关时剩 ρσ²（随机森林的公式，见其深读）；Bagging 不降偏差。
4. **早停为什么是正则？** 训练时长是容量/复杂度的代理：停在验证误差最低点，阻止模型继续吸收样本噪声。
5. **零训练误差一定过拟合吗？** 不必然：现代过参数化 + 隐式正则下（双下降、插值 regime），零训练误差的模型可以泛化很好。
6. **验证误差比训练误差还低说明什么？** 大概率是训练时开了 dropout/增广/正则而验证没开，或数据划分泄漏——先查实现。
