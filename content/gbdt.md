# GBDT 深读：从「拟合残差」到「拟合负梯度」

这篇是 **GBDT 梯度提升**主题的深度补充。XGBoost 深读推了二阶泰勒与叶子闭式解，这篇回到 Friedman 的原始形态，讲清一个概念跨越：**为什么「逐棵拟合残差」能推广成「逐棵拟合任意损失的负梯度」**——这一步把 boosting 从「回归平方损失专用」解放成「任意可导损失的通用机器」。

> [!KEY] 一句话抓住本质
> 提升法是函数空间的梯度下降：当前模型 $F_{t-1}$ 不够好，损失在它处的**负梯度方向**（对每个样本）就是「下一步该补的东西」——用一棵回归树去拟合这份「伪残差」，再加进来。平方损失下伪残差恰是普通残差 $(y - \hat{y})$——所以「拟合残差」只是通用算法的特例。

---

## 一、从残差到负梯度：一次视角升级

加法模型 $F_t(x) = F_{t-1}(x) + \rho h_t(x)$。想最小化 $\sum_i L(y_i, F_t(x_i))$。

**平方损失情形（直觉版）**：代入展开，$h_t$ 该拟合的目标只剩 $(y_i - F_{t-1}(x_i))$——普通残差。这就是最早的「残差拟合」直觉。

**通用情形（Friedman 1999）**：把 $L$ 在当前预测处一阶展开，对**每个样本的预测值**求负梯度：

$$r_i = -\frac{\partial L(y_i, \hat{y}_i)}{\partial \hat{y}_i}\Big|_{\hat{y}=F_{t-1}(x_i)}$$

这组 $r_i$ 叫**伪残差**：它指出「每个样本的预测该往哪边动才能降损失」。用回归树拟合 $r_i$、按线搜索定步长 ρ，就完成一次「函数空间的梯度下降」。

| 损失 | 负梯度（伪残差） |
|---|---|
| 平方 | $y - \hat{y}$（普通残差） |
| 绝对值 | $\text{sign}(y - \hat{y})$ |
| Huber | 近处 $y-\hat{y}$，远处 sign |
| 对数似然（分类） | $y - \hat{p}$（与逻辑回归梯度同形） |

**换损失 = 换负梯度**——对离群点稳健、对分类任务、对排序目标全部一套流程，这是 GBDT 成为「表格数据万能机器」的根基。

## 二、三件防过拟合的标准配置

1. **学习率（shrinkage）**：每棵树乘 ν（0.01~0.1）再加进来——小步多树，给后续树留修正空间（与梯度下降的学习率同构）；
2. **子采样（stochastic）**：每棵树只用一部分样本/特征——把 bagging 的方差收益嫁接到 boosting 上；
3. **树的容量限制**：浅树（3~8 层）是常态——boosting 用「浅树串行」降偏差（对照随机森林「深树并行」降方差，见其深读的分工表）。

## 三、GBDT → XGBoost：一步之遥

Friedman 的原版对「下一步补多少」只做了常数/一阶处理。XGBoost 的贡献是在同一个加法框架里把目标对**新树的输出**做二阶泰勒展开，得到叶子权重闭式解与增益公式（完整推导见 XGBoost 深读）。所以：

> GBDT = 函数空间梯度下降（一阶、统计视角）；XGBoost/LightGBM = 同一框架 + 二阶信息 + 工程化（分裂查找、正则、并行）。

理解了这篇，XGBoost 深读里的 $g_i, h_i$ 就有了出处：它们正是通用损失在当前预测处的一、二阶导数。

## 三·五、负梯度与残差在数值上的直观对比

平方损失下两者重合，换损失立刻分化。以一个离群点（y=100，当前预测 10）为例：

- **平方损失**：伪残差 = 90——离群点几乎绑架这一棵树（树把大部分容量花在拟合它）；
- **绝对损失**：伪残差 = sign(90) = 1——离群点只贡献「方向」，不贡献「幅度」；
- **Huber（δ=20）**：残差 90 > δ → 伪残差 = δ·sign = 20——「方向 + 封顶幅度」。

这就是「GBDT 换损失 = 换性格」的具象化：Huber/绝对损失版的 GBDT 在脏数据上稳得多（与损失函数深读的隐式似然视角一致：绝对损失 ↔ 拉普拉斯噪声假设，重尾）。

**多分类的 Softmax-GBDT**：每类一个树序列（K 组树），每轮 K 棵树分别拟合各自类别的 softmax 负梯度——K 类问题训练成本 ×K（LightGBM 的 multi-softmax）或 one-vs-all 拆分（multi-ova），这也是树模型在超大类别数（如推荐itemid）上让位给嵌入模型的原因之一。

## 四、要点总结

1. **GBDT 为什么每棵树拟合负梯度？** 函数空间梯度下降：负梯度是「预测该移动的方向」；树是非参数的「方向拟函数」。
2. **平方损失下负梯度是什么？** 普通残差——经典「拟合残差」是通用算法的特例。
3. **boosting 降偏差还是降方差？** 串行浅树主要降偏差（逐步修正系统性错误）；子采样能顺带压方差。
4. **shrinkage 的作用？** 缩小每棵树贡献、等价于「更小步长的梯度下降」，需要更多树但更稳、泛化更好。
5. **GBDT 能换损失吗？** 能——换损失只需换负梯度公式（Huber/分类/排序都行），这是相对随机森林的关键柔性。
6. **为什么用回归树做基学习器即使任务是分类？** 树拟合的是连续的伪残差；叶子上再经损失联系函数映到概率/类别。
