# 因果推断深读：相关不是因果的三种修法

这篇是**因果推断**主题的深度补充。「相关 ≠ 因果」人人会背，这篇讲清**为什么观测数据不能直接下因果结论**（混淆结构），以及主流的三种修法——**RCT、匹配/回归调整、双重机器学习**——各自的适用域。

> [!KEY] 一句话抓住本质
> 因果问题无法只靠数据回答，必须有**关于世界结构的假设**。观测数据的相关 = 因果效应 + 混淆路径的贡献；识别因果 = 用假设（图结构/随机化）切断混淆路径。**因果图（DAG）是表达这些假设的语言**，do-算子是「干预」的数学化。

---

## 一、为什么相关不是因果：混淆的结构

冰淇淋销量与溺水人数正相关——不是冰淇淋致溺，是**夏天**同时推高两者（混淆变量）。用 DAG 表达：冰淇淋 ← 夏天 → 溺水。回归里不加「夏天」这个控制变量，冰淇淋系数就带着夏天的贡献。

三种经典的结构陷阱：

1. **混淆（confounding）**：X←Z→Y——**要控制 Z**；
2. **对撞偏差（collider）**：X→Z←Y——**控制 Z 反而制造假相关**（「 conditioning on collider opens path」）：招飞行员只看健康（Z），健康与成绩在入选者里出现负相关——明明无关，一控制就「相关」了；
3. **中介（mediator）**：X→M→Y——控制 M 会**切掉**因果路径（估计的是直接效应），不控制是总效应——**控制变量不是越多越好，要看它在你问的问题里扮演什么角色**。

> [!WARN] 一句话判据
> 「该控制什么」由**因果图**决定，不是由 R² 决定。盲目的「控制一切」会制造对撞偏差；「什么都不控制」会带着混淆。先画图，再选控制集。

## 二、修法一：随机对照实验（RCT）——金标准

随机分配处理 → 处理组与对照组在一切（含混淆变量）上分布相同 → 组间差 = 因果效应（ATE）。A/B 测试就是商业世界的 RCT。

**不行的时候**：伦理（不能随机让人吸烟）、成本、时间（政策效果要等十年）——于是需要观测数据的因果推断。

---

## 三、修法二：条件调整（匹配/加权/回归）

假设「可忽略性」（给定协变量 X，处理分配与潜在结果独立——即 X 已包含全部混淆），三种等价实现：

- **匹配**：给处理组找特征相近的对照组（倾向得分匹配 PSM：用处理概率作单维匹配）；
- **逆概率加权（IPW）**：按 1/P(T=1|X) 加权，造出一个「伪随机化」样本；
- **回归调整**：直接把 X 放进回归（g-computation）。

**共同死穴**：可忽略性**不可检验**——漏了一个混淆变量（隐藏偏差）结论就废。实践靠领域知识反复论证 + 敏感性分析（「要多强的隐藏混淆才能推翻结论」）。

## 四、修法三：双重机器学习（DML）与现代工具箱

高维混淆变量 X 下，传统调整会因「正则化偏差」失真。**DML（Double ML）**的两步框架：

1. 用任意 ML 模型（神经网络/GBDT）分别预测「处理 T」与「结果 Y」关于 X 的残差：
$$\tilde{T} = T - m(X),\qquad \tilde{Y} = Y - e(X)$$
2. 对两个**残差**做简单回归——残差化已经剥掉了 X 的贡献。

命名「双重」：两个预测都要正交化 + 交叉拟合（防过拟合偏差）。**它把「ML 的预测力」与「因果识别的假设」分工**——ML 负责吃掉混淆，因果假设负责识别。工具：econml、DoubleML。

其余主流方法速查：**工具变量 IV**（找一个只通过 T 影响 Y 的外生变量，两阶段最小二乘——假设「排除性」很难满足）；**断点回归 RDD**（录取分数线两侧的准随机比较）；**双重差分 DID**（政策前后×处理对照组的差中之差）。

## 常见误区

- **「控制了足够多的变量就能得到因果」** —— 控制了对撞变量反而**引入**偏差（见正文对撞一节）；控制集合的正确性取决于因果图结构，不是数量。
- **「随机对照实验（RCT）永远可行」** —— 医疗伦理（不能让人吸烟）、可行性（无法随机分配性别）让 RCT 常常不可行——这正是观测性因果推断存在的理由。
- **「因果发现算法能从数据中自动学出因果图」** —— 在经典假设下只能学到**马尔可夫等价类**（一组不可区分的图）；定图仍需领域知识或实验干预。
- **「相关性高 = 因果线索强」** —— 混淆变量可以制造任意高的相关；工具变量的「相关性」要求反而很低（只要不完全为 0）——相关强度与因果证据是两个维度。

## 五、要点总结

1. **为什么观测数据不能直接下因果结论？** 相关=因果+混淆路径贡献；识别需要结构假设。
2. **对撞偏差是什么？为什么「控制一切」危险？** 控制共同结果（collider）会打开混淆路径、制造伪相关——控制集由 DAG 决定。
3. **倾向得分匹配的前提与死穴？** 可忽略性（无隐藏混淆）；不可检验，需敏感性分析兜底。
4. **DML 为什么叫「双重」？** 处理与结果两个 nuisances 都用 ML 残差化 + 交叉拟合——正交化防正则偏差。
5. **A/B 测试为什么是金标准？** 随机化切断一切混淆路径——不需要知道混淆是谁。
6. **中介变量控制与否的差别？** 控制中介=估计直接效应；不控制=总效应——取决于你问什么。
