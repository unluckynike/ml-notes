# 损失函数与信息论深读：交叉熵、KL 与 MLE 的三角关系

这篇是**损失函数与信息论**主题的深度补充。表面上损失函数是一张查表（回归用 MSE、分类用 CE），实际上几乎所有损失都是**最大似然**换皮——「交叉熵 = KL + 熵」的三角关系把 MSE、CE、focal 全部串起来。

> [!KEY] 一句话抓住本质
> 对「模型分布 q 拟合数据分布 p」的最通用的度量是 KL 散度 $\text{KL}(p\|q)$；数据分布的熵是常数，所以**最小化 KL ≡ 最小化交叉熵 H(p,q) ≡ 最大化似然**。换假设分布就换损失：高斯 → MSE，分类分布 → CE，重尾 → Huber。

---

## 一、信息论三件套

**熵**（不确定度）：$H(p) = -\sum p\log p$——分布越均匀熵越大（平均需要多少比特描述）。

**交叉熵**：$H(p, q) = -\sum p\log q$——用「为 q 设计的编码」去传 p 分布的消息，平均要多少比特。

**KL 散度**：$\text{KL}(p\|q) = \sum p\log\frac{p}{q} = H(p,q) - H(p) \ge 0$——编码次优带来的额外开销，衡量两个分布的差。

三角关系：**交叉熵 = 熵 + KL**。数据分布 p 固定时 H(p) 是常数 → 最小化交叉熵等价最小化 KL。损失函数几乎没有例外地落在这条线上。

---

## 二、从假设分布推出损失

**回归 → 高斯似然 → MSE**：假设 $y = f(x) + \epsilon,\ \epsilon \sim N(0, \sigma^2)$，负对数似然：

$$-\log p(y|x) = \frac{(y - \hat{y})^2}{2\sigma^2} + \text{const} \;\Rightarrow\; \text{MSE}$$

推论：MSE 隐含「噪声是高斯、方差恒定」——重尾噪声（离群点）下，平方项把它们的梯度放大到绑架训练，这正是 **Huber**（近处平方、远处线性）存在的理由：把似然假设换成重尾分布。

**分类 → categorical 似然 → CE**：$-\log q(y|x)$，对 one-hot 的 p 求交叉熵就是熟悉的 $-\log \hat{p}_y$（见逻辑回归深读的完整推导）。

**加权与焦点**：

- 类别不平衡 → 按频率反比加权 CE；
- **Focal Loss** = $(1-\hat{p}_y)^{\gamma}\times$CE：把「模型已经很自信且对」的样本损失指数压低，聚焦难样本（检测领域的支柱，见 YOLO 深读）；
- **标签平滑**：目标从 one-hot 改为 [1−ε, ε/K,...]——抑制过度自信、提升校准（与校准主题呼应），本质是给 KL 目标混入均匀分布。

## 三、选损失的工程清单

| 问题形态 | 首选 | 备注 |
|---|---|---|
| 回归·高斯噪声 | MSE | 默认 |
| 回归·有离群点 | Huber / Log-cosh | 梯度有界 |
| 回归·要区间 | 分位数损失 / NLL | 配合共形预测出区间 |
| 分类·平衡 | CE | — |
| 分类·极不平衡 | focal / 加权 CE | 配合 PR 曲线评估 |
| 生成·概率建模 | NLL / ELBO | 见 VAE/扩散深读 |
| 排序 | pairwise/listwise | 优化相对序而非绝对分 |

> [!WARN] 换损失前先想清楚
> 损失决定梯度的形状：MSE 的梯度 $(\hat y - y)$ 随误差线性增长（大错大梯度，但离群点也大梯度）；CE 配 sigmoid 的梯度有界（见逻辑回归深读）；focal 非单调（很自信且对时梯度趋零）。**「指标不可导就用代理损失」**（如 IoU→soft-IoU/Dice）是分割/检测的日常操作。

## 常见误区

- **「交叉熵损失 = KL 散度」** —— 交叉熵 = 熵 + KL 散度；当目标分布 p 固定时最小化交叉熵等价于最小化 KL——「等价」仅在 p 固定时成立，p 变化时两者不同。
- **「损失值越小模型越好」** —— 训练损失小可能对应过拟合（训练集记忆）——用验证集损失/任务指标评估；训练损失是诊断工具而非评估指标。
- **「focal loss 一定优于交叉熵」** —— Focal Loss 通过降低易分类样本权重来聚焦难样本——在类别极度不平衡时有优势，但在平衡数据上可能不如标准 CE 稳定——不是万能替换。
- **「损失函数的选择对最终性能影响不大（模型够大就行）」** —— 损失函数决定了优化的目标方向——错误的损失函数（如回归用 MSE 而目标需要排序）会让大模型学出「精确的错误答案」。

## 四、要点总结

1. **交叉熵、KL、MLE 的关系？** H(p,q)=H(p)+KL(p‖q)；数据固定时 H(p) 为常数 → 最小化 CE ≡ 最小化 KL ≡ 最大化似然。
2. **MSE 隐含什么假设？** 高斯噪声、方差恒定；离群点下平方梯度绑架训练 → Huber。
3. **KL 为什么不对称、为什么非负？** 编码次优的额外开销 ≥0（log 为凹）；不对称因为两个方向的「错配代价」不同。
4. **focal 的 γ 干什么？** $(1-p)^{\gamma}$ 压低易样本权重，聚焦难样本；γ=0 退化为 CE。
5. **标签平滑为什么有用？** 目标不再是极端 0/1，抑制 logit 无限增大，改善过自信与校准。
6. **多任务怎么合损失？** 加权和是默认；量级差异大时用不确定性加权（Kendall）或 GradNorm 动态平衡。
