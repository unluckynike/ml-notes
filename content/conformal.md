# 共形预测深读：覆盖保证为什么成立

这篇是**共形预测**主题的深度补充。上面标签页给了操作三步（分割-校准-取分位数），这篇回答更根本的问题：**为什么 ⌈(1−α)(n+1)⌉ 分位数恰好给出 ≥ 1−α 的覆盖率**——证明只用到「交换性」一个假设，是统计学里少见的「几行算术换一个不依赖分布的保证」。

> [!KEY] 一句话抓住本质
> 新样本的非一致性分数与校准分数**可交换**——它在 n+1 个分数里的「名次」均匀分布在 1..n+1。取校准分数的第 ⌈(1−α)(n+1)⌉ 大值当阈值 q，新分数超过 q 的概率恰好 ≤ α。「P(新分数小于等于 q) ≥ 1−α」就是这么来的，与模型形式、数据分布完全无关。

---

## 一、算法回顾（split conformal）

1. 训练集拟合任意模型 $\hat{f}$；
2. 校准集（n 个，不参与训练）算分数 $s_i = |y_i - \hat{f}(x_i)|$（回归）；
3. $q$ = $s$ 的 $\lceil(1-\alpha)(n+1)\rceil / n$ 经验分位数（升序第 $\lceil(1-\alpha)(n+1)\rceil$ 个）；
4. 新样本区间 $[\hat{f}(x) - q,\; \hat{f}(x) + q]$。

---

## 二、证明：一行名次论证

设新样本 $(x_{n+1}, y_{n+1})$ 与校准集**可交换**（联合分布对重排不变——独立同分布是最常见情形）。新分数 $s_{n+1}$ 与 $s_1 \ldots s_n$ 可交换，所以在 n+1 个分数里，**$s_{n+1}$ 的名次在 1 到 n+1 之间均匀分布**（每个位置概率 $\frac{1}{n+1}$）。

事件「$s_{n+1}$ 是严格最大」的概率 $\le \frac{1}{n+1}$（并列时更小）。推广：

$$P\left(s_{n+1} > \text{第 } \lceil(1-\alpha)(n+1)\rceil \text{ 大的校准分数}\right) \le \frac{n+1 - \lceil(1-\alpha)(n+1)\rceil}{n+1} \le \alpha$$

于是 $P(y_{n+1} \in [\hat{f}(x)\pm q]) \ge 1-\alpha$。证毕——**没有对模型、噪声分布、样本量做任何假设**（有限样本成立，不是渐近结论）。

> [!NOTE] 为什么是 ⌈(1−α)(n+1)⌉ 不是 ⌈(1−α)n⌉
> 那个 +1 就是为新分数自己留的「名次名额」：n+1 个里挑第 k 大，新分数排在它后面的概率是 (n+1−k)/(n+1)。α=0.1、n=50 时 k=⌈45.9⌉=46，违反率 ≤ 5/51 ≈ 9.8% ≤ 10%。少 +1 会把保证悄悄破坏。

## 三、变体：对症下药

| 场景 | 变体 | 思路 |
|---|---|---|
| 异方差数据 | **CQR**（分位数回归共形） | 用分位数回归模型的残差宽度做分数——区间随局部难度伸缩 |
| 分类输出集合 | 预测集（prediction set） | 分数=1−softmax，累加 softmax 直到超过阈值 T——输出「一组候选标签」，大小=难度 |
| 时间序列 | ACI / online conformal | 违反时自动调 α 补偿——交换性破坏后的在线补救 |
| 分布漂移 | weighted conformal | 按新旧分布似然比给校准样本加权 |

**实践清单**：校准集要「像未来数据」（同一来源、同期）；n 别太小（覆盖率方差 ~ 1/√n，n≥100 才稳）；报告覆盖率时用「多次重抽校准集」的区间而非点值。

## 三·五、与贝叶斯不确定性的对比与互补

| | 共形预测 | 贝叶斯后验 |
|---|---|---|
| 保证类型 | 频率派边际覆盖（分布无关、有限样本） | 主观条件分布（依赖先验与似然正确性） |
| 输出 | 区间/集合（无方向） | 完整分布（有形状） |
| 条件性 | 边际保证（平均意义） | 条件化（每个 x 一个分布） |
| 计算成本 | 校准集分位数（几乎免费） | MCMC/VI 训练 |

两者回答的问题不同：「1−α 的次数罩住」（共形）vs「模型认为概率如何分布」（贝叶斯）。**实践组合**：贝叶斯给形状与方向感（哪个区域不确定），共形给硬保证（上报给监管的区间用共形校准过）——医疗诊断类系统常见这种「双层不确定性」。

**CQR 的位置**：标准共形的区间等宽（所有 x 一样宽）；贝叶斯给条件化形状但依赖先验；**CQR（共形化分位数回归）**用分位数模型 + 共形校正——既有条件化的宽度自适应，又保住分布无关的覆盖保证——是工程上的最优折中（Romano 2019）。

## 常见误区

- **「共形预测给出的是「这个样本有 95% 概率正确」」** —— 保证是**边际的**（对所有样本平均 ≥95% 覆盖），不是条件于单样本的；特定难样本的覆盖率可以远低于 95%。
- **「共形预测不需要任何数据划分假设」** —— 需要「可交换性」（数据 i.i.d. 的弱化版）；分布漂移会破坏保证——时间序列需要专门的变体。
- **「区间越窄模型越好」** —— 区间宽度与覆盖率是跷跷板；比较模型应固定覆盖率看宽度（或反之），不能只看单一指标。
- **「共形预测只能用于分类/回归的点预测」** —— 框架可扩展到任何「有非一致性分数的任务」：异常检测、分布偏移检测、时间序列区间、甚至 LLM 的候选集过滤。

## 四、要点总结

1. **交换性是什么、为什么是唯一假设？** 联合分布对重排不变（i.i.d. 是特例）；名次均匀性只依赖它。时间相关、训练/部署分布漂移都会破坏它。
2. **+1 的作用？** 给新分数自己留名次名额，保证有限样本下违反率 ≤ α。
3. **覆盖率 1−α 是对谁的保证？** 边际（marginal）保证——对随机抽的新样本平均成立，不保证每个 x 的条件覆盖（那需要更强的方法且与黑盒模型冲突）。
4. **CQR 解决什么？** 标准版区间等宽；CQR 用分位数模型让宽度随局部方差自适应。
5. **分类怎么用？** 输出预测集：softmax 累计到阈值，集合大小反映模型不确定性（大集合=模型拿不准）。
6. **和贝叶斯不确定性的区别？** 共形是频率派的分布无关保证（不依赖先验正确）；贝叶斯给出条件化的主观分布但受模型设定影响。两者可叠加使用。
