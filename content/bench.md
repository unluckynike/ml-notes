# 评测基准深读：基准的生命周期与污染检测实务

这篇是**评测基准与数据污染**主题的深度补充。上面标签页给了污染的数学（虚高 = c·(1−p₀)·m），这篇讲清**一个基准的完整生命周期**（发布-刷榜-饱和-退役）、**污染检测的具体操作**，以及「动态基准」的设计原则。

> [!KEY] 一句话抓住本质
> 基准是一种**公共品**：发布之日就在贬值（爬虫语料吸收考题）——「刷榜-饱和-失效」是所有公开基准的宿命循环。对抗这个循环的方法论只有两条腿：**检测污染**（把已被泄题的部分剔除/加权）与**更新题目**（私有、动态、改写）。

---

## 一、基准的生命周期

```
设计（覆盖能力面、防泄漏）
  → 发布（成为社区通用语）
  → 刷榜（模型针对性优化 / 语料吸收考题）
  → 饱和（分数挤在 90%+，区分度消失）
  → 复检（私有力学版重考：GSM8K vs GSM1k 式对照）
  → 退役或轮换
```

**MMLU 的命运是教科书**：2019 年区分度极好 → 2024 年头部模型挤在 88%+ 且被污染质疑 → 社区转向 GPQA（研究生级难题）、LiveBench（按月换题）等。**基准的半衰期约 2~4 年**——引用基准时要报「发布年份」，这和引用软件版本一样重要。

---

## 二、污染检测的具体操作

**三层检测从粗到细**：

1. **表面重叠（n-gram）**：基准题与训练语料做 10-gram（或 13-gram）精确匹配/最小编辑距离——能抓「原文照搬」，抓不住改写；实现上就是字符串哈希索引，一晚上能扫完全网语料；
2. **语义重叠（embedding）**：题目与语料的嵌入相似度检索（阈值如 cos > 0.85 人工复核）——抓改写与翻译泄漏；误报率高（模板化题目天然相似）需要人工确认；
3. **行为检测（黑盒）**：
   - **成员推断**：模型对「疑似泄漏题」的困惑度异常低、对改写版骤降——裂口即证据；
   - **改写重考（GSM1k 式）**：换数字/换实体/换场景重建同结构题——若模型在新题上大幅掉分而原题满分，**「会做」是假的**；这是最有说服力的取证；
   - **时间切割**：只用基准发布日期之后的语料训练的模型做对照。

**工程建议**：训练前的语料去污染（n-gram 过滤是标配、开源 pipeline 很多）+ 评测时的改写重考双保险；报告分数时附「去污染策略」声明。

## 三、动态基准的设计原则

- **私有力学版**（held-out twin）：与公开版同分布同结构但保密——随时抽查真水平；
- **定期轮换**：LiveBench 按月用新数据生成题目；题目生成源要**避开**「会被爬的公开内容」（如自造数学题、合成代码任务）；
- **防过拟合设计**：题目生成器保密、答案可程序化验证、采样参数随机化；
- **人类盲测兜底**：Chatbot Arena 式 Elo——不可刷（题目是用户现想的），但噪声大、偏「用户喜好」——与基准互为补充。

## 三·五、污染检测的工程实现（伪代码级）

n-gram 重叠检测的落地实现（10-gram 精确匹配版）：

```python
# 语料侧：把每条文档的 10-gram 集合哈希进布隆过滤器/倒排字典
index = {}
for doc_id, text in corpus:
    grams = {text[i:i+10] for i in range(len(text)-9)}
    for g in grams: index.setdefault(hash(g), set()).add(doc_id)

# 评测侧：对每道考题查重叠
for q in benchmark:
    hits = index.get(hash(q[:10]), set())

```

关键工程量级：百万级文档 × 每文档百个 10-gram → 几亿条目——Python 半天、Rust 几分钟；**语义级检测**（嵌入相似度 > 0.85）再过一遍抓改写，人工复核收敛误报。

**成员推断的黑盒版**：不改模型只看行为——对疑似泄漏题与「改写 twin」分别测困惑度/答案一致率，裂口 >15pp 即判污染（GSM1k 的方法论）。**隐私注意**：成员推断本身是双刃剑——同一技术既能测污染也能测「训练集里有没有某人的数据」（与差分隐私深读的威胁模型呼应）。

## 四、要点总结

1. **污染虚高公式的两个旋钮？** 污染比例 c（数据侧）与记忆强度 m（模型侧）；泛化好的模型污染伤害反而小。
2. **三层检测各自抓什么？** n-gram 抓照搬、嵌入抓改写、行为检测（改写重考）抓「背题 vs 会题」。
3. **GSM1k 的实验设计？** 私有同结构重考：公开榜高分模型在 twin 上掉分幅度即污染程度的下界。
4. **基准饱和后还有什么用？** 无区分度即退役——转用更难的衍生基准或动态基准；分数仍可做「下限证明」。
5. **Arena 式评测的优劣？** 不可刷、贴真实偏好；噪声大、偏口彩、任务分布不代表专业场景。
6. **为什么不干脆全部私有评测？** 公开基准的价值在可复现与社区对齐——私有+公开的组合是现实解。
