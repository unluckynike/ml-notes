# 差分隐私深读：定义、机制与组合定理

这篇是**差分隐私**主题的深度补充。上面标签页给了 Laplace 机制的演示，这篇把理论三件套讲全：**严格定义（为什么 e^ε 是对的形状）**、**两大机制（Laplace/高斯）的推导**、**组合定理（隐私是消耗品的数学）**。

> [!KEY] 一句话抓住本质
> 差分隐私要求：**改变任何一个个体的数据，输出的分布几乎不变**（所有可能输出集合上，概率比 ≤ e^ε）。它不保证「结果看起来没有泄露」，而是保证「**存在反事实：无论你在不在，结果都可能一样**」——攻击者无法区分。这是可证明、与攻击者能力无关的隐私。

---

## 一、定义为什么长这样

$$\text{P}[M(D) \in S] \le e^{\epsilon}\cdot\text{P}[M(D') \in S] + \delta \qquad \forall\, S,\; \forall\, \text{相邻 } D, D'$$

逐块拆解：

- **相邻数据集**（差一个个体）：隐私的单位是「一个人」，不是「一条记录」——用户级 DP 要求把一个人的所有记录视作整体；
- **概率比 ≤ e^ε**：核心承诺。若比值无界，输出分布依赖某个体——攻击者用假设检验就能以高置信推断「他在不在」。**e^ε 上界直接封死所有统计检验的效力**（这就是「可证明」的含义）；
- **δ（松弛）**：高斯机制需要的小豁免（δ 必须远小于 1/n——即「碰运气成功的概率」可忽略）。

**ε 的量级感**：ε=0.1 极强（几乎无信息）、ε=1 强、ε=8 弱（业界常超）；δ 常取 1e-5~1e-7。**隐私预算是政策决定，不是工程决定**。

---

## 二、两大机制

**Laplace 机制**（纯 DP，δ=0）：数值查询 f 加 Laplace(Δf/ε) 噪声。Δf 是**敏感度**——单个体能改变结果的最大幅度（计数=1；求和=最大可能值；中位数敏感度难界——所以 DP 钟情计数类查询）。推导：Laplace 密度比 $\frac{p(x)}{p(x')}\le e^{\Delta f/\epsilon\cdot(\text{查询差})}\le e^{\epsilon}$——噪声尺度与敏感度成正比、与 ε 成反比。

**高斯机制**（(ε,δ)-DP）：加 $N(0, \sigma^2)$，σ 由 (ε,δ) 解析给出。噪声分布更「工程友好」（与 SGD 的加噪自然融合），代价是松 δ。**DP-SGD**（深度学习版）：逐样本梯度**裁剪到范数 C**（把敏感度压到 C）+ 加高斯噪声 + 私有 SGD 的组合定理追踪总预算——训练差分隐私模型的标准配方。

---

## 三、组合定理：隐私是消耗品的会计学

- **串行组合**：依次发布 k 个 (ε₁..ε_k)-DP 结果，总保障是 (Σεᵢ)-DP——**预算累加**；
- **并行组合**：作用在**不相交**的数据子集上的查询，总 ε = max(εᵢ)（不累加）——分桶查询便宜的原因；
- **后处理不变性**：对 DP 输出做任何加工（聚合/训练/可视化）不增加泄露——一次加噪，处处可用。

这三个定理构成「隐私预算会计」：设计整个数据管线时按组合定理记账。实操：**隐私账本**（privacy budget ledger）记录每个分析的消耗，预算耗尽即停——苹果/谷歌的遥测系统都内置了这一机制。

**局部 vs 中心 DP**：中心（数据集中后加噪——信任收集者）vs **局部（LDP，用户端加噪后再上传——不信任任何人）**。RAPPOR/随机响应是 LDP 的经典构造：谷歌键盘/苹果 emoji 统计用的都是 LDP——噪声更大，但连收集者也被防。

## 四、面试要点速答

1. **差分隐私的定义与直觉？** 相邻数据集上输出概率比 ≤ e^ε——「有你没你，结果分布几乎一样」，攻击者的假设检验失效。
2. **敏感度是什么、为什么关键？** 单个体能改变查询结果的最大幅度；噪声尺度=Δf/ε——敏感度小的查询才便宜。
3. **Laplace 与高斯机制的取舍？** 纯 DP（δ=0）vs (ε,δ)-DP；高斯噪声与 SGD 融合自然（DP-SGD 用它）。
4. **串行与并行组合的区别？** 依次查询预算相加；不相交子集上取 max——设计查询结构省预算。
5. **DP-SGD 的三步？** 逐样本梯度裁剪（定敏感度）+ 加噪 + 预算记账（矩会计）。
6. **局部 DP 与中心 DP 的区别？** 加噪发生在用户端（不信任收集者）vs 服务器端——LDP 噪声更大但信任假设最弱。
