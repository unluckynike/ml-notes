# 机制可解释性深读：叠加、SAE 与因果验证

这篇是**机制可解释性**主题的深度补充。演示里「读权重热图」是最古老的可解释性手段，它在真实大模型上失效的原因（**叠加**）、现代的解法（**稀疏自编码器**）、以及「发现特征」与「证明因果」之间的鸿沟——这三件事构成现代 MechInterp 的主线。

> [!KEY] 一句话抓住本质
> 小模型里「一个神经元 ≈ 一个概念」，权重即说明书；大模型里概念数远超神经元数，网络用**叠加**（几个概念共享同一组神经元的非线性组合）硬塞——单神经元解释失效。SAE 用「稀疏编码」把叠加解开：比神经元更多的特征、每个只对单一概念放电。

## 一、权重可视化：为什么在小模型上管用

演示里的现象：训练后隐层神经元的输入权重自发对齐到「竖条/横条/斜条」。条件是**概念数 < 神经元数**——每个概念可以独占一个方向。这时：

- 权重向量 W 行 = 该神经元在输入空间的「感受野」；
- 激活 h = ReLU(W·x + b) 在「概念出现」时放电——权重热图即概念的画像。

CNN 的第一层卷积核可视化（边缘/颜色斑点检测器）是同一原理的图像版——这也是「深度网络先学通用特征」的最直观证据。

## 二、叠加：为什么大模型上失效

Anthropic 的叠加假说：真实世界的概念数（百万级）远超神经元数（万级），网络的选择是——**用近乎正交的高维方向表示远多于维数的概念**，多个概念共用神经元但方向错开：

$$a = \sum_i f_i \, d_i \quad (f_i \text{ 是概念激活，} d_i \text{ 是近乎正交的方向})$$

后果：单个神经元的权重是**多个概念方向的和**——可视化出来是「杂物抽屉」（比如同时响应日语字符与 code fence）。Polysemanticity（多语义性）不是 bug，是容量策略。


**叠加的干扰实验**——把每个特征等强度写进 2 维残差流，读出时必然互相串扰：

```python
import numpy as np
rng = np.random.default_rng(0)
d = 2
for n_feat in (4, 24):
    W = rng.normal(size=(d, n_feat))
    W = W / np.linalg.norm(W, axis=0, keepdims=True)   # 等强度写入
    x = np.zeros(n_feat); x[0] = 1.0
    readout = W.T @ (W @ x)                    # 线性读出
    inter = float(np.abs(np.delete(readout, 0)).max())
    print('特征数', n_feat, '| 信号', round(float(readout[0]), 2), '| 最大串扰', round(inter, 2))
# 串扰与信号同量级——「叠加」是表示容量换串扰的交易，SAE 做的就是解压这个混合
```python
import numpy as np
rng = np.random.default_rng(0)
d_model, n_feat = 2, 5
W = rng.normal(size=(d_model, n_feat)) * np.sqrt(n_feat) * 0.5
x = np.zeros(n_feat); x[0] = 1.0               # 只激活特征 0
r = W @ x
print((W.T @ r).round(3))                      # 特征 0 被读出，其余 4 个也被误读出小值
# 特征数 >> 维度时串扰不可避免——这就是「叠加」：模型宁可互相干扰也要多存特征
```
## 三、SAE：用稀疏性解压叠加

稀疏自编码器的思路：在模型激活上训练一个「过完备 + L1 稀疏」的自编码器——

$$\text{encoder: } f = \text{ReLU}(W_{\text{enc}} a + b),\qquad \text{重建 } \hat{a} = W_{\text{dec}} f$$

特征维度 ≫ 激活维度（如 16 倍），L1 强迫每次只激活少数特征——**每个 SAE 特征趋向单概念**。Anthropic 在 Claude 上跑出的成果：数千万个可命名特征（金门大桥、代码漏洞、谄媚语气），并演示了「人为放大金门大桥特征」的因果干预——特征不只是相关，是可操纵的。

## 四、从「相关」到「因果」：激活修补

可视化与探针只证明「信号存在」，不证明「信号被使用」。**激活修补（activation patching）**提供因果证据：

1. 跑两个输入（干净 vs 对立例）记录激活；
2. 把干净输入运行中的某个组件激活**换成**对立例的；
3. 若输出翻转 → 该组件对行为因果有效；无影响 → 只是路过的相关信号。

电路分析（circuit analysis）= 找出「完成某个行为所需的最小组件集合」。经典成果：Induction Head——两层注意力的组合实现「[A][B]…[A]→预测[B]」的复制算法，且这类头 formation 的时点与 in-context 学习能力的跃升吻合。

## 三·五、稀疏自编码器的训练细节与失效模式

SAE 的训练目标（在激活 a 上）：

$$L = \lVert a - \hat{a}\rVert^2 + \lambda \lVert f \rVert_1$$

三个工程要点：

1. **L1 系数 λ 的跷跷板**：λ 大 → 特征极稀疏但重建差（漏概念）；λ 小 → 特征变回「杂物抽屉」。现代做法是 **TopK 激活**（只保留最大的 k 个特征，硬稀疏替代 L1）——稳定性显著更好；
2. **死特征问题**：初始化 unlucky 的特征永不激活——用「辅助损失」（死特征偶尔接受残差）或定期重置（用死特征去重建当前残差最大的方向）；
3. **特征吸收（feature absorption）**：「以 -ing 结尾的动词」特征可能被「动词」+「-ing」吸收——某些概念无法独立表示，SAE 会把复合概念「吸收」进子概念——这是当前 SAE 结果解读的最大陷阱。

**评估的金标准问题**：「SAE 特征是否因果有效？」——用特征消融/放大（steering）验证：Golden Gate Claude 把「金门大桥」特征放大 10 倍后，模型对任何问题的回答都会往桥上扯——这是「特征→行为」因果链的最强公开演示。

## 常见误区

- **「可视化某一层就理解了整个模型」** —— 单层可视化只展示该层的「特征检测器」；信息在层间的组合与传递（电路）才是行为的完整解释——单层是冰山一角。
- **「可解释性方法给出的解释就是模型的真实逻辑」** —— 解释是**模型行为的近似描述**（post-hoc rationalization 的风险）——不同方法可能给出不一致的解释，需要因果验证。
- **「可解释性越高性能一定越低」** —— 存在 trade-off 但不是线性的：稀疏正则化、注意力正则化等方法可以在几乎不损失性能的前提下提升可解释性。
- **「人类可读的解释 = 人类可用的洞察」** —— 一个准确的解释如果过于复杂（如 1000 个电路交互）对人类没有可操作性——「忠实性」与「可理解性」是两个正交维度。

## 五、要点总结

1. **权重可视化何时失效、为什么？** 概念数 > 神经元数时叠加发生——单神经元混多概念，热图成杂物抽屉。
2. **SAE 的两个关键设计？** 过完备（特征数≫激活维）+ L1 稀疏——把叠加「解压」成单概念特征。
3. **激活修补证明什么？** 因果性：换入/换出某组件激活导致输出翻转，才是「被使用」而非「路过」。
4. **Induction Head 为什么重要？** 第一个完整的 Transformer 电路 + 与 ICL 能力涌现的时间相关。
5. **可解释性对安全的价值与边界？** 审计欺骗/后门的白盒证据；但发现的特征需因果验证，且覆盖率远未完整。
6. **探针（probing）的陷阱？** 探针自己可能「学到」分类而非「读出」信息——需要控制探针容量与对照任务。
