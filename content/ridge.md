# 岭回归与 Lasso 深读：从共线救火到稀疏选择

这篇是**岭回归·Lasso**主题的深度补充。两个「带罚的线性回归」看似只差一个平方，性质却分道扬镳：**岭把共线特征拧在一起用，Lasso 直接把弱特征踢出局**。这篇从闭式解、几何、贝叶斯三个视角讲透这个分岔。

> [!KEY] 一句话抓住本质
> 岭回归 $\hat\beta = (X^{\text{T}}X + \lambda I)^{-1}X^{\text{T}}y$：加一个 λI 让病态矩阵起死回生、所有权重集体收缩；Lasso 的 L1 罚则制造**精确的零**——从「救共线」到「做选择」，一线之隔。

---

## 一、岭回归：λI 的三重身份

$$\hat{\beta}_{ridge} = (X^{\text{T}}X + \lambda I)^{-1}X^{\text{T}}y$$

1. **数值救火**：$X^{\text{T}}X$ 共线时接近奇异（条件数爆炸），加 λI 把所有特征值平移 λ——矩阵正定、求逆稳定。这就是「岭」的名字（对角线像山脊抬高了谷底）。
2. **连续收缩**：λ 从 0 → ∞，系数从 OLS 平滑缩到 0——**没有任何系数会精确为零**（圆等高线碰球，见正则化深读）。共线特征组的系数被「摊平」使用，预测更稳、解释时别单独看系数。
3. **贝叶斯/主成分视角**：岭 = 给系数加高斯先验的 MAP；也可以证明岭回归等价于**对主成分做软收缩**——方差小的方向被压得更狠（小特征值方向 +λ 的相对惩罚最大），这是它对付共线的本质。

**选 λ**：交叉验证扫对数网格（0.001~100）；岭的解关于 λ 连续，CV 曲线平滑好选。

**岭解与有效自由度**——df(λ) = Σ d_j²/(d_j²+λ)，从 p 连续滑向 1：

```python
import numpy as np
rng = np.random.default_rng(0)
X = np.column_stack([np.ones(50), rng.normal(size=(50, 4))])
w_true = np.array([1., 2., 0., 0., -1.])
y = X @ w_true + rng.normal(scale=0.3, size=50)
for lam in (0.0, 1.0, 10.0, 100.0):
    b = np.linalg.solve(X.T @ X + lam * np.eye(5), X.T @ y)   # 岭解闭式
    d = np.linalg.svd(X, compute_uv=False)
    df = float((d**2 / (d**2 + lam)).sum())
    print(lam, b.round(2), 'df =', round(df, 2))
# λ=0 时 df=5（全参数）；λ→∞ 时 df→1（只剩截距方向）——正则化是「参数量的连续旋钮」
```

## 二、Lasso：稀疏与选择

$$\min \lVert y - X\beta\rVert^2 + \lambda\lVert\beta\rVert_1$$

没有闭式解（|β| 不可导处即稀疏点），用坐标下降/近端梯度求解。几何（正则化深读已画）：菱形尖角在坐标轴 → 切点常为整维零 → **自动特征选择 + 可解释模型**。

**Lasso 的坑**：

- **共线时的任性**：强共线特征组里 Lasso 只随机挑一个（谁先入模谁活），换数据就换人——要稳定选择用**弹性网**（L1+L2 混合：L2 先把组拧紧、L1 再整组收缩/剔除）；
- **p >> n 时最多选 n 个**特征（理论限制）——高维小样本用弹性网或 group lasso；
- **λ 的选择对「选择结果」敏感**：报告选中特征时要说明 λ 怎么来的（CV/稳定性选择）。

**岭 vs Lasso 决策树**：要预测精度、特征有共线 → 岭；要做选择/要可解释 → Lasso；两者都要/高维 → 弹性网；不确定 → 弹性网（α 也当超参调）。

## 三、把它们放回统计家族

| 视角 | 岭回归 | Lasso |
|---|---|---|
| 罚 | $\lambda\lVert\beta\rVert_2^2$ | $\lambda\lVert\beta\rVert_1$ |
| 贝叶斯先验 | 高斯 | 拉普拉斯 |
| 解 | 闭式、连续收缩 | 迭代、精确稀疏 |
| 共线行为 | 摊平共担 | 随机独宠一个 |
| 对尺度敏感 | 是（先标准化！） | 是（先标准化！） |

> [!WARN] 必须标准化
> 罚项对各系数一视同仁——量纲大的特征（收入以元计）会被不公平地重罚。**先 z-score 再正则**，系数才可比；sklearn 的 Pipeline(StandardScaler, Ridge) 是标准姿势。

## 三·五、自由度 df(λ) 与正则化的「有效参数量」

岭回归的有效自由度有一个精确公式（ESL §3.4）：

$$\text{df}(\lambda) = \sum_{j=1}^{p} \frac{d_j^2}{d_j^2 + \lambda}$$

$d_j$ 是 $X$ 的奇异值——λ=0 时 df=p（全参数自由），λ→∞ 时 df→0（什么都不学）。**λ 在「每个方向上按奇异值比例分配收缩」**：小奇异值方向（共线/噪声）被压得狠，大奇异值方向几乎不动——这就是「岭 = 主成分软收缩」的另一面。

Lasso 没有闭式自由度，但可以数非零系数（df 取「非零系数个数」，是自由度的无偏估计）——**AIC/BIC 用 df 比较「不同 λ 的模型」就有了统一标尺**。这套「按方向分配收缩」的思想，在贝叶斯里是先验精度、在深度学习里是权重衰减（AdamW 的解耦衰减，见优化器深读）——同一个数学换了三次衣服。

## 常见误区

- **「岭回归改变了模型的线性假设」** —— 岭回归仍是参数线性模型（y 仍是 β 的线性函数）；改变的是估计方法（加入 L2 惩罚）——模型的函数形式不变。
- **「岭回归可以用于特征选择（把不重要的系数压到零）」** —— 岭回归（L2）将系数缩小但不精确为零——无法做特征选择；Lasso（L1）才能产生稀疏解。
- **「岭回归只用于解决多重共线性」** —— 岭回归有三种视角：正则化、贝叶斯先验（高斯 MAP）、核方法（KRR）——共线性只是其中一个应用场景。
- **「岭回归的截距也需要正则化」** —— 截距通常不正则化；正则化截距会使模型对目标变量的整体偏移过度敏感——sklearn 的 fit_intercept=True + penalty 只作用于系数。

## 四、要点总结

1. **岭回归为什么能救共线？** λI 平移所有特征值恢复正定；等价于对主成分软收缩，压掉小方差方向的噪声放大。
2. **Lasso 为什么产生精确零、岭不能？** L1 菱形尖角落在坐标轴；L2 圆只能一般位置相切。
3. **弹性网解决什么？** Lasso 在共线下选择不稳 + p>n 的数量限制：L2 拧组 + L1 挑组。
4. **正则化前为什么要标准化？** 罚项量纲敏感，未标准化时大量纲特征被系统性重罚。
5. **λ 怎么选？** 交叉验证（对数网格）；Lasso 报告特征选择时附 λ 与稳定性检验。
6. **MAP 视角下两者差在哪？** 高斯 vs 拉普拉斯先验——先验形状决定后验是否鼓励零。
