# ViT 深读：一张图怎么变成一句话

这篇是**视觉 Transformer**主题的深度补充。ViT（2020）只做了一件事——**把图像切块当 token，其他照抄 NLP 的 Transformer**——却在数据量上来后碾压 CNN。这篇讲清 patch 化的工程细节、它用多少数据换来这个结果、以及它和 CNN 互相学到什么。

> [!KEY] 一句话抓住本质
> ViT = 「一张 224×224 的图 = 196 个 16×16 的 patch = 196 个 token」。每个 patch 拉平后过一个线性层得到词向量，加上可学习的位置嵌入，送进标准 Transformer 编码器；[CLS] token 的输出当整图表示。**它把视觉问题彻底翻译成了语言问题**——代价是没有了卷积的先验，需要更多数据来补。

---

## 一、patch 化：唯一的「视觉特有」步骤

$$z_0 = [x_{\text{cls}};\; x_p^1 E;\; x_p^2 E;\; \ldots;\; x_p^N E] + E_{\text{pos}}$$

- 224×224×3 的图切成 $P=16$ 的块 → $N = (224/16)^2 = 196$ 个 patch，每个拉平成 $16 \times 16 \times 3 = 768$ 维向量；
- $E$ 是 768×768 的线性投影（实现上就是一个 stride=16 的卷积——**patch 化本质是「超大核、无重叠」的卷积**）；
- 拼一个可学习的 `[CLS]` token（NLP 的直译），加可学习位置嵌入。

之后全是标准 Transformer 编码器：多头自注意力 + MLP，Pre-LN，GELU。分类头接在 `[CLS]` 输出上。

**归纳偏置清单（ViT 丢了什么）**：卷积的局部性、平移等变、层级组合——ViT 只保留「patch 内局部性」（切片那一步）和「序即位置」（位置嵌入）。**其余先验全部交给数据学**。

---

## 二、数据饥渴：JFT-300M 的故事

原论文最著名的消融：

| 训练数据 | ImageNet 上 ViT vs ResNet |
|---|---|
| ImageNet-1k（130 万） | ViT 落后 |
| ImageNet-21k（1400 万） | 接近 |
| JFT-300M（3 亿，谷歌私有） | **ViT 大幅领先** |

结论：**ViT 拿掉了归纳偏置的先验，就得多吃数据把它学回来**——注意力需要自己发现「相邻像素相关」「物体平移不变」。曲线在数据轴上交叉后，ViT 上限更高（无硬编码天花板）。

现实折中路线：

- **中等数据**：DeiT（2021）用强增广 + 蒸馏，让 ViT 在 ImageNet-1k 上也打过 CNN——「数据不够，增养来凑」；
- **要 CNN 的先验又要注意力的容量**：Swin（窗口分层注意力，O(n) 复杂度）、ConvNeXt（反向证明「现代训练配方 + 卷积」也能打平 ViT）；
- **当下实践**：视觉编码器用 ViT 变体（VLM/CLIP 都基于它），检测分割用层次化骨干（Swin/ConvNeXt）——见「多模态大模型 VLM」。

## 三、位置嵌入与注意力在图上看什么

- **位置嵌入可视化**：相邻 patch 的位置嵌入相似度呈 2D 网格结构——模型自学出了「图像是二维摆放的」这一先验（这是 ViT 论文最漂亮的图之一）。
- **注意力距离**：浅层头看邻域（拟态卷积），深层头看全局；随着数据增多，浅层也出现远程头——**「先学局部，再学全局」的涌现顺序**。
- 复杂度：$O((H/P \cdot W/P)^2)$——序列长是 patch 数（196），不是像素（50176），这是 patch 化在计算上的全部意义；代价是 16×16 内的细节被压缩，细粒度任务用更小 patch（14 甚至 8）或高分辨率输入。

## 三·五、多尺度与高分辨率的工程变体

ViT 的固定 patch（16×16）在密集预测/小目标上的两个问题与对策：

- **小目标 < 1 patch**：目标被「塞进」一个 token 里消失——对策是**更小的 patch 或滑动窗口**（高分辨率输入，token 数平方增长，成本爆炸）；
- **密集预测需要像素级输出**：单尺度单次输出不够——Swin 的**层次化金字塔**（4 个阶段逐级下采样，像 CNN 的 FPN）让多尺度特征天然存在——检测/分割头直接接。

**高分辨率的账**：224²（196 token）→ 1024²（4096 token）≈ 21 倍计算——「直接放大」不经济。工程方案：**平铺切块**（切 224 子图分别过编码器，最后融合——GPT-4V 的多裁剪策略）、**窗口注意力**（Swin 局部窗口内交互，线性复杂度）、**token 剪枝/合并**（ToMe：训练-free 合并相似 token，减 30~50% 计算几乎无损）。

**MAE 的 view**：ViT 的 patch 化对掩码自监督极其友好——「丢 patch」就是掩码（CNN 的特征图掩码做不到）——这是 ViT 在自监督时代反超 CNN 的架构红利之一（见自监督深读的 MAE 一节）。

## 四、要点总结

1. **ViT 怎么处理图像？** 切 16×16 patch → 线性投影成 token + 位置嵌入 → 标准 Transformer 编码器 → [CLS] 分类；patch 化等价于 stride=P 的卷积。
2. **为什么小数据打不过 CNN？** 卷积自带局部性/平移等变先验；ViT 要用数据学这些——DeiT 证明强增广+蒸馏能补一部分。
3. **224 输入有多少 token？** (224/16)² + 1 = 197（含 [CLS]）。
4. **ViT 与 Swin 的区别？** Swin 在局部窗口内做注意力 + 层级下采样，复杂度线性、有金字塔特征（适合检测分割）；ViT 全局注意力、单尺度。
5. **位置编码用哪种？** 原版是可学习绝对位置（不外推）；后续 MAE/Swin 也多可学习式，长上下文/外推场景换 RoPE 变体。
6. **ViT 的推理成本主要在哪？** 注意力对 patch 数平方 + FFN 对宽度平方；高分辨率下 patch 数平方增长是主要瓶颈（Swin/线性注意力为此而生）。
