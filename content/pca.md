# PCA 深读：最大方差与最小重构误差是同一件事

这篇是 **PCA 降维**主题的深度补充。PCA 人人会调 `.fit_transform()`，这里讲清两件常被含糊掉的事：**「最大方差」和「最小重构误差」为什么殊途同归**、**SVD 和协方差特征分解是什么关系**。

> [!KEY] 一句话抓住本质
> PCA 找的是一组**正交方向**，沿它们投影后：数据方差最大（保留信息最多）——等价地——投影回去时**重构误差最小**。这组方向就是中心化数据协方差矩阵的**特征向量**（按特征值从大到小），几何上就是数据的「主轴」。

---

## 一、路线 A：最大方差

数据已中心化（均值 0）。投影到单位方向 $u$ 上，投影值为 $u^{\text{T}}x_i$，其方差：

$$\text{Var}(u^{\text{T}}X) = u^{\text{T}}\Sigma u, \qquad \Sigma = \frac{1}{n}X^{\text{T}}X$$

约束 $u$ 是单位向量，用拉格朗日乘子最大化：

$$\max_u\; u^{\text{T}}\Sigma u \quad \text{s.t.}\;\; \lVert u\rVert = 1$$

驻点条件 $\Sigma u = \lambda u$——**$u$ 必须是 $\Sigma$ 的特征向量**，目标值 $u^{\text{T}}\Sigma u = \lambda$ 正是特征值。所以：方差最大的方向 = 最大特征值对应的特征向量；第二主成分在与第一正交的补空间里继续找，得第二大特征值，以此类推。

---

## 二、路线 B：最小重构误差（并证明两条路等价）

用前 K 个方向 $u_1, \ldots, u_K$ 重构每个点：$\hat{x}_i = \sum_{k=1}^{K}(u_k^{\text{T}}x_i)u_k$。重构误差：

$$\frac{1}{n}\sum_i \lVert x_i - \hat{x}_i\rVert^2 = \frac{1}{n}\sum_i \left(\lVert x_i\rVert^2 - \sum_{k=1}^{K}(u_k^{\text{T}}x_i)^2\right)$$

前一项与选哪组方向无关——**最小化重构误差 = 最大化投影方差之和**。两条路线在数学上是同一个问题，没有取舍。

> [!NOTE] 一个常被忽略的等式
> $\Sigma$ 的**特征值之和 = 数据总方差 = 迹(trace)**。所以「前 K 个特征值 / 全部特征值之和」就是**保留的方差比例**——这是画「碎石图」和选主成分个数的依据（如累计 95% 方差）。

---

## 三、SVD 视角：实践中的 PCA 长这样

实践中从不显式算协方差再特征分解（数值不稳、慢），而是直接对中心化数据做**奇异值分解**：

$$X = U S V^{\text{T}}$$

- $V$ 的列**就是主成分方向**（右奇异向量）；
- $S$ 的奇异值满足 $\lambda_k = s_k^2 / n$（方差 = 奇异值平方 / n）；
- 投影结果 $XV$（前 K 列）即降维坐标，等于 $U_k S_k$。

为什么数值更稳：特征分解 $\Sigma = X^{\text{T}}X/n$ 先做平方会把小奇异值的精度压掉，SVD 跳过这一步；这也是 `numpy.linalg.svd` 与 sklearn PCA 的实现路径。

```python
import numpy as np
X = X - X.mean(0)                # 1. 中心化（必做！PCA 对均值敏感）
U, S, Vt = np.linalg.svd(X, full_matrices=False)
Z = X @ Vt[:2].T                 # 2. 取前 2 个主成分方向的投影
var_ratio = S**2 / (S**2).sum()  # 3. 各主成分的方差占比
```

## 四、什么时候会骗你

| 陷阱 | 原因 | 对策 |
|---|---|---|
| **没标准化** | 量纲大的特征方差大，垄断第一主成分 | 先 z-score（sklearn 的 `StandardScaler`） |
| **非线性结构** | PCA 是线性投影，Swiss roll 会被压成一团 | Kernel PCA / t-SNE / UMAP |
| **把 PCA 当分类预处理万能药** | 最大方差方向 ≠ 最有区分力的方向 | 有监督降维用 LDA |
| **用 PCA 防泄漏** | 在全部数据（含测试集）上拟合 PCA = 泄漏 | 只在训练集上 fit |
| **解释成分符号** | 特征向量符号任意（±u 等价） | 别纠结载荷的正负翻转 |

**与因子分析的区别**：PCA 是确定性变换（找最优线性投影，无概率模型）；因子分析假设「隐因子 + 噪声」的生成模型，噪声可有各向异性。想要概率语义或缺失值处理用 FA/PPCA。

## 五、面试要点速答

1. **PCA 的两条等价目标？** 最大投影方差 = 最小重构误差（重构误差里与方向无关的项剔除后，剩余就是负的投影方差）。
2. **主成分和特征值的关系？** 主成分是协方差矩阵的特征向量，特征值 = 该方向上的方差；特征值/迹 = 方差占比。
3. **PCA 为什么先中心化？** 协方差定义在均值上；不中心化时第一主成分会被均值方向劫持。
4. **SVD 和 PCA 的关系？** 中心化 X 的右奇异向量 = 主成分；奇异值平方/n = 特征值；数值上更稳。
5. **白化（whitening）是什么？** 投影后再除以标准差，让各维度方差为 1——去掉「幅度」只留「相关结构」，常作深度学习输入预处理。
6. **PCA 与 LDA？** PCA 无监督（方差最大），LDA 有监督（类间/类间距比最大）；标签有用时 LDA 的投影往往更有区分力。
