# 语音合成深读：从源-滤波到 LLM 式语音

这篇是**语音合成 TTS**主题的深度补充。上面标签页给了「源-滤波」的物理直觉与共振峰演示，这篇补全现代管线的两个核心部件——**声学模型与声码器的分工**，以及 LLM 式语音为什么改变了游戏规则。

> [!KEY] 一句话抓住本质
> 现代 TTS = **文本前端 → 声学模型（文字→Mel 频谱）→ 声码器（频谱→波形）**。两个模型的分工源于一个事实：语音的「内容结构」与「波形细节」需要不同粒度的建模——先在 Mel 频谱（便宜、紧凑）上解决「怎么读」，再用声码器解决「怎么听起来真实」。

---

## 一、文本前端：被低估的 30%

多音字（「重庆」vs「重量」）、数字读法（「110」是电话还是数字）、缩写展开（「CEO」）、韵律断句——**文字到发音的规范化（TN）与韵律预测**决定「听起来对不对」。端到端模型大幅压缩了这一层，但工业系统仍保留显式前端做可控性（专有名词读音、语气标注）。

---

## 二、声学模型三代

1. **拼接式**：录音库切单元拼接——自然但机械感、成本高（录全音素覆盖）；
2. **参数式**：HMM 状态对齐 + 决策树预测声学参数（F0/时长/频谱包络）——可控性强，音质天花板低（本站演示的共振峰合成是它的极简版）；
3. **神经声学模型**：
   - **Tacotron 2**：注意力编码-解码，文字直接出 Mel——注意力对齐消除逐帧标注（与 ASR 的 CTC 同一思想的两面）；
   - **FastSpeech 2**：**非自回归**（一次并行出全部帧）+ 显式预测时长/音高/能量（可编辑韵律！）——速度快十倍、鲁棒性好，工业主流；
   - 可控性的工程价值：时长/音高/能量三个预测器让「改语速、改重音」变成直接改中间变量。

---

## 三、声码器：从 Griffin-Lim 到神经声码器

Mel→波形的逆问题是欠定的（相位丢失）：

- **Griffin-Lim**：迭代相位重建——免费但金属感；
- **WaveNet**（2016）：逐样本自回归建模波形——自然度飞跃，但慢；
- **HifiGAN / BigVGAN**：GAN 训练的并行声码器——实时、自然度达标，工业默认。

**为什么 Mel 频谱是中间表示**：紧凑（8 倍降采样）、感知对齐、对声码器友好——「频谱管内容，声码管质感」的分工由此而来。

---

## 四、LLM 式语音：范式转移

**VALL-E / Codec-SLM 路线**：音频经神经编解码器（codec）离散化成 token 序列 → 语音合成 = **音频 token 的下一个 token 预测**。三个质变：

1. **零样本音色克隆**：3 秒参考音频做 prompt，模型续写同音色的语音——「声音」变成上下文属性；
2. **与 LLM 共享基建**：文本、音频统一 token 空间，同一 Transformer 多模态生成（GPT-4o 的实时语音即此路线）；
3. **涌现副产物**：情绪保持、环境声延续、甚至「结巴后的自我纠正」——从训练分布里免费长出来。

代价与风险：**声纹诈骗与深度伪造**（音色克隆即武器）——水印、活体检测、授权协议是部署的伴生工程。

## 三·五、FastSpeech 2 的三个显式预测器与可控合成的实现

FastSpeech 2 的关键设计是把「隐藏在 Tacotron 注意力里的随机性」变成**显式可编辑的变量**——三个预测器：

1. **时长预测器**：每个音素说多久（对齐信息从 MFA 强制对齐蒸馏而来）——改时长 = 改语速（局部变速：只让关键词读慢一倍）；
2. **音高预测器**：F0 轨迹——改音高曲线 = 改语调（疑问句尾部上扬、重音强调）；
3. **能量预测器**：响度——改重读与情绪强度。

**「可控性」是参数式思想的神经版**：经典参数合成（本站演示）显式控制 F0/共振峰；FastSpeech2 显式控制时长/音高/能量——**把不可解释的隐变量拉出来变成旋钮**是可控生成的通用方法论（ControlNet 深读的结构条件、扩散的 CFG，都是同一思想）。

**韵律的连续性问题**：句级合成已好，但「跨句的情绪演进」（一段愤怒的话逐渐平复）仍弱——长上下文 TTS（把多句拼成上下文）与情感向量插值是两条在研路线。

## 常见误区

- **「TTS 的 MOS 分越高 = 人耳越难分辨」** —— MOS 是平均意见分（5 分制主观评价）——MOS 4.5 ≠ 无法分辨（人耳对韵律/情感/呼吸声极其敏感）；MOS 是统计量，不适用于单句判断。
- **「神经 TTS = 端到端 = 不需要文本前端」** —— 即使端到端模型也需要**文本规范化**（数字→读音、缩写→全称、多音字消歧）——文本前端（TN）仍是 TTS 管线中最容易被低估的错误来源。
- **「情绪 TTS = 加一个情绪标签」** —— 真实的情感韵律涉及音高/时长/能量的连续变化与跨句连贯——一个标签无法编码复杂情绪（讽刺/犹豫/渐进变化），需要细粒度韵律控制。
- **「语音克隆只需要几秒参考音频就完美了」** —— 几秒参考可以克隆音色但**韵律风格/口音/习惯用语**需要更长的参考数据——克隆质量与参考数据量正相关。

## 五、要点总结

1. **声学模型与声码器的分工？** 文字→Mel（内容与韵律）；Mel→波形（质感与相位）——中间表示的模块化。
2. **FastSpeech 2 相对 Tacotron 2 的优势？** 非自回归并行生成（快、稳）+ 显式韵律变量（可控可编辑）。
3. **WaveNet 的历史意义与瓶颈？** 逐样本自回归的真实感飞跃；速度慢 → GAN 并行声码器接棒。
4. **为什么用 Mel 频谱做中间层？** 感知对齐 + 紧凑 + 逆问题可被声码器学。
5. **VALL-E 的范式突破？** 语音 token 化后用 LLM 建模——零样本克隆与多模态统一生成。
6. **克隆滥用的防线？** 音频水印、授权采样、活体/真伪检测——部署与能力同等重要。
