# BERT 深读：掩码语言建模与双向编码

这篇是 **BERT 编码器**主题的深度补充。BERT 开创了「预训练 + 微调」范式，它和 GPT 的对比是经典必考题。这篇讲清：**MLM 为什么比预测下一词更适合理解任务**、**80/10/10 替换策略的细节与原因**、**NSP 为什么后来被证明是败笔**。

> [!KEY] 一句话抓住本质
> BERT 把预训练目标从「预测下一个词」改成「**完形填空**」（随机挖掉 15% 的词让模型猜）。因为填空时**左右两边的上下文都可见**，同一个词在不同位置的语义被真正「双向」地编码进向量——这正是分类、检索、抽取这些理解任务需要的表示。

---

## 一、双向为什么重要

「他到银行___取钱」：预测空格必须同时用左边（「银行」）和右边（「取钱」消歧：是柜台 bank 还是河岸 bank）。

- GPT 式自回归只能看左边 → 理解任务天然吃亏（右边的消歧信息丢了）。
- 朴素的「双向预测所有词」会**信息泄漏**：每个词在预测同伴时间接看见了自己（层数越深泄漏越严重）。

BERT 的解法：**挖掉再猜**。被挖的词在输入里被替换，模型物理上看不到答案，双向上下文合法可用。

---

## 二、MLM 的实现细节：80/10/10

随机选 15% 的 token，对这些位置做三选一替换：

| 比例 | 替换为 | 目的 |
|---|---|---|
| 80% | `[MASK]` | 主体：真正的完形填空 |
| 10% | 随机词 | 防止模型只学「看到 [MASK] 就预测」的捷径 |
| 10% | 保持原词 | 让模型保持「任何位置都可能是对的」的表示习惯，微调阶段没有 [MASK] 也能用 |

损失只算这 15% 的位置（不是全词表交叉熵全覆盖）——所以 MLM 每条样本的有效监督信号比 GPT 少（GPT 每个位置都有损失），这是 BERT 预训练**样本效率略低**的原因之一。

> [!WARN] 预训练/微调的分布缺口
> `[MASK]` 只在预训练出现，微调任务里没有——这就是 10%/10% 两支存在的意义（强迫模型对「正常句子」也维持逐词表示质量）。T5 用「替换 span」的哨兵词、RoBERTa 用动态掩码，都是对这个缺口的修补。

---

## 三、NSP：一个被证伪的第二任务

原始 BERT 还有第二个目标：**下一句预测**——给一对句子 A/B，判断 B 是否是 A 的真实下文（50% 真实 / 50% 随机配对），动机是让模型学会句间关系（问答、推理需要）。

**RoBERTa（2019）的消融**：去掉 NSP、加大 batch 和数据后各项任务反而更好。分析：

- NSP 太简单（随机配对在主题上就明显跳变），模型学到的是**主题连贯检测**而非逻辑关系；
- 单句拼接更长序列（更多 MLM 信号）比 NSP 的收益大。

后续 ALBERT 把 NSP 换成 **SOP**（sentence order prediction：给真实相邻的两句，判断顺序是否被交换）——去掉「主题捷径」，强迫学顺序逻辑。现代用法：**纯 MLM（或其变体）足够**。

---

## 四、两种用法：微调 vs 特征提取

**微调（fine-tuning）**：预训练权重 + 任务头（通常一层线性），全参数在下游数据上继续训练。BERT 时代标准做法，小数据集（几百条）也能有好效果。

**特征提取（frozen features）**：冻结 BERT，把各层隐向量当特征：

- 拼接**最后 4 层**的 `[CLS]` 或平均池化（ELMo 式用法，常比只取最后一层稳）；
- 喂给轻量分类器/CRF（NER 任务里 BERT+CRF 是经典组合）。

```python
# 微调的最小骨架：加一个线性头，全部一起训
class BertForClassifier(nn.Module):
    def __init__(self, bert, n_cls):
        super().__init__()
        self.bert = bert
        self.head = nn.Linear(bert.config.hidden_size, n_cls)
    def forward(self, ids, mask):
        out = self.bert(ids, attention_mask=mask)
        cls = out.last_hidden_state[:, 0]      # [CLS] 向量当句表示
        return self.head(cls)
```

> [!TIP] [CLS] 是什么？
> 一个拼在句首的**特殊可学习 token**。预训练时它没有显式任务（NSP 取消后更没有），但注意力的聚合让它在顶层隐式汇总了整句信息；微调时「cls + 线性头」成了最顺手的句级接口。直接拿预训练 BERT 的裸 [CLS] 做相似度效果很差（没经过对齐训练）——句向量请看 SBERT。

## 五、BERT 家族与句向量问题

| 模型 | 改动 | 关键收益 |
|---|---|---|
| RoBERTa | 去 NSP、动态掩码、更多数据更大 batch | 同尺寸全面更强 |
| ALBERT | 参数共享（层间共享权重）+ SOP | 参数大减，速度换表达 |
| DistilBERT | 蒸馏（6 层学 12 层） | 小 40%、快 60%，保留 ~97% 性能 |
| MacBERT / 中文系列 | whole-word masking 等中文适配 | 中文任务标配 |
| **SBERT** | 孪生结构 + 对比式微调 | **句向量**：直接 cosine 检索/聚类 |

SBERT 值得单独记：BERT 原生的句向量各向异性（语义空间被压成窄锥），直接算余弦相似度不可靠；SBERT 用「两个共享权重的 BERT + 句对目标」把向量拉到可度量空间——这是现代**句嵌入模型**（检索、RAG 的 embedding 层）的直系祖先。

## 六、BERT vs GPT：怎么选

| 维度 | BERT（encoder-only） | GPT（decoder-only） |
|---|---|---|
| 预训练目标 | 完形填空（双向） | 预测下一词（因果） |
| 天生强项 | 理解：分类、NER、检索、句向量 | 生成：写作、对话、代码、few-shot |
| 训练效率 | 每样本仅 15% 位置有损失 | 每个位置都有损失 |
| 推理形态 | 一次编码、多次复用（检索友好） | 自回归逐步生成 |
| 时代走向 | 专精理解/嵌入场景 | 通用大模型主流（生成+理解通吃） |

历史注脚：2020 年前后「BERT 还是 GPT」是路线之争；如今答案收敛为——**通用能力走 decoder-only 大一统，纯理解/检索场景 encoder 模型（及其蒸馏版）因便宜仍然广泛部署**。见「推理优化与部署」「RAG」主题。

## 七、要点总结

1. **MLM 为什么 80/10/10？** 主体掩码 + 随机替换防捷径 + 保留原词弥合预训练/微调的 [MASK] 分布缺口。
2. **NSP 为什么被抛弃？** 任务太易（主题捷径），RoBERTa 消融显示去掉更好；ALBERT 的 SOP 是更干净的替代。
3. **BERT 为什么不能直接做生成？** 双向注意力没有因果约束，训练目标也不是序列因子化；生成需自回归结构（BART/T5 用 encoder-decoder 补齐）。
4. **[CLS] 为什么能当句表示？** 微调时充当聚合接口；但预训练裸 [CLS] 不适合相似度——需要 SBERT 式对齐。
5. **BERT 与 GPT-2 同年，为何通用大模型走了 GPT 路线？** 生成即通用接口（few-shot/ICL 只在自回归范式自然出现）；decoder-only 训练推理工程更收敛。
6. **wordpiece 与 BPE 的区别？** wordpiece 选合并的判据是似然增益（`##` 续接标记），BPE 是频率；BERT 用 wordpiece（3 万词表），GPT 用 BPE（5 万）。
