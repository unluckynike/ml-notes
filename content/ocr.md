# OCR 与文档智能深读：从 CRNN 到「文档即提示词」

这篇是 **OCR 与文档智能**主题的深度补充。OCR 是最「古老」的深度学习落地之一，它的三层管线（识别→版面→理解）正在被多模态大模型压成一层。这篇讲清各层的经典方案与被压缩的逻辑。

> [!KEY] 一句话抓住本质
> 文档智能的难点从来不是「认字」，是**结构**：哪个数字是金额、哪两栏是同一行、阅读顺序怎么走。经典管线 = OCR（认字）+ 版面分析（找结构）+ 下游理解（用结构）；VLM 路线把三层压成「图 + 提示词」——工程天平在「专用管线的精确」与「VLM 的零配置泛化」之间摆动。

## 一、识别层：CRNN+CTC 的长寿配方

CRNN（2015-17 定型）：**卷积提特征（视觉）→ 按列切帧（把图变序列）→ 双向 RNN 建上下文 → CTC 解码（对齐边缘化）**。

三个设计理由（与语音识别完全同构，见其深读）：

1. 变长文本需要序列输出而非固定类别；
2. 没有逐字符边界标注——CTC 用「空白符+折叠」把对齐积分掉（演示的三步动画）；
3. RNN 上下文解决粘连/花体会「吃掉」字符的问题（单字符分类做不到）。

现代变体：检测用 DBNet（可微二值化）分割文本行；识别端 SVTR 等纯 Transformer 替换 RNN；中文场景还要分词字典与形近字处理（己/已/巳）。


**CER：OCR 的成绩单**——编辑距离对齐识别结果与真值：

```python
import numpy as np
def cer(ref, hyp):
    d = np.zeros((len(ref) + 1, len(hyp) + 1), dtype=int)
    for i in range(len(ref) + 1): d[i, 0] = i
    for j in range(len(hyp) + 1): d[0, j] = j
    for i in range(1, len(ref) + 1):
        for j in range(1, len(hyp) + 1):
            d[i, j] = min(d[i-1, j] + 1, d[i, j-1] + 1,
                          d[i-1, j-1] + (ref[i-1] != hyp[j-1]))
    return d[-1, -1] / len(ref)

print('CER:', round(cer('发票金额壹仟贰佰元', '发票金额壹仟弐伯元'), 3))
# 数字字段错一个字符可能比文字错一整句代价更高——按字段加权评估更接近业务
```
## 二、版面层：结构的恢复

- **版面分析**：检测标题/段落/表格/图片/公式区域（目标检测模型的文档特化，LayoutLM 系把「文本+坐标+图像」三路信息联合建模）；
- **阅读顺序**：双栏、跨页、表格嵌套——规则（投影切割）到图神经网络（版面元素建图推理顺序）的演化；
- **表格结构还原**：行列关系是老大难（合并单元格、跨页表）——专用模型（TableFormer 类）仍是生产标配。

## 三、理解层与 VLM 压缩

**经典管线**：OCR 文本 + 结构 → 信息抽取（NER/规则/表单映射）→ 入库。误差会**级联**：识别错一个「万」字，抽取全错。

**VLM 路线**（GPT-4V/Qwen-VL 直接看图）：跳过显式 OCR，端到端「图→答案」。优劣清晰：

| | 专用管线 | VLM |
|---|---|---|
| 精度（固定版式） | 高（99%+） | 中，有幻觉（会脑补字段） |
| 新文档类型 | 需开发配置 | 零配置（提示即配置） |
| 成本 | 低（端侧可跑） | 高（每页几千视觉 token） |
| 可控性 | 强（规则兜底） | 弱 |

**生产组合拳**：固定高量版式走专用管线、长尾版式走 VLM 兜底；关键数值（金额）双通道校验。RAG 的「文档大脑」管线（见其深读）里，OCR 是最前端的 feeding 层。

## 三·五、表格结构还原与版面分析的难点

表格是文档智能的珠穆朗玛——难点不在「认字」在**结构**：

- **合并单元格**：跨行/跨列的归属关系（视觉上空的格子其实有语义）；
- **无边框表**：靠对齐关系而非线条判断行列——纯视觉检测失效；
- **跨页表**：表头重复、续页识别；
- **嵌套表/表内图表**。

主流方案三代：模板匹配（固定版式，一模板一配置）→ 检测+关系分类（单元格框 + 行列关系预测，TableFormer 类）→ VLM 直接读（零配置但有幻觉风险，关键数值要校验）。**生产组合**：高频固定版式走模板/专用模型（精度 99%+），长尾版式走 VLM，双通道不一致进人工——「精度预算」按业务错误成本分配（金融票据的错误成本 >> 论坛截图）。

## 常见误区

- **「OCR = 识别印刷体文字」** —— 现代 OCR 是文档智能的前端：包含版面分析（表格/图文/公式区域）、结构还原（阅读顺序/层级）与语义理解（实体抽取）——文字识别只是第一步。
- **「手写体识别准确率已经和印刷体一样」** —— 手写体的自由度（笔顺/连笔/个人风格）远高于印刷体——在受限场景（银行支票数字）可接近印刷体，自由手写仍有显著差距。
- **「端到端 OCR（无 CTC）一定优于 CRNN+CTC」** —— 端到端简化管线但需要大量训练数据且不利于定位（不知道哪个字符在哪）；CRNN+CTC 在定位需求场景仍有优势。
- **「OCR 输出的文字顺序就是阅读顺序」** —— 多栏/表格/图文混排时文本框顺序 ≠ 阅读顺序——版面分析（layout analysis）是独立模块，不是 OCR 的副产品。

## 四、要点总结

1. **CRNN 三段各自解决什么？** 卷积提视觉特征、RNN 建字符上下文、CTC 免对齐解码。
2. **CTC 空白符的两个职责？** 「此处无新字符」+「分隔相邻重复」——没有它双写（ll）会被折叠丢失。
3. **版面分析输出什么？** 区域框+类型+阅读顺序——「结构化文档」的骨架。
4. **VLM 为什么会「脑补」字段？** 生成式模型补全分布倾向，视觉证据不足时用语言先验填充——关键数值要校验。
5. **误差级联怎么缓解？** 双通道（管线+VLM）交叉校验、置信度门控人工复核。
6. **OCR 与语音识别的深层同构？** 「变长输入→序列输出+无对齐标注」——同一个 CTC，两个领域。
