# 反向传播深读：从链式法则到矩阵梯度

这篇是**神经网络 MLP**主题的深度补充，也是整个深度学习的「发动机舱」。目标：读完能在纸上**手推一个两层网络的全梯度**，并理解自动微分框架（PyTorch/TensorFlow）在你写 `loss.backward()` 时到底做了什么。

> [!KEY] 一句话抓住本质
> 反向传播 = **链式法则 + 动态规划**：前向时把每个中间结果存下来，反向时**每个中间量只算一次梯度、处处复用**，把指数级膨胀的求导路径压缩成与网络规模同阶的计算量。

---

## 一、为什么需要「反向」地算？

网络是一个复合函数：$\text{loss} = L(f_n(f_{n-1}(\cdots f_1(x))))$。

对第 1 层参数求导，按链式法则要把**沿途每一层的局部导数**乘起来。关键观察：不管求哪一层的参数梯度，**都是从 loss 出发往回走的同一条路径的前缀**。

- 如果**从每个参数出发**往 loss 方向求（前向模式微分）：$n$ 个参数要走 $n$ 条路，重复计算爆炸。
- 如果**从 loss 出发**反向走一遍（反向模式微分）：沿途把「loss 对每个中间节点」的梯度都算出来存住，参数梯度顺手套用——**一次反向，全部参数到手**。

代价与收益：反向模式一次得到的正是**所有参数的梯度**（输出 1 个、参数百万个），这正好匹配深度学习的形状（标量损失、海量参数）。

---

## 二、计算图与链式法则

把网络画成计算图，每个节点是一次运算。记 $\bar{a} = \partial L / \partial a$（节点 $a$ 的「上游梯度」）。

**乘法节点** $c = a \cdot b$：

$$\bar{a} = \bar{c} \cdot b,\qquad \bar{b} = \bar{c} \cdot a$$

（乘法反向 = 交换乘。）

**加法节点** $c = a + b$：

$$\bar{a} = \bar{c},\qquad \bar{b} = \bar{c}$$

（加法反向 = 原样传递。）

**多父节点**：若 $a$ 被用了两次（$c = a\cdot b$，$d = a\cdot e$），则梯度**相加**：

$$\bar{a} = \bar{c}\cdot b + \bar{d}\cdot e$$

> [!WARN] 最常见的 bug 来源
> 「一个变量的梯度 = 它所有使用路径的梯度之和」。实现时如果对同一个张量写两次 `grad = ...` 而不是 `grad += ...`，梯度就被悄悄覆盖——这是手写反传和阅读别人代码时的头号检查点。

## 三、手推两层网络（核心章节）

设一个最小网络：输入 $x \in \text{R}^2$，隐层 3 个单元，输出 1 个单元，激活都是 Sigmoid，损失用均方误差。

```
z1 = W1·x + b1        (W1: 3×2, b1: 3×1)
a1 = σ(z1)            (3×1)
z2 = W2·a1 + b2       (W2: 1×3, b2: 标量)
y_hat = σ(z2)
L  = ½(y − y_hat)²
```

**反向逐层求**（利用 $\sigma'(z) = \sigma(z)(1-\sigma(z))$）：

**第 1 步·输出层误差项**：

$$\delta_2 = \frac{\partial L}{\partial z_2} = -(y - \hat{y})\cdot\hat{y}(1-\hat{y})$$

**第 2 步·输出层参数梯度**（误差项 × 该层输入）：

$$\frac{\partial L}{\partial W_2} = \delta_2 \cdot a_1^{\text{T}},\qquad \frac{\partial L}{\partial b_2} = \delta_2$$

**第 3 步·把误差传回隐层**（误差项 × 权重 × 激活导数）：

$$\delta_1 = (W_2^{\text{T}} \delta_2) ⊙ a_1 ⊙ (1 - a_1)$$

其中 $⊙$ 表示逐元素相乘（Hadamard 积）。

**第 4 步·隐层参数梯度**：

$$\frac{\partial L}{\partial W_1} = \delta_1 x^{\text{T}},\qquad \frac{\partial L}{\partial b_1} = \delta_1$$

> [!KEY] 万能模板（背这个）
> 每层参数梯度 = **本层误差项 $\delta$ × 本层输入**；本层误差项 = **（上层误差项反向乘上层权重） $⊙$ 本层激活导数**。任何深度的网络都是这四行的循环。

**形状检查法**：梯度必须与参数**同形状**。$W_2$ 是 $1\times 3$，$\delta_2\, a_1^{\text{T}}$ 是 $(1\times1)(1\times3)$ ✓。写代码时把每步形状注释出来，80% 的反传 bug 当场现形。

## 四、梯度检查：数值梯度对拍

工业界标准做法——用**有限差分**近似梯度，和反传结果对拍：

```python
def numerical_grad(f, x, eps=1e-5):
    """f: 标量函数; x: numpy 数组——逐元素扰动求数值梯度"""
    grad = np.zeros_like(x)
    it = np.nditer(x, flags=['multi_index'])
    while not it.finished:
        ix = it.multi_index
        old = x[ix]
        x[ix] = old + eps; fp = f(x)
        x[ix] = old - eps; fm = f(x)
        x[ix] = old
        grad[ix] = (fp - fm) / (2 * eps)
        it.iternext()
    return grad

# 相对误差 < 1e-7 很好；1e-5~1e-7 可接受；> 1e-3 基本确定有 bug
rel_err = np.abs(g_bp - g_num) / np.maximum(1e-8, np.abs(g_bp) + np.abs(g_num))
```

> [!TIP] 实操建议
> 对拍要用**双精度**、eps 取 $10^{-5}$ 量级；先在一个**极小网络**（两三个单元）上对拍通过，再放大——大网络上定位 bug 是噩梦。

## 五、梯度消失与爆炸：反传的宿命

反向传播每过一层就乘一次「权重 × 激活导数」。这个连乘因子的量级决定命运：

| 情形 | 连乘量级 | 后果 | 对策 |
|---|---|---|---|
| Sigmoid + 大权重 | $> 1$ 持续放大 | 梯度**爆炸**，loss 变 NaN | 梯度裁剪、正交初始化 |
| Sigmoid + 小权重 | $< 1$ 持续缩小 | 梯度**消失**，前层学不动 | ReLU、残差连接、LSTM 门控 |

Sigmoid 导数最大值只有 0.25——10 层网络梯度最好也要缩到 $0.25^{10} \approx 10^{-6}$。这解释了三件事：**为什么 ReLU 取代了 Sigmoid**（正区导数恒为 1）、**为什么残差连接如此有效**（恒等通路让梯度无衰减直达）、**为什么 LSTM 能撑住长序列**（细胞状态的加法更新让梯度走「传送带」）。

初始化的目标也是控制这个量级：Xavier 初始化让方差前后向都守恒（配合 tanh），He 初始化针对 ReLU 把方差放大 2 倍补偿。

## 六、自动微分：框架在帮你做什么

PyTorch 的 `loss.backward()` 做的事：

1. 前向时记录**计算图**（每个张量的运算与父节点）——这是「动态图」的含义：每次前向按你的 Python 代码现搭一张图。
2. 从 loss 反向拓扑排序，逐节点套本文第三节的模板。
3. 梯度**累加**进 `.grad`（所以连续两次 `backward()` 之间要 `zero_grad()`，否则梯度翻倍——对应第二节「多父节点相加」）。

理解了这一点，就明白为什么：`detach()` 能截断梯度（把节点从图上摘下来）；`with torch.no_grad()` 能省内存（不建图）；`tensor.requires_grad_(True)` 能对输入求梯度（即「显著性图」）。

## 七、要点总结

1. **反向传播和链式法则的关系？** 链式法则是数学原理，反向传播是它在计算图上的高效实现（反向模式自动微分 + 中间结果复用）。
2. **为什么一次 backward 能得到所有参数的梯度？** 反向模式微分从标量 loss 出发只走一遍，沿途每个中间节点的梯度只算一次。
3. **$\delta$（误差项）的物理含义？** loss 对该层**加权输入 z** 的偏导，是「责任」的度量；参数梯度由它与本层输入组合而来。
4. **梯度检查的相对误差阈值？** 双精度下 $10^{-7}$ 内为佳，超过 $10^{-3}$ 必有 bug。
5. **为什么 ReLU 缓解梯度消失？** 正区导数恒为 1，连乘不再指数缩小；但要注意「死 ReLU」问题（负区梯度恒 0）。
6. **为什么残差连接让深网络可训？** $y = F(x) + x$ 的加法支路给梯度一条无衰减的恒等通路（$\partial y/\partial x = F'(x) + 1$）。
