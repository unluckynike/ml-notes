# t-SNE 深读：条件分布、重尾与那些不能下的结论

这篇是 **t-SNE 可视化**主题的深度补充。t-SNE 是最容易被误读的算法——它画出的图**看起来**像散点图，但簇间距离、簇大小、点数多少都可能完全没有意义。这篇讲清它的机制，以及一张「正确解读清单」。

> [!KEY] 一句话抓住本质
> t-SNE 在高维空间和低维空间各建一个「概率分布」，然后**移动低维点让两个分布的 KL 散度最小**。高维用高斯（局部结构），低维用自由度 1 的 t 分布（重尾）——重尾解决了「高维邻居挤在低维一团」的拥挤问题，也造就了它漂亮的簇分离效果。

---

## 一、从 SNE 到 t-SNE：三步演化

**第 1 步·SNE（2002）**：把点对相似度变成条件概率——$x_j$ 是 $x_i$ 邻居的概率正比于高斯核：

$$p_{j|i} = \frac{\exp(-\lVert x_i - x_j\rVert^2 / 2\sigma_i^2)}{\sum_{k \neq i}\exp(-\lVert x_i - x_k\rVert^2 / 2\sigma_i^2)}$$

低维对应 $q_{j|i}$（固定 $\sigma=1/\sqrt{2}$），最小化 $\sum_i \text{KL}(p_{\cdot|i} \| q_{\cdot|i})$。SNE 的问题：损失不对称、难优化、**拥挤问题**——高维中「中等远」的点在低维被压得极近。

**第 2 步·对称化**：t-SNE 用联合分布代替条件分布：

$$p_{ij} = \frac{p_{i|j} + p_{j|i}}{2n},\qquad q_{ij} = \frac{(1 + \lVert y_i - y_j\rVert^2)^{-1}}{\sum_{k \neq l}(1 + \lVert y_k - y_l\rVert^2)^{-1}}$$

注意 $q$ 用的是 **t 分布（自由度 1）**，不是高斯。

**第 3 步·重尾的魔法**：t 分布的尾巴按 $z^{-2}$ 衰减，高斯按 $e^{-z^2}$。效果是低维中「不太相似」的点被允许推到**很远**——中等距离的点不再挤作一团，小簇也能撑开自己的空间。这就是 t-SNE 图上簇与簇之间那圈诱人空白带的来源。

> [!WARN] 但这也意味着
> 簇间距离是被「撑出来」的显示效果，**不编码任何高维信息**。两个离得远的簇，在高维里可能其实很近。

## 二、perplexity：每个点自己决定「多远算邻居」

每个点有自己的 $\sigma_i$，由**困惑度**（perplexity）控制：

$$\text{Perp}(P_i) = 2^{H(P_i)},\qquad H(P_i) = -\sum_j p_{j|i}\log_2 p_{j|i}$$

直觉：perplexity ≈ 每个点「认多少个有效邻居」。sklearn 默认 30，建议在 5~50 之间多试几个——**同一数据不同 perplexity 的图可能差异巨大**，这不是 bug，是算法的敏感本性（密度不均的数据天然需要不同尺度的邻居）。

实践参数速查：`learning_rate` 取 n/12 附近（sklearn 的 'auto' 已自动）；`early_exaggeration` 阶段先把簇推开再精修；迭代至少 1000 步再看；**init='pca'** 比 random 收敛更快更稳。

**t-SNE 的高维侧一步**——把距离变成「邻居概率」，perplexity 调带宽：

```python
import numpy as np
rng = np.random.default_rng(0)
X = rng.normal(size=(50, 10))
d2 = ((X[:, None] - X[None]) ** 2).sum(-1)
np.fill_diagonal(d2, np.inf)
beta = 1.0                                       # 1/(2σ_i²)：perplexity 二分搜索的目标
P = np.exp(-d2 * beta); P /= P.sum(1, keepdims=True)
print('每行熵 ≈', round(float(-(P * np.where(P>0, np.log(P), 0)).sum(1).mean()), 2),
      '→ perplexity ≈', round(float(np.exp(-(P * np.where(P>0, np.log(P), 0)).sum(1).mean())), 1))
# perplexity = 2^熵：beta 的二分搜索就是为了让每个点的「有效邻居数」都等于设定值
```

## 三、正确解读清单（最重要的一节）

| 你看到的 | 能下的结论 | 不能下的结论 |
|---|---|---|
| 一团点聚成小簇 | 簇内点在高维**相对**更相近 | ✗ 簇的大小有意义（受局部密度影响） |
| 两个簇分开 | 两簇内点互不为近邻 | ✗ **簇间距离有意义**（被重尾人为放大） |
| 簇里点的密度 | — | ✗ 密度无意义（拥挤问题的补偿机制扭曲它） |
| 单个点的位置 | 点与其近邻的相对位置 | ✗ 孤立点的绝对位置（随机性大） |
| 全局结构 | — | ✗ 任何全局结论（t-SNE 只保局部） |

验证工具：跑多个 perplexity / 多个 seed，看结论是否稳定；需要全局结构时用 **UMAP**（保留了更多全局拓扑）或先 PCA 看大方差方向。

**t-SNE vs UMAP**：UMAP 用流形假设 + 单纯形上的交叉熵，速度通常快数倍、全局结构更好、还能 `transform` 新样本（t-SNE 不能——它是「一次性排版」）；UMAP 的簇间距离同样要谨慎解读。两者都是**可视化工具**，不是特征提取器——降维结果喂下游模型通常不如 PCA 稳。

## 常见误区

- **「t-SNE 图中簇的大小 = 该簇的内部方差」** —— t-SNE 的 perplexity 参数**标准化了每个点的有效邻居数**——簇的大小反映的是「算法的选择」而非数据的真实方差——不能从簇的大小推断数据特征。
- **「t-SNE 图中簇之间的距离 = 簇之间的真实距离」** —— t-SNE 优化的是局部邻域保持，全局距离不可信——两个远距离簇可能在高维中很近（反之亦然）。
- **「t-SNE 可以用来降维做下游任务」** —— t-SNE 的嵌入**没有 out-of-sample 映射**（新数据点无法嵌入）且不保距——降维用 PCA/UMAP/AutoEncoder，t-SNE 仅用于可视化。
- **「t-SNE 的困惑度越大 = 考虑的邻居越多 = 结果越好」** —— 大 perplexity 关注全局结构（忽略局部细节）、小 perplexity 关注局部结构（忽略全局拓扑）——没有「更好」，只有「看哪个尺度」。

## 四、要点总结

1. **t-SNE 优化什么？** 高维 $p_{ij}$ 与低维 $q_{ij}$ 的 KL 散度；KL 不对称，重视「高维近的映射后还近」，不关心「高维远的去哪」。
2. **为什么低维用 t 分布？** 重尾解决拥挤问题：允许不相似点放很远，中小尺度结构得以展开；同时梯度形式 $(1+\lVert d\rVert^2)^{-1}$ 对远点不爆炸，优化稳定。
3. **perplexity 的含义？** 每个点的有效邻居数（熵的指数形式）；控制 $\sigma_i$ 的二分搜索目标。
4. **t-SNE 为什么不能有测试集 transform？** 它没有显式映射函数，只有这 n 个点的最优摆放；新点进来需要重跑（或用参数化变体）。
5. **簇间距离能信吗？** 不能。重尾把不相似点推得很远，间距被夸大且随参数变化。
6. **什么任务该用 PCA 而不是 t-SNE？** 需要可逆变换/新样本投影/特征工程——PCA 是显式线性投影；t-SNE 只用于探索性可视化。
