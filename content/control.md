# ControlNet 深读：零卷积与「可控生成」的设计模式

这篇是**图像控制编辑**主题的深度补充。ControlNet 之所以成为 SD 生态的基石，在于一个精巧的工程决策——**零卷积**。这篇讲清它解决什么问题，以及「可控生成」作为一个设计模式的全家福。

> [!KEY] 一句话抓住本质
> 微调可控性最怕「捡了控制丢了画功」。ControlNet 的解法：**冻结原模型 + 拷贝一份编码器 + 零初始化卷积注入**——训练起点严格等于原模型（零卷积输出恒 0），控制能力从零逐渐长出，预训练能力零损伤。这个「外科手术式外挂」模式被后续无数工作复用。

---

## 一、零卷积：一行设计救全家

结构上：

$$y_c = F(x;\theta_{\text{frozen}}) + Z\big(F(x + C(\text{cond}); \theta_c)\big)$$

- F：U-Net 编码块（冻结）；拷贝块 θ_c 与 F 同结构、同初始化（起点行为一致）；
- C(cond)：条件图（边缘/深度/姿态）的编码；
- **Z：1×1 卷积，权重与偏置全部零初始化**——训练第 0 步 y_c ≡ F(x)，模型输出与原 SD **逐位相同**。

为什么关键：若随机初始化注入，微调早期就破坏预训练分布（灾难性遗忘的微调版）——生成质量崩、控制也学不稳。零卷积把「学控制」变成纯增量：**不动的部分保证画功，从零的部分长出控制**。这个思想与 LoRA 的 B 零初始化（见其深读）、ResNet 的恒等初始化（见其深读）一脉相承——**「新能力零起点，旧能力零损伤」**。

## 二、可控生成设计模式全家福

| 模式 | 机制 | 代表 |
|---|---|---|
| **结构注入** | 条件图 → 外挂编码器逐层相加 | ControlNet |
| **参考注入** | 参考图特征 → 注意力/适配器 | IP-Adapter（风格/人脸保持） |
| **部分重噪** | 原图加噪到 t* 再去噪（保结构比例） | img2img（strength 旋钮） |
| **区域重绘** | 只在 mask 内去噪 | inpainting |
| **首尾帧约束** | 端点帧给定，插中间 | 视频生成（见其深读） |

共同本质：**在去噪过程的某个环节加约束，控制「往哪个吸引子收敛」**——扩散的确定性采样（DDIM，见其深读）让「同一噪声+不同约束=可控差异」成为可能（演示可视化了这个事实）。

## 三、实践要点

- **条件预处理决定上限**：Canny 阈值、深度模型质量、姿态检测器的抖动都会传导进生成；OpenPose 对遮挡敏感、深度对玻璃无效——选条件先想「我的场景什么结构最稳」；
- **控制权重与引导范围的调法**：control_scale 全程 1.0 常过硬；进阶玩法「前强后弱」（前 30% 步强控制定结构、后 70% 放开让模型画细节）；
- **多条件叠加**：边缘+深度可同时挂，权重按「最想保的结构」排序——冲突时权重高的赢；
- **与 LoRA 组合**：风格 LoRA + 结构 ControlNet 是工作流标配（风格与结构解耦）。

## 三·五、Zero-卷积的梯度分析与多条件调度

零卷积不仅「保护预训练」，还有一层梯度动力学的考量：训练初期 $\Delta y = 0$ → 损失梯度全部流向控制分支 θ_c（主干冻结无梯度）——**控制分支拿到 100% 的学习信号**，收敛极快（几百步就能「画得像样」）。对比 adapter 类结构的梯度竞争，零卷积是「单车道」式训练。

**多条件的训练与推理调度**：

- 训练：多条件 ControlNet 可以联合训练（条件随机丢弃 → 学会组合），或分别训练后叠加权重；
- 推理的高级玩法：**条件的时间调度**——结构条件（深度/边缘）前 50% 步强控制定构图，后 50% 衰减放风格自由；这是「前期定骨架、后期长肉」的调度思想（与扩散的 coarse-to-fine 采样天然配合）。

参考图注入（IP-Adapter）的对比：ControlNet 注入「几何约束」（在哪怎么摆），IP-Adapter 注入「语义约束」（长什么样）——两者的注意力机制不同（cross-attn on image tokens vs 逐层相加），组合使用是文生图工作流的标配。

## 四、面试要点速答

1. **零卷积为什么零初始化？** 保证训练起点=原模型输出，微调不动预训练能力——增量学习控制而不遗忘画功。
2. **ControlNet 与 img2img 的区别？** 结构级注入（外挂网络，精确）vs 全图部分加噪（粗粒度、强度不可分区域调）。
3. **为什么条件能「只定结构不定纹理」？** 条件进的是编码器中低层（结构特征），纹理主要由噪声与去噪步决定——结构与质感的解耦。
4. **多条件冲突怎么办？** 权重分配（谁最想保谁大）、或分阶段控制（前期强后期弱）。
5. **IP-Adapter 与 ControlNet 的分工？** 参考「内容/风格」注入（像什么）vs 结构几何控制（在哪怎么摆）。
6. **ControlNet 思想的普适性？** 「冻结骨干+零初始化外挂」= 可控微调的通用模式（LoRA/T-2-I-Adapter 同宗）。
