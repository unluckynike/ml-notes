# 位置编码深读：从正弦编码到 RoPE

这篇是**位置编码与长上下文**主题的深度补充。注意力本身是「无序集合」运算，位置信息全靠外加——位置编码方案的演化（绝对→相对→旋转）是一条「如何优雅表达相对位置」的主线。RoPE 是当下的主流答案，这里把它的推导讲透。

> [!KEY] 一句话抓住本质
> RoPE 的目标只有一句话：**让两个 token 的注意力分数只依赖它们的相对位置**。做法是把 q、k 向量两两配对，按位置 m 旋转角度 $m\theta$——旋转的内积天然只含**角度差** $(m-n)\theta$，相对性自动成立。不改架构、不加参数，只改 Q/K 的变换方式。

---

## 一、三代方案的谱系

**第一代·绝对正弦（2017 Transformer）**：$PE_{pos}$ 按 sin/cos 公式生成加到输入。问题：模型要「自己」从绝对位置里学出相对关系；外推到训练长度之外无定义。

**第二代·可学习绝对（BERT/GPT-2）**：位置嵌入当参数学。表达更灵活，但**完全无法外推**（位置 513 没见过就没有嵌入），长上下文时代的硬伤。

**第三代·相对/旋转（当下主流）**：把「相对位置」直接编码进注意力计算——T5 相对偏置（分数加一个可学的标量偏置）、ALiBi（分数减去与距离成正比的罚——天然鼓励近处注意）、**RoPE**（下文）。三者对比：T5 偏置查表有外推上限；ALiBi 线性罚外推平滑但「远处的注意力」被系统性压制；RoPE 把位置揉进 Q/K 本身，与模型其余部分正交，成为 LLaMA/Qwen/DeepSeek 等的默认。

## 二、RoPE 推导：旋转的内积只看角度差

**目标**：找一个 $f(x, m)$（位置 m 的变换），使注意力分数

$$\langle f(q, m),\; f(k, n)\rangle = g(q, k, m-n)$$

只依赖相对位置 $m - n$。

**二维情形**：把 q 的前两维看成复平面上的复数 $q_1 + iq_2$，变换取**旋转**：

$$f(q, m) = q\,e^{im\theta}$$

则内积（复数共轭乘积的实部）：

$$\langle f(q,m), f(k,n)\rangle = \text{Re}\left[q\,\bar{k}\,e^{i(m-n)\theta}\right]$$

**只含 $(m-n)$**——目标达成，且这是唯一一类满足条件的正交变换（论文证明）。

**高维情形**：把 d 维两两配对成 d/2 个二维平面，每个平面用不同频率旋转：

$$\theta_j = 10000^{-2j/d},\qquad j = 0, 1, \ldots, d/2-1$$

高频分量（j 小）转得快、分辨相邻位置；低频分量转得慢、编码长程关系——与原始正弦编码的频率设计一脉相承（波长从 2π 到 10000·2π）。

**实现上**：在每层注意力的 Q/K 投影后、算分数前，对特征两两做旋转（拆分奇偶或前后半），不新增参数、不改变复杂度；V 不旋转（位置信息只用于「打分」，不进入被聚合的内容）。

> [!TIP] 为什么不把位置加到输入
> 加在输入只有一次注入（且逐层稀释）；RoPE 在**每层注意力的打分处**注入位置——位置信息贯穿全网络，长程对齐更稳。

**RoPE 十行**——把相邻维度对当平面坐标旋转，内积自动只看角度差：

```python
import numpy as np
def rope(q, pos, base=10000):
    d = len(q)
    out = np.empty_like(q)
    for i in range(0, d, 2):
        theta = base ** (-i / d)               # 低维转得快，高维转得慢
        c, s = np.cos(pos * theta), np.sin(pos * theta)
        out[i], out[i+1] = q[i]*c - q[i+1]*s, q[i]*s + q[i+1]*c
    return out

rng = np.random.default_rng(0)
q = rng.normal(size=8)
print(round(float(rope(q, 0) @ rope(q, 3)), 4),
      round(float(rope(q, 7) @ rope(q, 10)), 4))   # 两个内积相等：只依赖相对位置差
```

## 三、外推与「长上下文」的工程

RoPE 本身外推仍会退化：训练只见过 m−n 在窗口 W 内，超出后旋转角进入未见区域。主流外推方案都是**重新映射旋转角**：

| 方案 | 思路 |
|---|---|
| 位置内插（PI） | 位置除以缩放因子塞回窗口内——需少量微调 |
| NTK-aware / YaRN | 高频不缩、低频缩放（不同 j 用不同因子）——免微调或轻量微调 |
| 动态 NTK | 推理时按当前长度自适应缩放 |

配合「训练后期拉长窗口 + 长文本微调」，主流模型从 4K 扩到 128K+ 的标配路径就是 RoPE+YaRN 类方案。这也是「位置编码与长上下文」主题演示的数学背景。

## 常见误区

- **「正弦位置编码是固定的所以不如可学习的」** —— 正弦编码可以**外推到训练长度之外**（可学习的不能）；且实验显示两者性能差距极小——「固定」不是「劣」。
- **「RoPE 通过旋转编码了绝对位置」** —— RoPE 编码的是**相对位置**（通过 Q/K 的相对旋转角度）；绝对位置信息在注意力打分时被消除——这是它能泛化到更长序列的原因。
- **「ALiBi 比 RoPE 更好因为不需要训练」** —— ALiBi 的线性惩罚是简单但**限制了远程注意力的上限**；RoPE+插值/YaRN 在长上下文扩展上更灵活——各有适用场景。
- **「位置编码只加在输入层」** —— 原始 Transformer 在输入层加位置编码；但 RoPE 在**每层注意力**中注入（旋转 Q/K），ALiBi 在注意力分数中加偏置——现代方法分布在多个层级。

## 四、要点总结

1. **注意力为什么需要位置编码？** 自注意力对输入置换等变（对称），本身不含顺序。
2. **RoPE 的核心性质？** 旋转后的内积只依赖相对位置差——相对位置被「免费」编码进注意力分数。
3. **为什么对 Q/K 旋转而不旋转 V？** 位置只应影响「关注谁」（打分），不应混入「取什么内容」（聚合）。
4. **θ 的频率设计是什么？** 两两配对、频率从 $10000^0$ 到 $10000^{-1}$ 对数间隔——高频辨近、低频辨远。
5. **YaRN/NTK 与朴素内插的区别？** 朴素内插所有频率统一压缩（高频受害、局部关系糊掉）；NTK 系只压低频、保住高频的局部分辨率。
6. **ALiBi 与 RoPE 怎么选？** ALiBi 实现最简单、外推平滑但抑制远程注意；RoPE 表达力强、生态主流、外推靠 YaRN 类微调——当前开源模型几乎全在 RoPE 阵营。
