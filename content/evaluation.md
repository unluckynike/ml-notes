# 模型评估深读：指标家族、AUC 的真面目与校准

这篇是**模型评估与调参**主题的深度补充。面试与实战里，「选哪个指标」比「选哪个模型」错得更频繁。这篇把**混淆矩阵指标家族**、**AUC 的概率解释**、**不平衡场景的陷阱**和**概率校准**一次讲透。

> [!KEY] 一句话抓住本质
> 指标 = 你对「不同错误类型的代价」的量化声明。**先问「漏报和误报哪个更贵」，再选指标**——准确率、精确率、召回、F1、AUC 只是把这个问题回答成不同形状。

---

## 一、混淆矩阵全家桶

二分类把预测拆成 TP / FP / FN / TN，常见指标全是这四个数的比例：

| 指标 | 公式 | 回答的问题 | 什么时候看它 |
|---|---|---|---|
| 准确率 | $\frac{TP+TN}{\text{全部}}$ | 整体猜对多少 | **类平衡时才有意义** |
| 精确率 | $\frac{TP}{TP+FP}$ | 报出来的阳性有多少是真的 | 误报代价高（垃圾邮件拦截） |
| 召回率 | $\frac{TP}{TP+FN}$ | 真阳性抓到了多少 | 漏报代价高（癌症筛查、欺诈） |
| F1 | $\frac{2PR}{P+R}$ | P 与 R 的调和平均 | 无偏好地平衡两者 |
| Fβ | $(1+\beta^2)\frac{PR}{\beta^2 P + R}$ | β>1 偏召回、β<1 偏精确 | 有明确的代价不对称 |

**调和平均的用意**：F1 被「较小的一方」主导——P=1.0、R=0.1 时 F1 只有 0.18，算术平均却会给 0.55。想两头都好，必须**两头都真的好**。

> [!WARN] 准确率悖论（必考）
> 欺诈率 0.5% 的数据：全预测「正常」→ 准确率 99.5%，召回 0%。不平衡数据上**准确率是装饰品**；至少看 P/R/F1，最好再看下一节的 AUC 与 PR 曲线。

---

## 二、ROC 与 AUC：给「排序」打分

**ROC 曲线**：扫过所有阈值，画（FPR=FP/(FP+TN), TPR=召回）的轨迹。**AUC = 曲线下面积**，但更有用的解释是：

$$\text{AUC} = P(\text{score(随机正样本)} > \text{score(随机负样本)})$$

**AUC 就是「随机一对正负样本，模型把正的排在负的前面」的概率**。这解释了它的两大特性：

1. **与阈值无关**——衡量的是排序质量本身；
2. **对类不平衡稳健**——一对正负采样的概率不随正负比例变化（分子分母各自类内归一）。

读数基准：0.5 = 随机瞎猜；0.7~0.8 可用；0.8~0.9 良好。AUC 也有盲区：它对**分布整体平移不敏感**（只要排序不变），所以「概率准不准」要看第四节校准。

**PR 曲线**：画（召回, 精确率）。**极度不平衡时 PR 曲线比 ROC 信息量大**——负样本海量增加会拉低精确率，ROC 却几乎不动（TN 淹没在分母里）。经验法则：正样本 < 5% 时优先看 PR-AUC。

**多分类**：宏平均（每类算完取平均，类类平等）/ 微平均（先汇总 TP/FP 再算，样本平等）；报告里两个都给，差距大说明小类表现差。

## 三、阈值不是默认 0.5：按代价选

0.5 只是对称代价下的解。若漏报代价是误报的 C 倍，最优决策变成：

$$\text{判阳性} \Leftrightarrow P(y=1|x) > \frac{1}{1+C}$$

C=10（漏一个病人 = 误报十个正常人）时阈值应降到 ≈0.09。实务上更直接：**按业务 KPI（如召回 ≥ 95% 下精确率最大）在验证集上扫阈值**，把它当成一个普通超参管理。

---

## 四、校准：概率可信吗

很多场景要的是**概率本身**（风险定价、期望损失、贝叶斯决策），而不只是排序。校准回答：「模型说 70% 的那些事，是不是真的 70% 发生了？」

- **可靠性曲线（reliability diagram）**：把预测按概率分桶，画「预测均值 vs 实际发生率」，对角线 = 完美校准。
- **ECE（期望校准误差）**：分桶后 |预测 − 实际| 的加权平均，一个数说清偏差。
- **Brier 分数**：$(p - y)^2$ 的均值——同时惩罚排序错误和校准错误。

> [!NOTE] 神经网络普遍过自信
> 深度模型在测试集上 ECE 常达 0.05~0.15（说 0.9 的事只有 0.8 发生）。修法：**Platt 缩放**（对 logits 拟合一个 logistic）、**温度缩放**（验证集学一个标量 T 除 logits，不改排序、只改软硬度）、isotonic 回归（非参数）。树模型的预测概率也偏极端（叶节点平均），同样需要校准。

**评估流程避坑三则**：

1. **分层切分 + 交叉验证**：小数据单次切分方差大，5 折 CV 配「每折内调参、外层评估」的嵌套结构才不虚高。
2. **时间序列不能随机切**：随机切 = 用未来预测过去，必须按时间滚动验证。
3. **泄漏自查**：标准化/特征选择/缺失值填充只在训练折上 fit——`Pipeline` + `cross_val_score` 是防手滑的正确姿势。

## 五、面试要点速答

1. **AUC 的概率解释？** 随机正样本得分高于随机负样本的概率；与阈值无关、不平衡稳健。
2. **ROC-AUC vs PR-AUC 怎么选？** 类平衡看 ROC；正样本稀少看 PR（对类比例敏感恰恰是优点）。
3. **F1 为什么用调和平均？** 被短板主导，防止「一头 1.0 一头 0.1」混过算术平均。
4. **阈值怎么定？** 按误报/漏报代价或业务约束扫验证集；0.5 只是均等代价的特例。
5. **什么是校准、怎么修？** 预测概率 vs 实际频率的一致性；温度缩放/Platt/isotonic，验证集上拟合。
6. **准确率 99% 说明什么？** 先看类比例——0.5% 正率的欺诈数据上它等于「什么都没做」。
