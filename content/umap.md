# UMAP 深读：模糊单纯集与「为什么它比 t-SNE 快」

这篇是 **UMAP 流形学习**主题的深度补充。UMAP 常被当成「快版 t-SNE」，但它的数学出发点完全不同——**拓扑表示的对齐**（模糊单纯集），速度优势与「可 transform 新样本」都是这个出发点的副产品。

> [!KEY] 一句话抓住本质
> UMAP 在两边各建一个「模糊拓扑表示」：高维 = 局部自适应的 kNN 图（每个点用指数衰减的隶属度连接邻居），低维 = 一族指数距离曲线；然后**最小化两个拓扑的交叉熵**——边（吸引）与非边（排斥）分别对应两项。局部 σᵢ 自适应 + 负采样 + 稀疏图操作，让它比 t-SNE 的全配对优化快一个数量级。

---

## 一、高维侧：局部自适应的模糊图

对每个点 i，找 K 近邻，用指数核 $e^{-(d - \rho_i)/\sigma_i}$（ρᵢ = 到最近邻的距离，σᵢ 由目标 perplexity 解出）定义到邻居的隶属度 w ∈ (0,1]。三个讲究：

- **ρᵢ（局部偏移）**：最近邻的距离——保证第一个邻居的隶属度恰为 1（**每个点至少连着一个人**，密度低的区域不被剪掉）；
- **σᵢ（局部尺度）**：稀疏区放大 σ、稠密区缩小——**不同区域允许不同尺度**，这是它对密度不均数据比全局核稳的原因；
- **模糊并集**（概率和 max）对称化成无向图——t-SNE 用算术平均对称化，UMAP 用「或」语义（任一边强则边强）。

几何直觉：UMAP 假设数据**均匀采样**自黎曼流形，指数核近似测地距离的局部展开——「邻居关系」而非「欧氏距离」才是本质。

---

## 二、低维侧与损失：交叉熵的两项

低维用 $w_{low}(d) = \frac{1}{1+a\,d^b}$（可调 a,b 拟合期望的距离-概率曲线）。最小化：

$$C = \sum_{e \in E} w_h(e)\log\frac{w_h(e)}{w_l(e)} + \sum_{e \notin E} (1 - w_h(e))\log\frac{1 - w_h(e)}{1 - w_l(e)}$$

第一项：**图上的边在低维被拉近**（吸引）；第二项：**非边被推开**（排斥）。与 t-SNE 的 KL 同构，但：

- t-SNE 用 t 分布的重尾解决拥挤；UMAP 直接把排斥项做成**负采样**（随机抽非边算排斥）——计算从 O(n²) 降到近似 O(n·1.1)；
- **初始嵌入**用谱方法（图的拉普拉斯特征向量）而不是随机——起点就有全局结构，收敛快且稳。

**UMAP 的骨架**——高维侧「k 近邻模糊图」，低维侧吸引/排斥的 SGD 布局：

```python
import numpy as np
rng = np.random.default_rng(0)
X = rng.normal(size=(60, 8))
d2 = ((X[:, None] - X[None]) ** 2).sum(-1)
np.fill_diagonal(d2, np.inf)
k = 10
rho = np.sort(d2, axis=1)[:, k - 1]              # 第 k 近的距离（局部基准）
P = np.exp(-(d2 - rho[:, None]) * 2.0) * (d2 < rho[:, None])   # 只连 k 近邻
W = P + P.T                                      # 模糊并集（对称化）
W /= W.sum()
Y = rng.normal(size=(60, 2)) * 0.1
for it in range(300):                            # 低维侧：有边吸引、无边排斥
    i, j = rng.integers(0, 60, 2)
    if W[i, j] > 0:
        Y[i] -= 0.05 * W[i, j] * (Y[i] - Y[j])
    else:
        Y[i] += 0.02 * (Y[i] - Y[j]) / (0.1 + np.linalg.norm(Y[i] - Y[j])**2)
print('模糊图非零边:', int((W > 0).sum()), '| 布局后平均半径:',
      round(float(np.linalg.norm(Y, axis=1).mean()), 2))
```python
import numpy as np
rng = np.random.default_rng(0)
X = rng.normal(size=(60, 8))
d2 = ((X[:, None] - X[None]) ** 2).sum(-1)
k = 10
rho = np.sort(d2, axis=1)[:, k]                  # 到第 k 个邻居的距离（局部基准）
P = np.exp(-(d2 - rho[:, None]) / 1.0) * (d2 > rho[:, None])   # 局部连通强度
P_sym = P + P.T; P_sym /= P_sym.sum()            # 模糊并集（对称化）
Y = rng.normal(size=(60, 2))
for it in range(200):                            # 低维侧： SGD 拉/推
    i, j = rng.integers(0, 60, 2)
    if P_sym[i, j] > 0:
        Y[i] -= 0.01 * (Y[i] - Y[j])             # 吸引
    else:
        Y[i] += 0.001 * (Y[i] - Y[j]) / (0.1 + np.linalg.norm(Y[i]-Y[j]))  # 排斥
print(P_sym.round(3)[0][:8], Y.shape)
```

## 三、与 t-SNE 的实证差异

| 维度 | t-SNE | UMAP |
|---|---|---|
| 速度 | 慢（O(n²) 除非近似） | **快一个数量级** |
| 全局结构 | 弱 | 明显更好（簇间相对位置可参考） |
| 新样本 | 不能 transform | **可以**（嵌入函数可复用） |
| 参数稳定性 | perplexity 敏感 | n_neighbors 相对温和 |
| 降到 >2 维 | 不推荐 | 常用（特征工程可行） |

共同红线：**簇间距离都不能当精确度量**——UMAP 保留得更好 ≠ 可量化。

**两个关键超参**：`n_neighbors`（局部 vs 全局：小=细节碎簇、大=全局骨架）；`min_dist`（低维点的最小间距：小=紧密簇、大=松散布局）。

## 三·五、与 t-SNE 的定量对照实验设计（自己动手验证）

对「UMAP 保全局、t-SNE 保局部」的最好方式是自己做一次对照实验：

```python
# 三组数据各画 UMAP / t-SNE 各一次，固定随机种子
# 1. 真簇数据（digits）：两者都应分簇清晰 → 检验局部保真
# 2. 连续流形（swiss roll / MNIST 时间插值）：
#    UMAP 应保留「渐变连续性」，t-SNE 常碎成小岛 → 检验全局结构
# 3. 同分布重复采样两次：比较两次嵌入的「簇相对位置」稳定性
```

第三个实验最有说服力：t-SNE 两次运行的簇间布局差异大（局部最优随机），UMAP 的布局更可复现——**可复现性是 UMAP「全局结构更好」的可操作定义**。

**n_neighbors 与 min_dist 的调参直觉**：n_neighbors 小（5）= 碎片化细簇（细节多、全局碎）；大（100）= 全局骨架（簇合并、细节糊）。min_dist 小 = 簇内紧密成点团；大 = 松散云。业务建议：先 n_neighbors=15 / min_dist=0.1 起步，看「粒度是否匹配你的问题尺度」再调。

## 常见误区

- **「UMAP 的距离和簇与 t-SNE 一样不可信」** —— UMAP 基于流形距离（假设数据在低维流形上），在保留**全局结构**（簇间相对位置）上比 t-SNE 更好——但也不等于精确距离。
- **「UMAP 的 n_neighbors 越大 = 保留越多局部结构」** —— 恰好相反：n_neighbors 小 = 关注局部（更多碎片化小簇）、大 = 关注全局（更大的簇融合）——参数含义与直觉相反。
- **「UMAP 比 t-SNE 快所以总是更好的选择」** —— UMAP 快但保留的全局结构在某些数据集上可能引入「伪连接」（本应分开的簇被连接）——t-SNE 的局部保真度在某些任务更优。
- **「UMAP 可以像 PCA 一样用于特征提取（低维输出可直接当特征）」** —— UMAP 的嵌入不保距也不保角度——分类任务上可能可用（有论文支持），但回归/度量任务不适用；它首要服务于可视化。

## 四、要点总结

1. **UMAP 的核心思想？** 高低维各建模糊拓扑表示，最小化交叉熵对齐——图布局问题而非纯降维。
2. **ρᵢ 的作用？** 最近邻距离做局部偏移，保证每个点至少一条强边——稀疏区不被遗弃。
3. **为什么比 t-SNE 快？** 稀疏 kNN 图 + 负采样排斥（不必算全配对）+ 谱初始化。
4. **为什么能 transform 新样本？** 学到的是「图的嵌入函数」（沿边优化位置），新点按它到已有点的邻接关系定位。
5. **n_neighbors/min_dist 各调什么？** 前者管局部-全局权衡（邻居数），后者管低维簇的松紧。
6. **什么时候仍用 t-SNE？** 只要局部细节、不在乎速度与 transform；或需要与既有 t-SNE 结果对比时。
