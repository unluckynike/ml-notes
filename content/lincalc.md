# 线性代数与微积分深读：几何直觉的三层进阶

这篇是**线性代数与微积分**主题的深度补充。演示给了 2D 变换的直觉，这篇把它推进到深度学习实际使用的三层：**矩阵=变换的组合**、**特征分解=找主轴**、**梯度=高维地形的最陡方向**——并解释为什么 GPU 是「线性代数机器」。

> [!KEY] 一句话抓住本质
> 深度学习的全部计算由两种积木组成：**矩阵乘法**（线性变换的复合）与**逐元素非线性**（打破线性合并）。训练则由**链式法则**驱动（梯度沿计算图反传）。看懂这三样的几何意义，模型架构论文里的数学就不再吓人。

---

## 一、矩阵=变换：复合与「为什么是 GPU」

$y = Ax$ 的几何：A 把整个空间拉伸/旋转/剪切。**矩阵乘法 $AB$ = 先做 B 的变换再做 A 的**（复合）。深度网络的一层 = 一次线性变换 + 一次非线性：

$$h = \sigma(Wx + b)$$

为什么 GPU 是「AI 芯片」：矩阵乘法可以分解成海量**独立的乘加**（输出矩阵的每个元素是独立的点积）——GPU 的数千核心天然并行；这就是「AI = 线性代数」的硬件含义（见 AI 芯片深读的 Roofline）。

**形状速记**（面试常考）：$(m \times n) \cdot (n \times p) = m \times p$——内维必须相等；batch 维不动、特征维变换。Transformer 里的 QK^T：$(n \times d)(d \times n) = n \times n$（token 间的注意力矩阵）。

## 二、特征分解与 SVD：找「空间的主轴」

**特征向量** $Av = \lambda v$：变换下**方向不变**、只被伸缩 λ 倍的方向。它们回答的问题是：「这个变换的本质动作是什么？」

三个 AI 里的化身：

1. **PCA**：数据协方差矩阵的最大特征向量 = 数据最「摊开」的方向（见其深读）；
2. **谱聚类/Laplacian**：图拉普拉斯的最小特征向量 = 图的「天然切分」；
3. **Attention 的低秩性**：注意力矩阵近似低秩 → 可被 SVD 压缩（高效注意力的理论依据）。

**SVD（奇异值分解）** $X = U\Sigma V^T$：任何矩阵都能分解为「旋转 → 缩放 → 旋转」——比特征分解更通用（不需要方阵/对称）。它一次给出：最大奇异值方向=最重要的方向、截断小奇异值=最优低秩近似（PCA、LoRA 的数学都是它，见各自深读）。

## 三、梯度与链式法则：高维地形学

多元函数 f(x,y) 的**梯度** ∇f = (∂f/∂x, ∂f/∂y) 是一个**向量场**：每一点给出「最陡上升方向」。三个关键直觉：

1. **梯度⊥等高线**：等高线密集 = 陡峭（梯度大）——想象登山地图（见梯度下降深读）；
2. **链式法则 = 局部线性化的传递**：复合函数的导数 = 各层导数的**乘积**——反向传播就是「梯度从损失往回逐层乘」（见其深读的推导）；
3. **雅可比矩阵**：向量函数的梯度矩阵（每个输出对每个输入的偏导）——反向传播的每一步都是「乘以本层的雅可比」（通常是对角/稀疏/结构化，所以高效）。

**Hessian 与曲率**（进阶）：二阶导数矩阵描述「梯度本身怎么变化」——牛顿法用它走「曲率校正的步长」，深度学习里太贵（O(n²)），所以用一阶方法 + 自适应近似（Adam，见优化器深读）。

## 常见误区

- **「线性回归的『线性』是指变量之间是线性关系」** —— 「线性」指**参数**的线性（β 的系数为 1）；特征可以是 x²、log(x) 等非线性变换——「线性模型」能拟合非线性关系。
- **「R² 越接近 1 模型越好」** —— R² 随特征增加**单调不减**（即使新增的是噪声特征）——用调整 R²/AIC/BIC 或交叉验证评估；R² 高也可能是过拟合。
- **「矩阵可逆 = 模型可解」** —— 数学上可逆 ≠ 数值上稳定：条件数大时浮点精度丢失严重——用 SVD/QR 或正则化（岭回归）而非直接求逆。
- **「相关系数 = 因果强度」** —— 相关系数是**对称**的（x~y = y~x），不含方向信息——因果需要额外假设（无混淆/时间顺序/机制），这是因果推断主题的核心。

## 四、要点总结

1. **矩阵=变换**：乘法=复合，列向量=基的像；网络层=「线性变换+非线性」。
2. **特征向量/值**：方向不变的方向与其伸缩倍数——PCA/谱方法/低秩近味的共同根源。
3. **SVD**：任意矩阵=旋转·缩放·旋转；截断=最优低秩近似（PCA/LoRA 的数学）。
4. **梯度⊥等高线**：最陡上升方向；负梯度=最速下降。
5. **链式法则=雅可比连乘**：反向传播的本质；形状内维相等的速记。
6. **GPU=线性代数机器**：矩阵乘可完全并行——AI 与硬件的共生由此而来。
