# 贝叶斯调参深读：代理模型与采集函数

这篇是**模型评估与调参**主题的深度补充。网格/随机搜索是「无记忆的」，贝叶斯优化（BO）的每一步**利用全部历史**——代理模型 + 采集函数的组合拳。这篇讲清这两个组件、以及 BO 在什么条件下反而不如随机搜索。

> [!KEY] 一句话抓住本质
> 贝叶斯优化 = **用概率模型（通常是高斯过程）近似「超参→性能」这个昂贵的黑函数**，在代理模型上优化一个「采集函数」决定下一个试验点——平衡「 exploitation（去均值好的地方）」与「 exploration（去方差大的地方）」。每步都值钱时它才划算。

---

## 一、两个组件

**① 代理模型（高斯过程）**：对已评估点拟合「性能 f(x)」的分布——任意点给出**均值 μ(x)（猜测）与方差 σ²(x)（不确定度）**。GP 的直觉：核函数（如 RBF）假设「相近的超参性能相近」，评估越多、不确定带越窄。

**② 采集函数（Expected Improvement 最常用）**：回答「下一个点试哪」——EI 取「相对当前最优的期望改进量」：

$$\text{EI}(x) = \text{E}\left[\max(f(x) - f_{\text{best}},\; 0)\right]$$

解析形式（正态假设下）平衡两端：

- 均值低（好）→ 改进潜力大 → EI 高（**exploit**）；
- 方差大（未知）→ 可能藏着惊喜 → EI 高（**explore**）。

EI 恰好把「好 + 不确定」组合成单值——本站演示画的就是这条橙线（代理均值、不确定带、EI 曲线三者联动）。

## 二、与网格/随机的对比

| | 网格 | 随机 | 贝叶斯 |
|---|---|---|---|
| 利用历史 | 否 | 否 | **是** |
| 低维（<5）稠密预算 | 可 | 可 | 有优势 |
| 高维/混合类型 | 差 | 尚可 | 需改造（TPE/退化核） |
| 并行友好 | 是 | 是 | 差（串行性是它的本质优势） |
| 实现成本 | 零 | 零 | 需要代理+采集（库解决） |

**BO 什么时候不划算**：单次试验便宜（评估秒级→直接随机搜几千次）；超参高维且离散（GP 核失效——用 TPE，Hyperopt/Optuna 的默认）；并行资源多（BO 的贪心串行逻辑吃亏——批量 BO 是活跃研究）。

**低维有效性的原因**：BO 的优势 = 每步信息增益 × 评估成本；维度升高 GP 的样本复杂度爆炸——**实战黄金区间是 2~10 个连续超参**（学习率、正则、深度这种「每个都贵」的场景）。

## 三、流程与实操

```
初始化：随机撒 n₀ 个点评估（ GP 需要种子）
循环：
    GP 拟合历史 (x_i, y_i)
    最大化 EI 选 x*
    真实评估 f(x*)（训练+验证）
    加入历史
直到预算耗尽
```

实操三则：

- **对数空间采样**：学习率、正则强度跨数量级——先取 log 再进 GP；
- **预算管理**：BO 适合「贵评估」（几天的大训练）；配 Hyperband/Successive Halving 可淘汰差配置的中途（多保真优化）；
- **别过度信任代理**：EI 的探索在预算后期应该衰减（fallback 到最佳点的局部搜索）。

工具：Optuna（TPE，工程首选）、scikit-optimize（GP）、Ax/BoTorch（研究级）。

## 常见误区

- **「贝叶斯优化一定优于网格/随机搜索」** —— BO 的优势在高维连续空间+昂贵评估；低维离散空间或评估便宜时随机搜索打平甚至更好——方法选择取决于问题结构。
- **「搜索到的最优超参可以迁移到其他数据集」** —— 最优超参与数据规模/特征分布/模型架构高度耦合——跨数据集只有「方向性参考」没有「精确迁移」。
- **「Early stopping 是超参数调优的一部分」** —— Early stopping 本身就是正则化手段（限制模型复杂度）；与学习率/正则化系数存在交互效应——应纳入搜索空间而非固定。
- **「搜索空间越大越可能找到好结果」** —— 空间过大导致搜索稀疏化（好区域可能完全没被探索到）；先缩空间再搜索——空间设计比策略选择更重要。

## 四、要点总结

1. **BO 的两个组件？** 代理模型（GP/TPE：均值+不确定度）与采集函数（EI/UCB：决定下一点）。
2. **EI 如何平衡探索利用？** 均值低→期望改进大；方差大→可能超预期——两者在 EI 的解析式里相加。
3. **BO 的黄金适用域？** 评估贵（训练久）+ 低维连续超参（2~10）；便宜评估直接随机。
4. **GP 为什么高维失效？** 样本复杂度随维度爆炸，核函数的「相近性」假设稀释。
5. **TPE 是什么？** 用「好/差两组样本的密度比」当代理——不需要 GP，天然支持离散/条件超参（Optuna 默认）。
6. **多保真优化是什么？** 用低保真（少 epoch/小子集）快速淘汰，真预算只给幸存者（Hyperband/BOHB）。
