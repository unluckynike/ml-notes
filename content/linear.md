# 线性回归深读：正规方程、投影视角与 BLUE

这篇是**线性回归**主题的深度补充。线性回归是「最简单的模型」，但它的三个视角——**代数（正规方程）、几何（投影）、统计（高斯-马尔可夫）**——是所有监督学习的原型。考它往往不是考模型本身，而是考你对基础的理解深度。

> [!KEY] 一句话抓住本质
> 最小二乘解 $\hat{\beta} = (X^{\text{T}}X)^{-1}X^{\text{T}}y$ 有三层身份：代数上是正规方程的解；几何上是 **y 向 X 列空间的正交投影**；统计上是高斯噪声假设下的最大似然估计，且在无偏线性估计里方差最小（BLUE）。

---

## 一、三条路线推同一个解

**路线 A·矩阵求导**：$\min \lVert y - X\beta\rVert^2$ 对 β 求导置零：

$$X^{\text{T}}(y - X\beta) = 0 \;\Rightarrow\; X^{\text{T}}X\beta = X^{\text{T}}y \;\Rightarrow\; \hat{\beta} = (X^{\text{T}}X)^{-1}X^{\text{T}}y$$

**路线 B·几何投影**：$X\beta$ 张成列空间（n 维空间里的 p 维子空间），找「离 y 最近的子空间点」= **y 的正交投影**；残差垂直于子空间即 $X^{\text{T}}e = 0$——与正规方程一字不差。这个视角直接解释：残差与所有特征正交（相关性为零）。

**路线 C·最大似然**：$y = X\beta + \epsilon,\ \epsilon\sim N(0,\sigma^2)$，负对数似然展开后只剩 $(y-X\beta)^2$ 项——**最小二乘 = 高斯噪声的 MLE**（换噪声分布就换损失，见损失函数深读）。

**三条路线跑一遍**——两条闭式路解出的 β 应当完全一致（约 1e-15），梯度下降则从另一头逼近同一个解：

```python
import numpy as np
rng = np.random.default_rng(0)
X = np.column_stack([np.ones(100), rng.normal(size=(100, 3))])  # 首列=截距
beta_true = np.array([2., -1., .5, 3.])
y = X @ beta_true + rng.normal(scale=0.1, size=100)

beta_ne  = np.linalg.solve(X.T @ X, X.T @ y)   # 路线 A：正规方程
beta_svd = np.linalg.pinv(X) @ y               # 路线 B/C：SVD（sklearn 的实际路径）
b = np.zeros(4)                                # 第四条路：梯度下降
for _ in range(300):
    b -= 0.1 * X.T @ (X @ b - y) / len(y)

print(np.abs(beta_ne - beta_svd).max())        # ~1e-15：两条闭式路严格一致
print(np.abs(b - beta_ne).max())               # ~1e-12：GD 也收敛到了同一个解
```

## 二、高斯-马尔可夫：为什么「最小二乘」不是随便选的

条件：线性于参数、随机采样、无完全共线、外生性（E[ε|X]=0）、同方差无自相关。结论：

**OLS 在所有「线性无偏」估计中方差最小（BLUE）。**

两条务实推论：

1. **它不是万能最优**：「线性无偏」约束下最优；引入偏差（岭回归）可以换更小的均方误差——正则化的正当性来源（见岭回归深读）。
2. **假设破了会怎样**：异方差 → 标准误失真（用稳健标准误）；自相关（时间序列）→ OLS 仍无偏但效率低；内生性（特征与噪声相关，如遗漏变量/反向因果）→ **有偏**，这是因果推断要处理的核心问题（见因果推断主题）。

## 三、工程问题速查

| 现象 | 原因 | 处置 |
|---|---|---|
| $X^{\text{T}}X$ 不可逆 | 完全共线/特征多于样本 | 岭回归（加 λI）、删特征、PCA |
| 系数符号与直觉相反 | 多重共线 | VIF 检查、正则、看偏相关 |
| 残差呈喇叭形 | 异方差 | 加权 LS / 变换 y（log） |
| 残差有曲线结构 | 缺非线性项 | 加多项式/样条/换模型 |
| 一个离群点撬动整条线 | 平方损失对大残差敏感 | Huber/Robust 回归 |

**闭式解 vs 梯度 descent**：n 大 p 大时 $(X^{\text{T}}X)^{-1}$ 是 O(p³) 且矩阵巨大——SGD/拟牛顿更实际；p 小（<1万）闭式一步到位且数值精确。

## 三·五、正规方程的数值稳定性与中心化公式

$(X^{\text{T}}X)^{-1}$ 的条件数是特征缩放比的平方——量纲悬殊的特征（收入分 vs 年龄岁）让矩阵病态，浮点求逆丢精度。三个工程对策：

1. **标准化后再求逆**（等价于把 X 的列缩放归一）；
2. **QR 分解**：X = QR，$\hat\beta = R^{-1}Q^{\text{T}}y$——条件数只有原矩阵的（数值上是求逆的更稳路径，LAPACK 的实际实现）；
3. **SVD**：最稳（小奇异值截断 = 隐式岭回归），sklearn 的 `LinearRegression` 底层就是 SVD。

**中心化的等价形式**：带截距的线性回归 = 先对 y 与所有特征去均值，再在原点拟合无截距模型——截距就是「均值方程」：

$$\hat\beta_0 = \bar{y} - \sum_j \hat\beta_j \bar{x}_j$$

这解释了「为什么标准化后系数可比较」「为什么删掉一个共线特征其余系数会跳」——共线的贡献在系数间任意分摊，去掉一个，其余的立即吸收它的份额。

## 常见误区

- **「线性回归的系数 = 因果效应」** —— OLS 系数 = 相关性的线性分解；因果解释需要「无混淆假设」（所有混淆变量已被控制）；遗漏变量偏差使系数≠因果效应。
- **「线性回归不能处理分类变量」** —— 通过 one-hot/dummy 编码，线性回归可以处理分类变量；编码方式（reference class 的选择）影响系数解读。
- **「R² 高 = 好模型」** —— R² 随特征增加单调不减；高 R² 可能来自过拟合、伪回归或数据泄漏——需要看调整 R²/交叉验证/残差分析。
- **「线性回归对异常值不敏感（因为是全局拟合）」** —— OLS 最小化平方误差——对离群值极其敏感；一个极端点可以拉偏整条回归线。

## 五、多项式特征与正则化路径

线性模型通过**多项式特征扩展**可以拟合非线性关系：

$$x \rightarrow [x_1, x_2, x_1^2, x_2^2, x_1x_2]$$

sklearn 的 `PolynomialFeatures(degree=2)` 自动生成交互项与平方项——配合岭回归/Lasso 构成「多项式岭回归/多项式 Lasso」——**在保持「参数线性」的前提下引入「特征非线性」**。

**正则化路径（Regularization Path）**：λ 从 ∞ 到 0 扫描时系数的变化轨迹——Lasso 的路径展示「特征逐个进入模型」的顺序（LARS 算法高效计算整条路径）——这条路径本身就是特征重要性的排序。

## 六、线性模型的现代应用

尽管深度学习火热，线性模型在以下场景仍是首选：

- **高维稀疏数据**（文本/广告 CTR）：LR + FTRL 在线学习是广告系统的标配
- **可解释性要求高**（金融风控/医疗诊断）：系数可直接解读，监管友好
- **样本极少**（n < 100）：线性模型的方差低（偏差虽高但总误差可能更低）
- **需要概率校准**：逻辑回归天然校准（vs 树模型的分数需要后处理）

## 四、要点总结

1. **正规方程怎么推？** 平方损失对 β 求导置零：$X^{\text{T}}X\beta=X^{\text{T}}y$；要求 X 列满秩。
2. **投影视角说明什么？** 拟合值是 y 在列空间的正交投影，残差与每个特征正交（内积为零）。
3. **高斯-马尔可夫说了什么？** 五假设下 OLS 是 BLUE；破坏任一假设的后果要能列出。
4. **MSE 视角与 MLE 的关系？** 高斯噪声 MLE ≡ 最小二乘；换拉普拉斯噪声 → 最小绝对值回归（中位数回归）。
5. **什么时候 X^TX 不可逆？** 特征共线或 p>n；岭回归加 λI 恢复正定（同时改善条件数）。
6. **R² 与调整 R²？** R²=1−SSE/SST 随加特征单调升；调整 R² 按自由度罚，用于比较不同规模模型。
