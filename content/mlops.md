# MLOps 深读：模型只是冰山一角

这篇是**MLOps 与监控**主题的深度补充。模型上线不是终点——**数据在漂移、用户在变化、系统在腐化**。这篇讲清 ML 系统与普通软件的本质差异（为什么 MLOps 不是「DevOps + 模型」）、两级监控（数据/模型）的实现，以及一个机器学习项目的全生命周期检查点。

> [!KEY] 一句话抓住本质
> ML 系统与普通软件的差别只有一个词：**数据依赖**。代码不变、世界在变——模型的行为随输入分布漂移而失效（这是普通软件没有的故障模式）。MLOps 的核心 = 把「数据与分布」纳入版本管理、测试与监控，让模型像代码一样可回滚、可观测。

---

## 一、ML 系统的特殊故障模式

- **数据漂移（data drift）**：输入分布 P(X) 变了（用户画像随年代变化）；
- **概念漂移（concept drift）**：P(Y|X) 变了（欺诈手法升级、疫情改变消费行为）——更致命，因为「对的关系」本身变了；
- **反馈环（feedback loop）**：模型的预测影响它未来的训练数据（推荐系统只见过「被推荐过的物品」的反馈）——自我强化偏差；
- **静默失败**：模型不报错、只是悄悄变差——**没有监控的模型 = 没有错误处理的代码**。

## 二、两级监控

**第一级·数据监控（模型外）**：

- 输入特征分布 vs 训练分布：**PSI（群体稳定性指数）**、KL 散度、KS 检验——PSI > 0.25 通常触发告警；
- 类别特征的取值集变化（新类别出现=模型不认识它）；
- 缺失率、延迟、数据管道 SLA——**上游数据坏了，模型再好也白搭**（这是最常见的假警报根源）。

**第二级·模型监控（模型内）**：

- 标签可得时：真实性能指标（AUC/MAE）按时间切片监控——金标准但延迟（标签要等）；
- 标签延迟/不可得时：**代理信号**（预测分布的稳定性、校准漂移、置信度分布）+ 真实业务 KPI（转化率/坏账率）；
- 性能分群监控：整体指标正常、某个人群已崩（公平性/长尾问题）。

**报警哲学**：与 SRE 相同——有 runbook、有分级、有回滚预案。**模型回滚 = 旧模型+旧特征管线一起回滚**（特征变换不兼容是常见翻车点）。

## 三、生命周期检查点

| 阶段 | 关键实践 |
|---|---|
| 数据 | 数据版本化（DVC/lakeFS）、数据契约（schema 断言）、泄漏检查 |
| 训练 | 实验跟踪（MLflow/W&B：参数+指标+产物）、可复现（种子+环境锁定） |
| 评估 | 离线基准 + 切片分析（subgroup）、公平性审计 |
| 部署 | 影子模式（shadow：并行打分不上线）、金丝雀发布、A/B（因果验证，见因果推断深读） |
| 运维 | 两级监控、漂移告警、定时/触发式重训、模型注册表（版本+审批） |
| 治理 | 特征商店（训练/在线一致性）、审计日志、模型卡 |

**影子模式与金丝雀**：新模型先「影子运行」（只记录不生效）对比线上行为 → 小流量金丝雀 → 全量——三层缓冲把「静默失败」变成「可观测的渐进发布」。

## 三·五、特征商店与训练-在线偏差

ML 系统最阴险的一类 bug：**训练特征与在线特征不一致**（training-serving skew）。离线特征从数仓算（批处理，准确），在线特征实时算（低延迟，近似）——两边实现不同、更新时刻不同，模型吃到的分布悄悄不同。特征商店（Feature Store）的 raison d'être：

- **一份定义两处执行**：特征逻辑只写一次（Python UDF/SQL），离线回填与在线点查共用——从根上消除 skew；
- **时间旅行（point-in-time correctness）**：训练样本取「当时那一刻」的特征值而非最新值——防止特征泄漏（用未来数据训练，与因果推断深读的时序泄漏同源）；
- **在线物化**：预计算 + 缓存热点特征，在线 P99 < 10ms。

**LLM 时代的新形态**：RAG 索引的「新鲜度监控」（文档更新到索引生效的延迟）、prompt/评测集的版本化——特征商店的思想从「特征」扩展到「一切进入模型上下文的资产」。

## 四、面试要点速答

1. **数据漂移与概念漂移的区别？** P(X) 变 vs P(Y|X) 变——后者更致命（关系本身变了）。
2. **为什么说模型会静默失败？** 不抛异常、只慢慢变差——没有分布/性能监控就无从察觉。
3. **PSI 是什么、阈值多少？** 群体稳定性指数（分布距离的经验度量）；>0.1 关注、>0.25 告警（金融业惯例）。
4. **标签延迟时怎么监控模型？** 代理信号（预测分布/校准漂移）+ 业务 KPI；标签到了补算真实指标。
5. **反馈环怎么防？** 随机曝光/探索流量保留「无偏数据」；对齐训练数据与真实分布。
6. **影子模式的用途？** 新模型并行打分不上线——零风险对比行为差异，是金丝雀前的安全网。
