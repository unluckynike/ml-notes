# 迁移学习深读：预训练-微调范式的工程学

这篇是**迁移学习**主题的深度补充。现代 AI 的默认形态就是迁移学习：**ImageNet/海量语料预训练 + 下游微调**。这篇讲清三种迁移姿势的选择、微调的超参学问、以及「负迁移」什么时候发生。

> [!KEY] 一句话抓住本质
> 迁移学习 = 把「源任务学到的表示」搬到目标任务。核心事实：**底层特征是通用的（边缘/纹理/句法），高层特征是任务相关的（物体/语义）**——所以迁移的主要自由度是「冻结多少层、用多小的学习率微调哪些层」。

**线性探针 vs 全量微调**——同一个预训练特征，两种迁移的差距：

```python
import numpy as np
rng = np.random.default_rng(0)
n, d = 300, 16
X_src = rng.normal(size=(n, d))
W_true = rng.normal(size=(d, 2))
F = np.column_stack([np.tanh(X_src @ W_true),                # 与任务相关的方向（好预训练）
                     np.tanh(X_src @ rng.normal(size=(d, 7)))])  # 其余随机方向
y = (np.tanh(X_src @ W_true)[:, 0] > 0).astype(int) * 2 - 1

def train_logistic(X, y, iters=500, lr=0.1):
    w = np.zeros(X.shape[1])
    for _ in range(iters):
        p = 1 / (1 + np.exp(-X @ w))
        w -= lr * X.T @ (p - (y + 1) / 2) / len(y)
    return w

Xtr, ytr = F[:250], y[:250]; Xte, yte = F[250:], y[250:]
w = train_logistic(Xtr, (ytr + 1) / 2)
acc = float(np.mean(((Xte @ w > 0).astype(int) * 2 - 1) == yte))
print('线性探针准确率:', round(acc, 3), '（特征含相关方向 → 冻结即可用；特征差则必须微调）')
```

## 一、三种姿势：从轻到重

| 姿势 | 冻结情况 | 数据需求 | 适用 |
|---|---|---|---|
| **特征提取** | 全冻结，只训新头 | 极少（几百） | 目标数据小、源域近 |
| **微调（fine-tune）** | 全部或顶部解冻 | 中等（千级） | 默认选择 |
| **零样本/提示** | 不更新任何权重 | 0 | 基础模型时代（CLIP/GPT） |

**判别式学习率**是微调的标配技巧：底层（通用特征）用小学习率（如 1e-5）防破坏，高层（任务相关）用大学习率（1e-4~1e-3）。分层冻结/解冻的「渐进解冻」也常见：先只训头几轮，再逐层放开。

**三层困境**：目标数据量 × 源域相似度的 2×2 矩阵决定策略——

- 数据少 + 域近：特征提取即可；
- 数据少 + 域远：只微调高层 + 强正则（数据太少动底层必炸）；
- 数据多 + 域近：放心全参数微调；
- 数据多 + 域远：考虑「预训练权重当初始化」甚至从头训。

## 二、微调的工程细节

- **小学习率**：预训练权重已在好盆地里，1e-5~1e-4 量级；大 lr 等于「先摧毁再重建」（灾难性遗忘）；
- **早停看验证集**：微调过拟合来得很快（几轮内）；
- **warmup + 衰减**：动量/自适应优化器的统计量对新任务头几步不稳；
- **数据增广照常**：微调不是免死金牌，目标域过拟合照样发生；
- **NLP 的现代变体**：全参数微调 → **LoRA**（参数高效，见其深读）→ 提示/适配器（零训练成本），谱系一路轻量化。

## 三、域偏移与负迁移

**负迁移**（迁移后不如从头训）什么时候发生：源与目标的**底层统计都不同**（医学影像 vs 自然照片、目标域小还要动底层）。对策：

- **域适配**：学「域不变特征」——DANN（对抗：让判别器分不清特征来自哪个域）、MMD（最小化两域特征分布距离）；
- **自监督续训**：先在目标域无标签数据上继续自监督预训练，再微调（与自监督深读衔接）；
- **诊断信号**：目标域验证曲线在「解冻更多层」时变差 → 过度迁移，回退冻结。

**分布漂移 vs 域偏移**：域偏移是「训练与部署环境不同」（摄像头不同）；漂移是「部署后环境随时间变」（用户行为变化）——后者归 MLOps 监控管（见其主题）。

## 三·五、微调的灾难性遗忘与缓解

全参数微调的根本风险：新任务梯度把预训练权重推向新最优，**旧能力系统性退化**（catastrophic forgetting）。度量：微调后跑预训练时的标准基准（通用问答/图像分类），掉分超过 5% 即明显遗忘。

缓解的梯度：

| 手段 | 原理 | 代价 |
|---|---|---|
| 小学习率 | 别走出旧盆地太远 | 收敛慢 |
| **EWC** | 对「对旧任务重要的参数」加二次罚（Fisher 信息加权） | 要估 Fisher，二阶成本 |
| **LoRA** | 冻结基座，增量在低秩子空间——旧能力物理上无法被改写 | 容量上限（见 LoRA 深读） |
| **回放（replay）** | 微调数据里掺预训练分布样本 | 需要保留旧数据（隐私/存储） |

**实践配方**：微调 LLM 的默认 = LoRA（结构上免疫遗忘）+ 掺 5~10% 通用数据（保住对话与指令能力）+ 微调后在通用基准上回归测试——「别忘了老本事」需要被当成显式验收项。

## 常见误区

- **「预训练权重越强微调效果一定越好」** —— 更强的预训练模型在**域差异大**的目标任务上可能因「负迁移」而劣于弱模型+充分微调——源域与目标域的距离是关键变量。
- **「微调的学习率应该和预训练一样大」** —— 微调用大学习率会**灾难性遗忘**预训练知识（权重被大幅重写）；微调学习率通常比预训练小 10~100×（如 2e-5 vs 2e-4）。
- **「冻结底层只微调顶层总是安全的」** —— 当目标任务的**底层特征**与预训练不同（如 X光 vs 自然图像），冻结底层会阻止必要的低级特征适配——逐层解冻（discriminative lr）是更好的策略。
- **「预训练-微调范式对 Transformer 没有用（Transformer 是从零训练的）」** —— GPT/BERT/T5 全部使用「预训练→微调」——Transformer 的成功恰恰是这个范式最有力的证明（与 CNN 时代的 ImageNet 预训练同构）。

## 四、要点总结

1. **为什么底层特征可迁移？** 底层学到的是通用统计（边缘、纹理、n-gram），跨任务/跨域近似不变；高层任务相关。
2. **特征提取与微调怎么选？** 数据量 × 域相似度矩阵：小数据近域用前者；不确定时先跑特征提取基线再微调对比。
3. **微调为什么要小学习率/判别式学习率？** 预训练权重是优质起点，大步长破坏（灾难性遗忘）；底层更通用更该小动。
4. **什么是负迁移、怎么诊断？** 迁移后不如从头训；解冻更多层验证变差是信号——回退冻结或先做域适配。
5. **LoRA 与全参数微调的关系？** 参数高效微调：冻结基座只学低秩增量；行为适配接近全参、成本数量级降低。
6. **零样本迁移的前提？** 源任务足够通用（基础模型：CLIP 的图文对齐、GPT 的指令泛化）——任务定义方式本身被搬过来了。
