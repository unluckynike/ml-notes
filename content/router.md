# 模型路由深读：级联设计、置信度信号与成本的完整账

这篇是**模型路由与成本**主题的深度补充。演示里级联策略落在成本-质量的甜点位，这篇讲生产级的三个深水区：**升级判据（置信度从哪来）**、**完整成本账（显性+隐性）**、以及**路由器的训练与校准**。

> [!KEY] 一句话抓住本质
> 模型路由的本质是**按需分配不确定性预算**：简单的请求不值得花旗舰的钱，但「判断这个请求简不简单」本身需要一个信号。级联用「小模型的自我评估」当信号，路由器用「分类器预测」当信号——**信号的质量决定整个系统的质量**。

---

## 一、升级判据：四种置信度信号

级联的核心问题：「小模型的这个回答，可信吗？」四种信号从弱到强：

1. **logprob（对数概率）**：小模型输出 token 的平均概率——最便宜，但模型可能「流畅地自信」（错误回答的概率也不低）；
2. **自评估**：让小模型自评「1~10 分你多确定」——部分有效，但模型普遍过度自信（需校准，见模型评估深读）；
3. **一致性（self-consistency）**：采样 3~5 次看答案是否一致——一致 = 大概率对；成本 ×3~5，但只对升级判断的边缘 case 用；
4. **验证器**：可执行验证（代码跑测试、数学对答案）——最强信号，只对可验证任务可用。

**级联的工程形态**（FrugalGPT）：小模型答 → 用上述信号判「可靠吗」→ 不可靠升级到下一级（中→大→大+更长思考）——**每级只处理上一级漏下的**。阈值在验证集上校准：定在「升级成本节省 vs 质量损失」的最优点。

---

## 二、完整成本账：显性与隐性

**显性成本**（API 账单）：

- token 单价 × 输入/输出 token 量——prompt 缓存（重复前缀半价/免费）与 batch API（半价）先吃掉大头；
- 模型价差：旗舰 vs 小模型 10~50×——级联节省的主要来源。

**隐性成本**（常被漏算）：

- **重试率**：小模型失败重试的成本（重试率 20% 时，名义便宜 10× 实际只省 8×）；
- **延迟差异**：小模型快不仅是省钱——用户感知（延迟也是体验成本）；
- **多模型维护**：prompt 在不同模型间不通用（评测×N、迁移成本×N）；
- **路由器本身的成本与错误**：路由分类器的推理成本 + 路由错误的质量损失。

**语义缓存**（最强的省钱手段）：「问过的问题」直接回缓存——用嵌入匹配「语义相同」的问题（相似度阈值 + 缓存 TTL）。命中率 30% 就省 30% 账单；风险是「过时答案」（知识更新后缓存作废——TTL 与失效策略是关键）。

## 三、路由器的训练与校准

**分类器路由**（RouteLLM 路线）：训练一个小模型预测「这个请求旗舰 vs 小模型的质量差」，差大才路由给旗舰——

- **训练数据**：离线跑「同一批请求在两个模型上的回答 + LLM 裁判打分」得到偏好对；
- **特征**：查询 embedding + 元特征（长度/语言/任务类型）；
- **校准**：路由器的「升级概率」要映射到真实质量差（可靠性曲线，见模型评估深读）——不然阈值形同虚设。

**不完美的路由器也有价值**：路由准确率 80% 的分类器仍能省 50%+ 成本（错路由的 20% 里一半只是「多花了钱」）——**期望成本的计算**（见演示的四种策略对比）会告诉你阈值放哪最划算。

## 常见误区

- **「模型路由 = 总是选最便宜的能用的模型」** —— 路由不只是成本优化：不同模型有不同延迟/专业能力/上下文长度/多模态支持——路由是**多维决策**（成本+延迟+能力+合规），不是一维的「哪个便宜用哪个」。
- **「级联路由（先便宜后贵）总能省钱」** —— 级联引入**额外延迟**（小模型先跑一遍再决定是否升级）——对于延迟敏感的实时场景，级联反而增加首 token 延迟。
- **「路由器需要训练才能用」** —— 基于规则的简单路由（按长度/语言/关键词分类）零训练即可部署且效果稳定——ML 路由器（RouteLLM）是进阶选项不是必需品。
- **「路由策略一经部署就不需要调整」** —— 模型生态（新模型/价格变化）与用户分布持续变化——路由策略需要定期评估与更新（如同 MLOps 深读的模型监控）。

## 四、要点总结

1. **级联 = 不确定性预算的按需分配**：多数请求停在便宜层，难的才升级。
2. **四种置信度信号**：logprob（弱）→ 自评估 → 一致性 → 验证器（强）；信号质量决定系统质量。
3. **完整成本账**：单价×token 只是显性；重试、延迟、维护、路由错误都是成本。
4. **语义缓存优先于路由**：能不调用就不调用——命中率即节省率。
5. **路由器要校准**：升级概率映射真实质量差（可靠性曲线），80% 准确率已能省过半。
6. **Agent 场景的分层路由**：规划步骤用旗舰、工具调用与格式化用小模型——按步骤类型而非整个任务路由。
