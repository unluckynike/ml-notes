# HMM 与卡尔曼滤波深读：贝叶斯滤波的统一骨架

这篇是 **HMM 与卡尔曼滤波**主题的深度补充。演示里的「预测-更新」两步是所有贝叶斯滤波的公共骨架，这篇讲清这个骨架的数学、HMM 三大问题的算法细节、以及粒子滤波如何接住「非线性非高斯」的烂摊子。

> [!KEY] 一句话抓住本质
> 一切贝叶斯滤波都是同一个循环：**预测**（用运动/转移模型把旧信念往前推）+ **更新**（用贝叶斯定理让新观测校正信念）。卡尔曼是这个循环在「线性+高斯」下唯一的闭式解；HMM 是「离散」下的精确解；粒子滤波是用采样逼近任意分布的通用解。

## 一、统一骨架：预测-更新循环

隐状态 $x_t$ 演化、观测 $z_t$ 带噪。信念 = 后验分布 $bel(x_t) = P(x_t | z_{1:t})$：

**预测步**：$bel^-(x_t) = \int P(x_t|x_{t-1})\, bel(x_{t-1})\, dx_{t-1}$（信念沿转移模型推进一步，因过程噪声而变宽/变模糊）

**更新步**：$bel(x_t) \propto P(z_t|x_t)\, bel^-(x_t)$（用观测的似然重新加权，信念变窄/变清晰）

预测让信念**变宽**（不确定性增大）、更新让信念**变窄**（信息注入）——演示里的估计线之所以抖动又贴真值，就是这两股力在交替。三类滤波器只是「用什么数学表示信念」的区别：

| 滤波器 | 信念表示 | 适用 |
|---|---|---|
| 卡尔曼 | 高斯（均值+协方差） | 线性高斯 |
| HMM 前向 | 离散表格 | 有限状态 |
| 粒子滤波 | 加权样本集 | 任意非线性/非高斯 |

**卡尔曼一步**——预测-更新的最小实现，增益 K 是「信模型还是信观测」的自动权衡：

```python
import numpy as np
F, H, Q, R = 1.0, 1.0, 0.01, 1.0                 # 匀速模型 + 噪声
x, P = 0.0, 1.0                                  # 状态与协方差
rng = np.random.default_rng(0)
truth, obs, est = [], [], []
z_true = 0.0
for t in range(30):
    z_true += 0.2                                # 真实：匀速漂移
    z = z_true + rng.normal(scale=np.sqrt(R))    # 带噪观测
    x = F * x + 0.2; P = F * P * F + Q           # 预测（匀速模型：速度已知）
    K = P * H / (H * P * H + R)                  # 卡尔曼增益
    x = x + K * (z - H * x); P = (1 - K) * P     # 更新
    est.append(x); obs.append(z); truth.append(z_true)
err_kf = np.abs(np.array(est) - truth).mean()
err_raw = np.abs(np.array(obs) - truth).mean()
print('卡尔曼误差', round(float(err_kf), 3), '< 原始观测误差', round(float(err_raw), 3))
# 模型对（速度已知）时滤波显著降噪；模型错（漏掉速度项）时滤波反而更差
```

## 二、卡尔曼的数学：为什么是「最优」的

线性高斯假设下（转移/观测线性、噪声高斯），高斯信念经预测-更新后**仍然是高斯**——闭式更新就是卡尔曼方程。它是最优的含义：在同类信息下均方误差最小的线性估计器（比它好的都是非线性/非参数）。

**五个方程**（一维版三行）：

$$\hat{x}^- = F\hat{x} + Bu, \quad P^- = FP F^T + Q \quad\text{（预测）}$$
$$K = P^-H^T(HP^-H^T + R)^{-1}, \quad \hat{x} = \hat{x}^- + K(z - H\hat{x}^-), \quad P = (1-KH)P^- \quad\text{（更新）}$$

**增益 K 的直觉**（演示的曲线）：R 大（传感器烂）→ K 小 → 修正幅度小（更信模型）；P 大（模型不准/目标机动）→ K 大 → 更信测量。**K 在 0~1 之间自动滑动**——这就是「最优融合」的可视化。

**EKF/UKF**：非线性场景把模型在当前点线性化（EKF，阿波罗时代就上月球）或用 sigma 点采样（UKF）；粒子滤波则完全放弃高斯假设。

## 三、HMM 的三大问题与算法

| 问题 | 定义 | 算法 |
|---|---|---|
| 评估（filtering/smoothing） | $P(z_{1:T})$ 或 $P(x_t\|z_{1:T})$ | 前向 / 前向-后向 |
| 解码 | 最可能的状态序列 $\arg\max P(x_{1:T}\|z_{1:T})$ | Viterbi（动态规划） |
| 学习 | 估计转移/发射概率 | Baum-Welch（EM） |

**Viterbi 的直觉**：找最优路径不能贪心（每步取最可能状态可能整体次优）——动态规划保留「到每个状态的最优路径分数」，一步不漏。复杂度 O(T·N²)。

**前向-后向**：前向算「到 t 为止的观测证据」，后向算「t 之后将看到的证据」——两者相乘是完整的平滑后验（用未来信息修正当前估计；滤波只用过去、平滑用全部）。

**Baum-Welch = EM**：E 步用前后向算状态占据的后验，M 步按占据重估转移/发射计数——与 GMM 的 EM（见其深读）完全同构。

## 四、粒子滤波：万能的兜底

非线性+非高斯（机器人视觉定位、多模态目标）时闭式解全失效。**粒子滤波**：用 N 个加权样本（粒子）表示信念——

1. 每个粒子按转移模型推进（预测）；
2. 按观测似然给粒子加权（更新）；
3. 重采样（权重大的复制、小的淘汰）。

粒子数够多时可逼近任意分布；代价是 O(N) 计算与「粒子贫化」（重采样多样性损失）。**蒙特卡洛定位（MCL）**是它在机器人学的化身——演示（见具身智能深读的 MCL 部署）就是它的 2D 网格玩具版。

## 常见误区

- **「卡尔曼滤波只适用于线性系统」** —— 基本 KF 确实假设线性高斯；EKF（扩展）与 UKF（无迹）通过局部线性化/确定性采样处理非线性系统——假设可以放松而非换框架。
- **「HMM 的隐状态数量越大越好」** —— 状态数是模型容量参数；过大导致转移矩阵稀疏与过拟合（Baum-Welch 的 EM 会把低频状态当噪声吸收）——用 BIC/交叉验证选择。
- **「卡尔曼滤波的估计值就是真实值」** —— 滤波给出的是后验分布的均值——是「当前信息下的最优估计」而非真值；协方差 P 量化了残余不确定性（很多人忽略 P 只看 x̂）。
- **「粒子和卡尔曼是竞争关系」** —— 粒子滤波是贝叶斯滤波的非参数版本（用采样代替高斯假设）——两者是同一框架的不同实例化，选择取决于非线性程度与计算预算。

## 五、要点总结

1. **统一骨架**：预测（变宽）+更新（变窄）——三种滤波器只是信念表示不同。
2. **卡尔曼增益 K=P/(P+R)**：自动分配「信模型 vs 信测量」。
3. **HMM 三问题**：评估（前向）、解码（Viterbi）、学习（Baum-Welch=EM）。
4. **滤波 vs 平滑**：滤波只用过去、平滑用全部——离线分析用平滑、在线系统用滤波。
5. **粒子滤波**：采样逼近任意分布——非线性非高斯的万能兜底。
6. **现代融合**：深度网络学「转移/观测模型」，滤波骨架负责推断——learning + filtering 的混合是当前主流。
