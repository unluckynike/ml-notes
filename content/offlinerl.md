# 离线 RL 深读：分布偏移、保守性与方法谱系

这篇是**离线强化学习**主题的深度补充。演示里「朴素外推红线虚高、保守绿线诚实收缩」的对比，对应这个领域最核心的问题——**分布偏移下的外推误差**。这篇讲清它的数学、方法谱系（BC/CQL/IQL/DT）与选型。

> [!KEY] 一句话抓住本质
> 离线 RL 的全部难题是一句话：**策略要访问的状态-动作，数据集可能从未覆盖**——Q 函数在这些区域是自由外推，贪心会精准找到虚高的错误去访问，误差自我放大。所有方法都在回答同一个问题：「怎么让学到的策略待在数据支撑附近」。

## 一、分布偏移：一个例子看懂

医疗场景：数据来自「保守的老医生」（大多开保守处方）。离线 RL 学到的 Q 函数发现：「激进处方」在数据里偶尔出现时效果不错（幸存者偏差）→ Q(激进处方) 虚高 → 贪心策略选激进处方 → 但数据里激进处方的「后果」样本极少，Q 的估计根本不可信——**策略精准地跑向了数据最不可信的区域**。

数学：外推误差 = Q 在数据支撑外与真实值的偏差；贪心 argmax 会**系统性选择正偏差最大的动作**（winner's curse）。误差随训练轮次自我强化（self-accumulation）。

**分布偏移的数值实验**——数据只覆盖 a∈[0,2]，模型在覆盖外严重失真：

```python
import numpy as np
rng = np.random.default_rng(0)
def true_value(a): return -0.1 * (a - 5)**2 + 2.5   # 峰值在 a=5

actions = rng.uniform(0, 2, 200)                 # 数据只覆盖 a∈[0,2]
rewards = true_value(actions) + rng.normal(scale=0.2, size=200)
# 用二次函数拟合（模型族恰好正确），再看 a=5 处的外推
coef = np.polyfit(actions, rewards, 2)
pred5 = np.polyval(coef, 5)
print('外推 V(a=5):', round(float(pred5), 2), '| 真值:', round(true_value(5), 2))
print('数据覆盖内 V(a=1):', round(float(np.polyval(coef, 1)), 2), '| 真值:', round(true_value(1), 2))
# 覆盖内准，覆盖外飘——保守估计（CQL）就是冲这个来的
```

## 二、方法谱系：四条技术路线

| 路线 | 代表 | 思想 | 权衡 |
|---|---|---|---|
| **行为克隆（BC）** | 直接监督学习 (s→a) | 完全待在数据分布内 | 不会复合分布偏移，但只能模仿、无改进 |
| **保守值估计** | CQL | 压低数据外动作的 Q 值 | 稳；λ 调不好过度保守 |
| **策略约束** | BCQ/ TD3+BC | 动作离数据集别太远（距离约束） | 依赖密度模型质量 |
| **序列建模** | Decision Transformer | 把 RL 当序列翻译问题 | 无值函数、靠条件化回报 |

**CQL 的实现**（一行思想）：在标准 TD 损失上加一项

$$\lambda \left[ E_{s \sim D, a \sim \text{均匀}} Q(s,a) - E_{s,a \sim D} Q(s,a) \right]$$

——数据外动作的 Q 往下压、数据内动作往上抬——估值被「钉」在数据支撑内。

**IQL（隐式 Q 学习）**的巧思：完全避免查询数据外动作——用 expectile 回归估计「数据内的分位价值」（上分位数 ≈ 该状态下的最优动作价值），从不触碰 unseen (s,a)——简单稳定，成为工程常用。

**Decision Transformer 路线**：(R₁, s₁, a₁, R₂, s₂, a₂, ...) 作为序列输入 Transformer，条件于「目标回报」生成动作——RL 变成条件序列生成（与语言建模同构）。优点是简洁、可复用大模型架构；缺点是「目标回报」在真实环境里不好设。

## 三、与相邻领域的关系

- **vs 模仿学习（BC）**：BC 只复制行为（无改进）；离线 RL 要「比数据里的行为更好」（需要奖励信号 + 反事实推理）——能力上限更高，风险也更高；
- **vs 在线 RL**：在线能探索新策略（上限最高）但试错昂贵；离线安全但受数据覆盖限制——**现实部署常是「离线预训练 + 有限在线微调」**；
- **vs 监督学习**：离线 RL 处理「长期后果与信用分配」；一步决策问题用监督学习就够了（别把 RL 当锤子）；
- **与 LLM 的交汇**：RLHF 本质是「从人类偏好数据的离线数据学习策略」（见其深读）；Decision Transformer 开启「序列建模即 RL」路线。

## 四、实战：什么时候用、怎么评估

**适用**：试错不可接受（医疗/驾驶/工业控制）、有大量历史日志、奖励可定义或可反推。

**评估（D4RL 基准思路）**：数据集划分（训练/验证轨迹）→ 离线指标（FQE 等离线策略评估）→ 谨慎的在线小规模验证。**离线指标高 ≠ 真实部署好**——离线策略评估（OPE）本身是研究难题。

**常见坑**：

1. **奖励反推偏差**：从日志反推奖励（如用事后结果）会引入偏差与泄漏；
2. **保守超参的跷跷板**：λ 太小回到朴素外推、太大退化为 BC——在验证集上扫描；
3. **数据时效**：旧策略的日志反映旧环境（分布漂移，见 MLOps 深读）——需要时间窗过滤或重加权。

## 常见误区

- **「离线 RL = 在离线数据上做在线 RL」** —— 离线 RL 的核心挑战是**分布偏移**（策略访问数据未覆盖的区域）；不能直接套用在线 RL 算法（Q-learning 会外推虚高价值）——保守性/策略约束是必需的。
- **「离线 RL 的数据越多越好」** —— 数据**覆盖度**比数量更重要：10 万条只覆盖左半空间的轨迹不如 1 万条覆盖全空间的轨迹——数据多样性与任务相关性的评估先于训练。
- **「离线 RL 学到的策略可以直接部署」** —— 离线策略在部署环境（可能与训练数据分布不同）的表现需要**离线策略评估（OPE）**先估计——直接部署绕过评估是最大风险。
- **「Decision Transformer 是离线 RL 的终极方案」** —— DT 简洁且可扩展，但缺少 RL 的「改进」能力（只能模仿数据中最好的行为，不能超越）——序列建模与值函数方法是互补而非替代。

## 五、要点总结

1. **分布偏移**：策略访问的区域 ⊄ 数据覆盖——外推误差被贪心利用、自我放大。
2. **四条路线**：BC（纯模仿）/ 保守值（CQL）/ 策略约束（BCQ）/ 序列建模（DT）。
3. **CQL 一行思想**：压低数据外动作的 Q 值，钉住估值。
4. **IQL 的巧思**：expectile 分位数估计——从不查询数据外动作。
5. **Decision Transformer**：RL = 条件序列生成；「目标回报」当 prompt。
6. **部署纪律**：离线评估（OPE）→ 影子模式 → 小流量——三步走（见 MLOps 深读）。
